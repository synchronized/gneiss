# ADR-103：显式多态与引用按值持久化

- 状态：已接受。
- 日期：2026-11-04。

## 决策

ref 负责内存所有权，不隐含持久化共享身份。空引用保存为 null；普通引用内联字段；
声明类型显式注册 polymorphic 时使用 `$type_guid` / `$content` 信封，实际类型必须通过
已注册 base 链兼容声明类型。未知或无关类型在构造前拒绝。运行期类型 ID 不写入文件。

重复引用独立保存并独立恢复；循环引用报错。删除自动 `$root` / `$objects` / `$ref` 协议。
需要共享身份的业务显式保存对象列表和 object_id；跨文件资源身份继续由资源 URI 管理。

组件列表使用 ref<const component_description_base>。具体描述提供实际类型身份；编辑复制
具体值后替换引用。组件的类型信封和字段处理统一进入 Meta，不在组件包装中重建动态 codec。

## 权衡与验收

减少自动对象图与业务身份两套协议；代价是序列化不保持内存别名，重复内容占用文件空间。
当前不承诺任意继承字段自动合并；基类存在注册属性时冻结失败，避免静默丢字段。

验收覆盖空引用、重复引用独立恢复、循环拒绝、未知/无关类型、基类指针偏移、const 目标视图，
以及 Scene/Prefab、编辑器和 IPC 的组件往返。仅编译和针对性测试，不运行大场景或远端 CI。
