# ADR-082：撤销动态游戏模块

状态：已接受。替代 ADR-080 中保留最小游戏模块协议的决定。

当前没有独立分发游戏代码的需求。动态模块使 Runtime、Editor 启动、工程打包同时承担
ABI 校验、模块编译、Context 句柄与动态库生命周期管理，超过当前阶段需要。

删除动态 Game Module、模块专用示例与 C 协议，不提供兼容桥。Runtime 保留场景、输入、
渲染与编辑 IPC；工程模板改为纯场景与资产模板，运行和打包不编译或复制游戏 DLL。
客户注册 system 或其他逻辑入口留待后续设计，本次不新增回调框架或脚本承诺。

原模块工程不再执行自定义 C++ 游戏逻辑。已有模块字段需要移除；独立游戏代码加载、
固定步长游戏更新与模块热重载均不构成当前能力。保留与模块无关的场景和渲染示例。
