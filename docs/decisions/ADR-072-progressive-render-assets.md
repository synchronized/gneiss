# ADR-072：普通渲染资产默认逐步就绪

- 状态：方向已接受，尚未实施；具体结构与兼容性审计待完成。
- 日期：2026-10-22

## 背景

CAORS 替换后仍存在固定版本发布、版本选择、整批采用和历史保活等协议。
用户确认可以接受首次资源暂不显示、更新期间继续显示旧资源，再逐步切换到新内容。
此前为了严格整批一致性增加的协议不再作为普通加载的默认要求。

## 决策

普通视觉资产采用渐进可用策略，更新保留有效旧资源；共享逻辑 RID 默认稳定。
CPU 读取与解码留在 asset_manager，渲染侧负责上传、安全切换、缺省显示及资源退休。
Runtime 负责逻辑场景生命周期，不默认等待所有视觉资源同时完成。
不以“已提交”推断 GPU 已完成；底层同步与寿命按后端契约处理。
取消普通加载对通用确切版本采用和跨资产原子替换的默认要求；特殊事务只服务已确认消费者。
历史恢复语义、游戏模块必需依赖和公共 ABI 在迁移前单独审计，不视为已授权任意删除。

## 影响与替代方案

允许短暂缺省显示及跨资产分帧更新，换取较少的版本和事务状态；仍需任务顺序、失败诊断、
生命周期和资源回收。稳定 RID 不表示不同来源/类型/设备域可以混用，也不取消销毁失效。
全量整批就绪适合有明确一致性要求的局部操作，不再普遍施加；完全不跟踪上传结果则不能
可靠完成失败处理、重复提交控制与资源释放，不采用。

本决策调整 ADR-071 在替换完成后的后续简化方向，不改写既有实现和验收记录。
完整目标结构、迁移顺序、未决项和验收见
