# ADR-040：工程脚手架与目录包导出共用工作流

## 状态

已接受。

## 背景

工程模板、Editor 创建页面和未来命令行如果分别生成文件，会很快产生格式与构建配置漂移。导出又
需要明确区分作者输入、构建中间物和可运行内容。

## 决策

- 模板目录是脚手架文件的唯一来源，共用工作流负责复制、标识替换和事务提交。
- Editor 只负责收集用户输入和展示结果，不拥有工程文件生成规则。
- Runtime 配置与构建由进程工作流分阶段执行，任何失败都阻止启动。
- 目录包只包含工程描述、运行资产、已构建模块、Runtime、动态依赖及启动脚本。
- 包目录先写入同级临时目录，完成校验后再重命名；不隐式覆盖已有目录。

## 影响

增加命令或 UI 入口时无需复制工程规则；模板 Schema 变化只修改一处。首版目录包可审查且易于
诊断，但体积优化、归档、签名和平台商店集成需由后续发布管线承担。
