# ADR-075：普通资源加载不再强制来源复验

- 状态：已接受。
- 日期：2026-10-24。

## 决策

按用户确认，删除 source_revision_file_system、验证专用打开入口及 complete_validation 回执。
VFS 仅提供普通同步 open_read 与可选异步 begin_open_read，保留有界读取和失败语义。
普通资产、Scene/Prefab 和 Action Map 在读完并通过格式检查后使用实际读取的数据；
不重新读取来源，不因读完后文件改变而撤销本次结果，也不承诺跨文件的一致版本快照。
文件更新由后续加载或显式重载处理。

CPU 内容缓存仍使用读取过程中计算的摘要和字节数，不依赖来源账本或验证回执。
纹理容器格式完整性、选中负载摘要、旧 GPU 投影恢复时的内容匹配、挂载身份、
读取范围、大小上限、取消和失败后保留旧资源的规则不变。

场景不再有 verifying 阶段、复验任务或耗时统计；引用建立完成后同步实例化。
内部 IPC 同步删除该阶段名称；新旧宿主进程不得混用，公共 C ABI 不变。

## 取舍

减少一轮重复 I/O、哈希、来源账本和跨任务复验状态。加载期间被外部修改的散文件可能产生
混合内容：解析或格式检查能够发现的错误返回失败，合法但跨文件不一致的组合不额外拒绝。
这是降低普通加载语义要求的明确选择，不以时间戳或另一套隐式复验替代。

本决策覆盖旧方案中普通加载必须完成来源复验的要求。
实施与验收见[移除来源复验计划](../plans/PLAN-051-remove-source-revalidation.md)。
