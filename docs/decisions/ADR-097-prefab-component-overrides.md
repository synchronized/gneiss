# ADR-097：Prefab 组件结构覆盖与冲突边界

状态：已接受，2026-10-30。实施见 [PLAN-086](../plans/PLAN-086-prefab-component-overrides.md)。

## 决策

Prefab 引用持有组件新增/移除记录，与属性覆盖共用来源对象 UUID 和组件 GUID 定位。
新增保存完整不可变描述，移除保存目标键；不建立第二份运行对象列表。
来源更新重新应用覆盖，预检查失败不修改 World，也不丢弃覆盖或按名称猜测新目标。
运行时安装失败仍遵守既有组件适配契约，不引入资源版本发布或 GPU 事务。

同类型来源新增与实例新增冲突；来源组件删除使属性覆盖失去目标时冲突；
移除记录允许来源组件已不存在，并在来源重新出现时继续隐藏。来源对象消失则所有覆盖均冲突。
属性覆盖类型/路径失效返回定位诊断，不进行隐式转换或自动三方合并。

## 取舍

操作结果可预测，错误可定位，保留后续人工修复空间；代价是冲突需要用户修正来源或明确丢弃覆盖。
同步 Scene 接口只消费已准备资源；编辑器网格恢复来源复用异步资产入口，历史保留实际资源引用。
当前不扩展旧的文件级 Apply/Unpack 算法；含组件结构覆盖时明确拒绝，避免丢失数据。
