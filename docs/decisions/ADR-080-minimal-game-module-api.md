# ADR-080：撤销完整公共 SDK，保留游戏模块协议

- 状态：已接受，迁移实施中。
- 日期：2026-10-24。

## 决策

不再为全部引擎对象维护公共 C ABI 和对应 C++ 值包装。
Engine、Runtime、Editor、Tooling 使用随源码构建的原生接口。
include 仅保留实际游戏动态模块所需的 C 协议；它不再传递暴露完整引擎接口。
基本值只有一份权威定义，只有真实跨模块协议保留显式转换。

## 影响

删除全面 SDK 布局版本兼容、导出和 consumer 维护成本；旧 SDK 不再兼容。
游戏模块继续使用 C 边界，内部 C++ 消费者随引擎重编译。
游戏协议仍需明确所有权、线程和关闭顺序，不因移除 SDK 放宽生命周期校验。

## 替代方案

全部改为原生 C++ 动态模块会进一步减少转换，但要求统一工具链及 ABI。
当前先保留已使用的游戏模块能力，不扩大协议。
