# ADR-126：格式无关的值类型适配

状态：已被 [ADR-127](ADR-127-static-representation.md) 取代（2026-11-18）。

以下保留原决策记录；独立适配器表和上下文覆盖不再是当前设计。

Meta 的结构类别与整体 value 转换不决定特殊文件表示。序列化适配器以普通 C++ 表示类型
表达字符串、可空值或固定数组，并递归复用通用遍历。JSON 后端仅实现基础形态。

适配器由序列化表按运行时 type_id 查找，contexts 借用已配置表；Meta 不依赖序列化。
显式自定义表可覆盖内置适配器，其余回退到不可变内置表。配置完成后可并发只读，不能在
操作中注册。表示值由单次转换调用持有，不形成第二份权威状态。解码成功后提交候选，
保留属性 setter 语义。适配器返回错误或异常遵循现有序列化错误契约。

代价是新增类型擦除分派；收益是内置与用户类型共享扩展机制，格式后端不再增加类型分支。
不自动生成 value_ops，不新增二进制后端。旧对象 content_codec 与适配器同时配置时，
适配器优先；两者不应为同一类型重复定义文件格式。
