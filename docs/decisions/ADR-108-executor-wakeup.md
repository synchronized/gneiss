# ADR-108：宿主唤醒由执行器边界管理

## 状态

已接受，2026-11-07。实施见 [PLAN-103](../plans/PLAN-103-executor-wakeup.md)。

## 背景与决策

业务层重复转发通知不能替代完成队列。共享任务执行器还可能服务多个宿主，不能使用单一全局信号。
任务 scope 在创建时接收共享 wakeup_signal；执行器记录完成后通知。关闭 scope 释放信号。
信号只提供线程安全 notify，不回调生产者；可能在执行器锁内调用，禁止重入执行器。
资产管理器接管独占 scope 的生命周期，不依赖唤醒接口。Application 负责创建与交接。
渲染执行器属于应用，继续配置独立完成唤醒。场景和资产业务状态改变不再发送唤醒。

## 影响与替代方案

保留现有完成队列、轮询入口和有限等待，避免引入新的调度系统。
相比每个任务携带信号，scope 绑定减少业务参数；相比执行器全局配置，支持多个宿主隔离。
传入资产管理器的 scope 必须为空闲且独占，成功后调用方不得提交任务或关闭它。
