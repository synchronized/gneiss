# ADR-115：World 运行对象入口与场景归属

## 状态

2026-11-10：已接受并细化，实施见 [PLAN-110](../plans/PLAN-110-world-scene-ownership.md)。
细化 ADR-110/111/112 的运行接口边界，不宣称目标已全部实现。

## 决策

World 唯一拥有 ECS、场景实例槽位和层级。game_object/scene_instance 为非拥有句柄；
场景树只表示实体上的层级数据，不另建对象存储，不维持 scene_node_id 与 entity_id 双接口。
场景归属通过实体组件表达，初期不另建可变成员表；父子同场景，跨场景移动显式迁移子树。
普通改名/变换/组件操作通过 game_object/World，场景集合不重复转发。

Scene/Prefab 是只读描述资产，结构依赖异步加载，组合只处理已加载的固定数据。
实例化同步创建运行对象，视觉资源可继续异步加载；运行场景状态不拥有资产管理器。
描述装配是独立边界，反射不隐式执行文件 I/O 或对象创建。

Editor 文档是编辑权威，历史和投影各有职责；Runtime 对象不保存覆盖/撤销语义。
IPC 调用现有应用接口，不引入第二套状态。必要来源映射由装配回执交给编辑器/重载协调器。

## 2026-11-10 补充决策

运行对象不强制保存描述 UUID，来源关系由组合/实例化回执及外部投影维护。
compose 只处理固定描述；instantiate 接收显式目标场景与组合结果，失败只清理本次创建对象。
Scene/Prefab 共用装配入口，不由实例化隐式创建目标场景或激活相机。
完整重建生成新场景句柄，编辑会话更新自己的关联；不提供保留原句柄的 replace_members 接口。
默认相机为选择提示，激活和安全点切换属于应用/视口。
运行组件装配注册不依赖 Inspector/编辑历史策略。描述属性读写是 Engine 通用能力，
添加默认值、可删除标记、面板路由及编辑采用策略归 Editor 独立注册；后者按组件 GUID 关联运行类型。
不为 Editor 查询将策略反向保存到 Engine。具体 API、迁移步骤及验收统一见 PLAN-110。

## 取舍

保留 ECS 复用已有组件寿命及存储能力；删除无职责转发减少重复验证和类型分支。
代价是借用有效期、组件访问失效与场景归属不变量需要集中维护；遍历 membership 为线性查询，
有实际性能证据后才增加内部派生索引。编辑器同步失败不回滚已接受文档，明确记录预览失步。
不采用单 World 单 Scene 限制，因为需支持同一 World 多个可独立卸载的场景实例。
不让场景管理对象同时做资产加载、装配和普通对象编辑。

## 目录归属补充

World、GameObject、SceneInstance 与场景组合/装配统一位于 function/scene，
ECS 状态、层级实现和渲染快照提取放在其 detail 子目录。目录共置不改变资产、
运行对象和 Editor 文档的所有权；编辑组件策略仍在 Editor。
仅测试使用的查询模型不留在 Engine 接口中。具体布局见 PLAN-110。


## 受控对象与借用接口补充

普通对象的名称、层级、局部变换及场景归属统一为 World 私有 object_state。
辅助实体不伪装为 GameObject，内部仅登记必要归属。两种成员均随场景卸载。
遍历初期返回非保活句柄快照，避免公开 ECS 迭代器；无结构修改时保留同步 visitor，
不提前实现带修改代次的自定义范围类型。

组件新增拒绝同类型冲突，借用查询要求有效对象及所属线程。任何结构修改后重新获取借用。
副本读取及显式安装/替换继续保留，不把替换伪装为新增。
相机选择由独立渲染提取边界提供，状态使用 World 的通用扩展上下文；
World 不再包含相机业务方法、字段或销毁特判。应用决定何时选择，显式视口相机优先。
