# ADR-091：Prefab 作为普通对象的来源元数据

## 状态

已接受并实施；运行时成员、直接来源根、统一描述与相对覆盖键已迁移。实施与验收的权威来源为 [PLAN-058](../plans/PLAN-058-prefab-object-metadata.md)。

## 背景

ADR-090 清理了运行时重复状态，但普通节点与 Prefab 来源节点仍存在不同成员和拥有路径。
用户确认统一对象引用 Prefab，并用描述数据表达实例属性覆盖。

## 决策

Prefab 资产是模板，实例化结果是普通场景对象。所有实际节点由场景统一管理。
实例根逻辑挂接可选、类型化的来源元数据；由场景层保存来源资源强引用和来源节点到实际节点的非拥有映射。
底层场景树不持有 Prefab 资源或服务，ECS 继续拥有功能组件与资源绑定。
对象描述以可选 Prefab 引用表达实例，实例身份使用外层对象 UUID，覆盖只定位来源节点及属性。
运行时普通修改不自动创建持久化覆盖；编辑器显式维护覆盖，不改变共享模板。
最终使用模板来源根作为实例根，外层名称及局部变换优先；分阶段迁移避免同时改变管理和空间语义。

## 取舍

- 比独立 Prefab 对象体系更容易统一遍历、查询和生命周期；保存仍需识别来源节点，不能直接把全部运行时节点展开写入。
- 元数据采用场景私有表而非底层节点内的资源指针，保留现有分层边界；这张表只表达关系，不形成第二套对象状态。
- 不引入任意键值 metadata、结构覆盖和嵌套模板，降低当前实现成本。
- 去掉自动容器会改变旧根变换语义，必须同步更新格式及资产；不承诺任意旧 TRS 组合都能无损折叠。
