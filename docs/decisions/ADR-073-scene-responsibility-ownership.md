# ADR-073：场景结构、视觉加载与作者数据的所有权

- 状态：已接受，第一批已实现，行为验证待统一执行。
- 日期：2026-10-23

## 决策

scene_session 负责场景域切换，application_scene_state 持有 World 和实例服务，scene_instance
负责单个实例的节点、实体和资源引用。Editor document 负责编辑会话和查询镜像，不替代运行实例。

视觉加载服务在 session 内装配一次，始终使用宿主 VFS；场景结构请求不再复制上传后端或创建
视觉服务。切换继续要求旧请求排空，再由同一服务处理新视觉队列。服务请求号跨切换保持单调。

普通场景节点名称只在 scene_description 中持有；运行记录不再复制名称。查询按既有描述/运行
数组的对应索引读取作者名称，重命名只修改一处。UUID 的构建期索引用途本轮保持。

## 取舍

减少服务生命周期转换和名称双写，保持公共 ABI、一个 World 多个 Scene 与结构失败保护。
不合并 session 和 instance；直接合并会把场景切换与节点管理重新混在一起。
不删除文档 World 身份检查或被 UI 消费的镜像；需要进一步核对消费者才能减少这些状态。

编译验收与延后行为验证按[实施计划](../plans/PLAN-051-scene-responsibilities.md)执行。

## 补充决策：同步实例化

用户确认删除普通场景的跨帧结构构建。后台读取、解析与来源校验完成后，
由 scene_instance_service::instantiate_prepared 在所属线程一次创建整个实例。
删除 scene_load_builder、跨调用游标、步数和时间预算；不保留可选的分帧构建路径。
实例化只消费已准备描述和预留资源引用，不回退到同步文件读取；GPU 内容仍随后独立加载。
构建中的局部对象通过所有权自动清理，失败不切换活动场景域。

取舍：减少暂停、恢复和中间状态；一次实例化不可中途取消，大场景可能阻塞主线程。
当前接受此限制，不承诺每帧实例化预算。编辑器 Prefab 操作的分步处理不属于本次场景加载改动。

## 补充决策：统一场景服务

用户确认将场景加载、切换和生命周期协调收敛为 runtime::scene_service。
scene_session 与 scene_load_service 合并为同一对象；加载数据只存在于内部临时任务，
完成或取消后释放，不保留第二个服务对象及其重复装配依赖。
World 与实例集合继续组成场景域，scene_instance_service 改为域内 scene_instances；
它只管理该 World 的实例和操作，不依赖 Runtime，也不拥有加载队列或场景切换状态。
统一服务通过活动域提供实例集合访问，避免为所有实例操作增加一层逐项转发。

实现按生命周期、加载两份源文件组织。保留多个 Scene 共用 World、待切换域隔离、
同步实例化及独立视觉加载。公共 C ABI 不变；内部调用和头文件清单统一迁移。
验证沿用仅编译和必要源码检查，行为回归延后统一执行。

## 补充决策：编辑操作直接访问场景实例集合

Application 负责服务组织与应用生命周期，不为创建网格节点、捕获网格绑定提供业务转发。
Editor 通过 scene_document 的具体操作访问 scene_instances；文档检查线程、应用停止状态、
World 身份和场景有效性，并维护选择、脏状态与查询记录。Scene 不反向依赖 Application。
非编辑器调用方直接使用实例集合，并负责在其宿主生命周期允许的阶段调用。

文档创建入口只消费已准备资源，删除外部创建回调和未使用的 URI 创建路径。
编辑命令保留异步准备、冲突检查及历史组织，撤销按稳定 UUID 定位，重做持有资源强引用。
这样避免逐项应用转发及双向回调；代价是直接使用 Scene 的调用方不能依赖应用包装代查停止状态。

## 补充决策：文档不持有长期节点副本

文档只持有编辑会话状态。名称、层级、组件、变换及 Prefab 来源/覆盖从 Scene 查询；
单节点返回自有值，遍历返回短期快照，调用方负责持有。删除文档节点数组与编辑后的同步协议。
命令不依赖面板缓存，面板不将快照反向写回。查询不会隐式标脏，dirty 仍由编辑入口维护。

代价是面板刷新会重新查询和分配快照；当前接受，不提前引入版本和增量通知。
单节点查询仅在定位目标后读取完整组件。跨进程 Runtime 镜像继续保留，不属于文档副本。
