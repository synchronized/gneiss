# ADR-090：场景树和 ECS 作为运行时对象状态的权威来源

## 状态

已接受，实施见 [PLAN-057](../plans/PLAN-057-scene-object-storage.md)。

## 背景与决策

实例列表、场景树和 ECS 重复保存实体与资源绑定，普通对象和 Prefab 各自创建、清理。
保留场景树与 ECS 分工，将 UUID、名称和空间关系放入节点；功能组件与运行资源引用放入 ECS。
场景实例仅保留成员节点，Prefab 仅保留额外的来源关系。统一创建和销毁路径，失败创建立即清理。
文件描述保持独立，重载所需旧组件只在操作期间保留。

## 影响与替代方案

减少常驻引用和双向同步；节点查询需要一次句柄解析，借用字符串在节点删除或元数据修改后失效。
暂不将层级也迁入 ECS，避免扩大变换系统改造；不引入独立 Object 所有者层。
