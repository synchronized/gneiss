# ADR-104：Value 的受约束对象强引用

- 状态：已接受。
- 日期：2026-11-05。

## 决策

value 增加 ref<meta::object> 分支，在内存中用于对象传递和保活，持久化时按内容重建对象。
普通数学值继续按值保存，任意 C++ 结构体通过 meta::instance 借用访问。
value.hpp 仅前置声明对象基类，避免基础值头依赖完整 Meta 实现。

复制对象分支共享控制块，比较使用对象指针身份，不隐式深拷贝。
空对象引用区别于无类型的 invalid value。最后一次释放沿用 ref 的删除器和线程规则；
不新增统一主线程销毁队列，也不提供循环引用回收。

Meta 的引用类别保持不变。可变目标的 ref<T>（T 派生自 meta::object）
支持 read_value/write_value；写入检查 C++ 类型兼容性并保留原控制块和基类指针调整。
const 目标、普通结构体引用及裸指针不自动转换为可变对象引用。

对象分支不是标量快照。撤销、Prefab 覆盖等现有标量边界继续拒绝它；
需要保存对象快照时由业务显式复制对象或捕获属性数据。
通用 value JSON 使用 object 标签及 $type_guid/$content 信封，空对象引用使用 null。
只允许已注册且提供编解码能力的 meta::object 派生类，复用递归状态、引用环检测和校验；
解码后生成新对象，不保持共享身份。IPC 属性载荷直接使用 value，复用这套对象编解码。
普通类型化 ref 仍按 ADR-103 内联持久化，资源身份继续使用 URI。

## 权衡

复用现有对象身份和强引用，避免引入任意对象值容器或第二套生命周期。
共享修改对所有引用可见；调用方必须自行同步，不能把 value 复制当作撤销快照。
本次不扩展只读对象引用分支、对象图持久化或通用深拷贝。

## 验收

覆盖共享复制、空引用、最后一次释放、引用属性读写、无关类型拒绝、const 保护，
以及 value 对象和原有类型化 ref JSON 往返、未知类型/普通结构体拒绝、引用环和深度限制。
