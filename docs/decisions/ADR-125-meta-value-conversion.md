# ADR-125：类型结构与整体值转换独立

状态：已接受（2026-11-18）。

## 背景与决策

标量读写原先附着于 scalar_ops，导致对象不能在保留字段遍历的同时提供整体 value 转换。
采用独立 value_ops，通过 value_traits<T> 生成静态转换表。type_ops 仍仅有一个结构类别，
可额外提供整体转换能力；不创建第二份实例状态或所有者。

默认序列化按结构类别遍历，不因 value_ops 存在而选择自定义格式。对象 setter 仍在候选
初始化成功后执行；不能借整体赋值绕过 setter。转换失败、类型不匹配继续返回错误，
借用有效性属于调用前置条件。自定义 write 必须先校验再修改，失败时保持目标不变。

## 取舍

增加一张可选静态能力表，换取结构与值传递语义独立。特化须在首次实例化类型能力前可见，
并保持各编译单元一致。它不是任意 C++ 对象容器，也不自动增加 value 的存储分支。
