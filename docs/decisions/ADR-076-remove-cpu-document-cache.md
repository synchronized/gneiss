# ADR-076：删除独立 CPU 文档缓存

- 状态：已接受。
- 日期：2026-10-24。

## 背景

cpu_document_cache 在读取和解析完成后，按来源、URI、摘要和大小共享材质文档与网格数据。
它不避免重复 I/O 或解析，却引入独立弱引用索引、解码回调和批次接管协议。

## 决策

按用户确认删除该缓存、cpu_document_batch、asset_manager 的装配入口与回收调用。
准备流程直接解析并拥有材质参数和网格数组；删除仅供缓存登记使用的解码回调与文档保活字段。
网格在上传准备时移动到共享对象，渲染资源及在途帧继续按引用生命周期使用数据。
现有资源缓存仍负责正常资源复用；不另建 URI 映射替代被删除的缓存。

## 影响与替代方案

减少一层缓存及其协议；独立重复加载不再按内容共享 CPU 对象，可能增加重复数据的驻留内存。
保留独立内容缓存需要实际共享收益证据，目前选择更简单的直接所有权。
此决策取代 ADR-068、ADR-075 中保留独立 CPU 内容缓存的相关描述。
公共 C ABI、GPU 上传同步和失败保留旧资源的规则不变。

## 验收

清除源码、构建清单和测试中的缓存接口引用，调整材质准备和网格生命周期测试。
本阶段仅编译所有目标并做格式及边界静态检查；不执行测试、大场景或 CI。
