# ADR-109：结构化值、不可变文档与操作式 Prefab 覆盖

## 状态

2026-11-07：已接受，待分阶段实施。实施状态以 [PLAN-104](../plans/PLAN-104-value-document-prefab-overrides.md) 为准。

## 背景

复杂属性覆盖依赖 JSON property_snapshot，组件、子树、文档历史维护不同的复制恢复路径。
仅增加 value 对象引用不能固定历史内容；统一深拷贝又会破坏资源共享语义。

## 决策

扩展 value 为结构化数据表达；文档中结构化值逻辑不可变，可共享未修改节点。运行时对象强引用
不直接进入文档，捕获时按注册语义转为内嵌内容或稳定身份。外部资产只保存身份，不复制资源内容。
Core 负责数据与反射转换，Scene 负责对象身份及 Prefab 覆盖，Editor 负责文档版本和历史，World 负责运行时投影。

覆盖采用稳定路径和强类型操作，内容统一为 value。编辑器直接产生操作，diff 补充整块替换场景。
对象与组件实例 UUID 独立于类型 GUID。无身份可变列表整体替换，不以位置模拟稳定身份。
子树、文档和属性历史复用不可变值版本，允许删除现有专用内容快照，但不取消历史数据保留需求。

Prefab 源更新逐项重放覆盖，冲突保留并诊断，不猜测新目标、不要求跨资源原子回滚。
编辑文档是作者内容权威来源；World 投影失败不能反向覆盖文档。运行时无需持有编辑历史。

## 替代方案与代价

保留 JSON 快照实现简单，但把内存历史与文件格式耦合，难以统一差异和容器编辑。
只使用共享对象引用开销低，但无法保持历史内容。每次深拷贝全树较直观，但大文档历史成本高。
采用不可变结构增加路径复制、共享节点及历史预算管理成本；换取统一版本、历史和修改入口。
不实现自动共享对象图或循环图持久化；需要共享身份时领域数据显式定义对象表和引用。
