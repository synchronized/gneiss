# ADR-067：编辑器视口相机与运行时主相机分离

状态：已接受。

## 背景与决定

用户确认编辑器视口独立管理观察相机。原实现创建编辑器实体并写入 World 活动相机，
导致带主相机的 Prefab 和编辑器争用同一个选择槽位。禁止 Prefab 切换相机不能解决这一边界。

Editor 持有漫游相机的变换和投影设置，不在用户 World 创建实体或节点，不进入场景保存、
Prefab 和撤销历史。宿主将相机值交给渲染入口；World 仍提供场景内容，运行时主相机选择
保持独立。相机数学与渲染管线继续复用，不复制 World。

当前单视口宿主通过私有接口设置值副本；设置有效至替换、清除或 Application 销毁。
清除后使用 World 主相机。帧绘制和截图使用同一选择，视口尺寸变化时重建投影。
无效输入拒绝且保留原选择，接口仅允许所属线程调用，不保留宿主指针。

Prefab 成功创建仍可按现有运行时规则激活主相机，不能改变 Editor 的观察视角。
候选构造仍不得提前修改运行时活动相机，失败和取消必须保持原状态；这一事务要求不因
编辑器视角分离而取消。

## 范围与后续

本次只接通现有单视口。多视口、场景相机预览、游戏画面面板不在本次实现范围；以后由
各视口显式选择相机，不能回到共享的全局观察相机。未新增公共 ABI 或 Granit 接口。

实现及验证见 [M-331 视口相机记录](../records/M-331-editor-viewport-camera.md)。
