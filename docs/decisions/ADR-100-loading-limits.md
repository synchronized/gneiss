# ADR-100：加载保护集中到文件服务与格式解码器

- 状态：已接受。
- 日期：2026-10-31。

## 决策

删除普通加载的逐请求 maximum_bytes、Decoder 通用读取上限、管理器 fallback_limit、
resource_service 的 256 MiB 硬上限及场景加载组的额度透传。
文件服务统一配置单文件上限和在途缓冲预算，普通加载使用服务默认读取重载。
直接使用文件服务的调用方仍可显式收紧 read_options。

格式层保留结构、尺寸、数量、整数溢出检查及自身格式限制；PNG 保留像素展开保护。
这些约束不冒充完整内存预算。资源统计继续保留，但不据此拒绝普通加载。
缓存身份仅含来源域、URI、类型和内容相关配置，不再含读取额度。

## 影响

接口简化，文件服务配置成为统一读取边界。纹理描述与负载分别检查文件上限。
取消通用输出额度后，CPU 数据和并发解码内存不受完整预算控制；
后续流送系统负责总驻留预算、并发调度与淘汰，本次不提前实现。
PNG 的解压保护与文件服务缓冲预算不受影响。

实施见 [PLAN-095](../plans/PLAN-095-loading-limits.md)，当前契约见[资产参考](../reference/assets.md)。
