# ADR-111：局部文档历史与统一运行投影

## 状态

2026-11-08：已接受，实施见 [PLAN-106](../plans/PLAN-106-document-history-projection.md)。
调整 ADR-110 的历史版本保留选择，承接 ADR-109/PLAN-104 的文档权威边界。

## 决策

普通编辑历史记录局部作者数据前后值及结构变更，不以整文档快照为长期默认。
文档负责合法性和可逆变更；历史管理游标、合并及保存点；投影将目标有效数据更新到 World。
撤销与正常编辑共用变更通知和投影入口。Prefab 请求先解释为来源覆盖变更，历史不重新猜测覆盖。
实体未删除时保持身份；删除恢复分配新实体，用文档身份恢复关联，不另加重复运行实例 ID。
完整快照保留给保存/检查点/整文档替换，投影失败与文档接受分别报告。

## 取舍

整文档版本历史容易保证一致性，但默认整场景重建会失去无关实体身份和运行状态。
纯命令回调容易接入，却把反向操作及生命周期责任分散给 UI；本次不选择。
局部变更需要明确结构操作与旧值校验，增量投影需要处理部分失败；以集中入口和相关回归约束。
迁移期间可保留有边界的完整重建回退，不并行维护两份可编辑权威数据。
