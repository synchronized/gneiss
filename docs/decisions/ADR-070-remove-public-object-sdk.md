# ADR-070：删除公共 C++ 对象 SDK

- 状态：已接受
- 日期：2026-10-21

## 背景

公共 C++ 对象包装与内部原生对象同时演进，会增加命名、所有权与迁移维护成本。
用户确认优先整理内部架构，删除 `gneiss::sdk`，不继续维护完整的 C API 对象包装。

## 决策

- 删除公共对象 SDK，外部 C++ 消费者使用 C ABI；内部直接使用原生 C++ 对象。
- 保留 C ABI、共享枚举/ID/描述值及无状态转换；不删除整个 include，也不改变 C 符号和布局。
- 不创建兼容转发，不把 SDK 改名或移入另一处继续维护。
- 示例、模板与行为测试改为 C ABI；局部通用清理守卫不提供业务接口、不安装。
- 删除只针对 SDK move/adopt/析构约定的测试，保留并迁移 C ABI、场景、资源及编辑行为测试。
- 安装验证检查已删除头不可包含，C11 头和保留的 C++20 值头仍独立编译。
- 本决策替代 ADR-053、055、056、062 中要求公共对象 SDK 完整包装 C API 的部分，
  并更新 ADR-069 中不改变公共 SDK 的限制；内部原生层与 C ABI 的分层继续有效。

## 影响与替代方案

这是外部 C++ 源码不兼容调整，现有调用方须显式管理 C 句柄和错误；C ABI 不因此改变。
保留 SDK 或仅迁移命名空间仍需同步维护两套接口，因此不采用。
以后是否提供专门的外部 C++ SDK，应由真实消费需求另行决定；本次不开发插件 API。

迁移说明见 [0.51 迁移指南](../guides/migrating-0.50-to-0.51.md)，
验证见[实施记录](../records/M-332-public-object-sdk-removal.md)。
