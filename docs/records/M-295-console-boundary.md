# M-295：控制台脱离 Runtime 日志协议

日期：2026-10-05。

## 实施范围

将控制台实现迁至 `src/editor/console_model.hpp/.cpp`，加入独立编辑模型目标。
以拥有字符串的 `console_event` 替换宿主协议记录，保留级别、序号、时间、线程、来源、
分类、正文与结果码；不保存协议版本。

Apps 的 `runtime_log_adapter.hpp` 将已校验协议记录的文本字段移动进控制台。
Runtime 宿主保留解析、协议校验和按会话/序号/来源去重，控制台保留容量、筛选与会话记录行为。
不增加第二套日志服务、历史缓存或运行状态，公共日志 API 和线协议不变。

控制台测试直接链接模型库。新增零容量、无效会话检查；进程测试增加协议对象销毁后
全部元数据和长正文仍有效的适配验证，并保留真实子进程日志与重复首帧记录检查。

## 验证结果

- Windows Clang Debug 共享配置全量增量构建通过。
- Editor、工程/IPC 与边界 CTest 49/49 通过，49.16 秒。
- 控制台实现的编译命令不含仓库 Apps 路径；控制台测试链接不含宿主、工程或 IPC 协议库。
- 控制台、适配头及修改测试的 clang-format 检查通过；修改文档相对链接与 git diff --check 通过。
- 本轮未重跑静态、全量 Engine 单测和跨平台 Actions，未做分配失败故障注入。

## 剩余工作

场景镜像和属性响应仍使用协议类型；工程、进程装配与主程序面板仍待拆分。
本轮不代表完整薄入口或 0.45 发布完成。
