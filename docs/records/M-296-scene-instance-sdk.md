# M-296：场景实例包装与子树 Prefab 边界

日期：2026-10-06。

## 审查与缺陷

核对 23 个场景实例包装的描述借用、节点身份、场景所有权、快照与错误输出，补充公共 C++ 工作流测试。
修正文档中过宽的字符串有效期：节点描述按值返回，但其中字符串指针在场景修改后必须重新查询。
测试在重命名前复制名称与 UUID，修改后不解引用旧视图。

新工作流复现普通作者子树的恢复失败：捕获时保留了场景其他位置的 Prefab 声明，其父节点不在快照中，
恢复解析因外部父引用失败。现改为排除无关 Prefab。当前恢复器不支持 Prefab 投影，因此捕获/删除
内部挂接 Prefab 的子树、恢复含 Prefab 的快照，均在修改前返回 unsupported；单节点删除也检查
Prefab 子节点并返回 invalid_state，避免留下失效投影。失败前后序列化完全相同。

这是 Gneiss 作者场景语义修复，不需要 Granit 改动；没有新增 Prefab 子树复制能力或改变 C ABI 布局。
当前能力边界与借用期限以 [Scene Reference](../reference/scene-instance.md) 为准。
