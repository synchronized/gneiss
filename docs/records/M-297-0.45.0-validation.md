# M-297：0.45.0 整版验收

2026-10-06，本地常规矩阵、Release 完整 Cook 与 Debug 日常回归通过；Debug 完整 Cook 限时失败另列。Actions 恢复后所需远端 12 项发布检查已全部取得通过证据，[0.45.0 已发布](../versions/0.45.0.md)。

## 本地验证

Windows Clang Debug，启用 Granit、Editor、Runtime 与离线工具；共享和静态完整构建通过。

| 项目 | 结果 |
| --- | --- |
| 共享完整 CTest | 187/187，206.73 秒 |
| 静态完整 CTest | 184/184，107.02 秒 |

build/0.45-final-consumer-{shared,static}.log 及 build/0.45-final-exports.json。

## 平台范围

Windows 手动矩阵新增 MSVC Editor 全量编译及 CPU/无原生窗口 ImGui 测试。托管 Windows
没有 Vulkan ICD，显式排除创建真实图形设备的用例；这些用例仍由 Linux 图形矩阵完整执行，
本地 Windows 也已完整通过。配置和构建失败会立即终止 PowerShell 步骤，避免后续命令掩盖失败。

Linux 维持 GCC/Clang、共享/静态、真实图形、sanitizer 与无线程浏览器任务测试。
最终 run、PR 和发布链接见下文；纯文档更新不重复触发矩阵。

## 范围与限制

本版完成源码归属、薄 C ABI 与完整 C++ SDK 映射；不升级 Granit，不新增插件框架。
0.44 的 cooperative 大场景长帧、取消终态预算独立观测与真实 GPU 显存测量仍未解决。
Sponza 仅复用已有 Cook/日常输入验证行为，不重新作性能优化结论；第三方大资产不随发布分发。

## 首轮平台问题与修复

候选 af0a4d9 的 Windows MSVC 已编译 Editor；重导入队列夹具在临时目录含路径别名时失败。
本地目录联接复现退出码 2，统一规范路径基准后通过，普通专项也通过。补充失败阶段输出。
Lantern 工程 smoke 同样创建 Vulkan 设备，补入无 ICD 的 Windows 排除范围；Linux 与本地仍执行。

Linux 首轮已通过 Sanitizer、Clang 共享/静态、GCC 静态及图形静态；三个任务因 hosted Runner
多次分配失败被取消，不能视为测试通过。手动工作流新增 editor 范围，只补跑受影响的宿主矩阵；
无修改的核心和 Web 使用原候选的未执行任务补验，不重新跑已通过的完整矩阵。

完整 Cook Sponza Debug 首载触发工具既有 15 分钟期限，退出 4 / not ready，retained_tasks 为 0；
保留 build/0.45-final-sponza/summary.json，不计为通过。相同输入的 Release 首载成功：553 节点、
505 资源、候选 1,773,169,608 字节，未提高 2 GiB 预算。单样本不作为性能优化结论。

原取消工具在进入被测阶段前同步预载完整 Cook 失败（退出 11）。预载改为同一异步事务并消费
终态/回收旧域，不调整预算、校验或超时；小夹具在线程池和协作模式下的切换、取消、失败保留
旧画面共 6/6 通过。大场景复验结果见下文，旧失败日志保留。
