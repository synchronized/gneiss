# 0.10.0 稳定性预览验收记录

## 当前结论

0.10.0 候选已完成本地 Windows Clang Release Shared/Static 验收，以及远端 Windows、Linux 手动
矩阵验收。版本接口、未来 1.0 ABI 候选基线、0.9 Application v1 Consumer、图形样例、资产工具、
隔离安装 Consumer、Granit 运行时及 Sanitizer 均通过。当前记录不是最终发布结论；Changelog
发布日期和 `v0.10.0` 标签仍待完成。

## 本地矩阵

| 配置 | 结果 | 覆盖 |
| --- | --- | --- |
| Windows Clang Shared Release | 46/46 通过 | C/C++ API、ABI 候选、0.9 Consumer、图形样例、安装 Consumer |
| Windows Clang Static Release | 54/54 通过 | Shared 覆盖项、资产工具、Lantern 导入、静态依赖闭环 |

两种配置的 `gneiss_version_example` 均由项目版本生成并通过正则校验。隔离安装 Consumer 会删除旧
安装树后重新安装，检查项目许可证、Changelog、第三方声明与四份 Runtime 第三方许可证，再从复制到
源码树外的样例源文件配置、构建和运行。

候选提交在本地额外通过无 Granit、无编辑器的 Windows MSVC Shared Release 完整构建，以及
`gneiss.installed_consumer` 隔离安装测试。

使用，因警告视为错误而中止构建。候选提交 `91124b2` 修复条件编译参数处理后，两条工作流全部通过。

## 已确认发布内容

- 安装头文件、库、CMake package 与版本文件报告 `0.10.0`。
- Shared 安装包含 Gneiss DLL，Static 安装不依赖 Gneiss DLL。
- 稳定运行时、Temple 与 Lantern Gallery 的配套资产安装到 `share/gneiss/examples`。
- 项目许可证、Changelog 和第三方声明安装到 `share/doc/gneiss`。
- EnTT、yyjson、libspng 与 miniz 许可证原文安装到 `share/doc/gneiss/licenses`。
- Granit 保持外部依赖，不由 Gneiss 安装树复制或重新发布。
