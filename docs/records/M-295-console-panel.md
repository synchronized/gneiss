# M-295：控制台面板与宿主分离

日期：2026-10-06。

## 变更

将控制台绘制、日志行格式化及筛选/暂停状态从 Editor main 移入 `src/editor/console_panel.hpp/.cpp`，
编入 `gneiss_editor_ui`。面板借用唯一日志模型、进程展示值和同步清空回调，不依赖工程、进程或 IPC。
宿主继续负责 Runtime 输出和模型的同时清空；日志路径只在绘制期间借用，面板不缓存进程数据。

暂停保存记录 ID 截止位置，不复制日志。后台接收与容量淘汰继续进行；已淘汰的暂停记录不会被新记录替代。
面板的筛选、暂停、自动滚动状态仍由窗口持有，模型、协议解码和宿主所有权不变。
