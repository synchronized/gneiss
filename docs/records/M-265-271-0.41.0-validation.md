# M-265～M-271：0.41.0 异步模型资产验收

## 状态

2026-09-25，发布验收通过。范围见
[VER-041](../plans/VER-041-0.41.0-async-model-assets.md)，当前契约见
[调度指南](../guides/task-scheduling.md)。本版无 Granit 跨仓库修改。

## 正确性

- 两种执行模式覆盖混合首次加载、材质纹理闭包、类型冲突、依赖缺失、容量限制、取消后重试、
  已获许可后取消拒绝、旧 RID 与旧快照保持、材质依赖所有权。
- 假上传后端验证 4 资源与 8 MiB 分批边界，第二批失败后回收整批，缓存不出现半发布。
  原纹理回归继续覆盖同步事务覆盖、卸载后迟到拒绝、缓存命中不读盘和失败清理。
- GPU 像素回归在真实管线渲染并回读，两个模式均由蓝色变红色；材质切换新纹理依赖后恢复蓝色，
  网格缩小后像素覆盖减少。混合批次任一源损坏，整张 RGBA 输出与失败前完全相同；改变离屏输出
  尺寸后仍正确。此验证补齐 0.40 系统 GDI 截图未取得 Vulkan 画面的缺口。
- IPC 编解码和 Runtime 路由验证域版本 3 的 progress/cancel、身份、数量和消息方向拒绝。
  Editor/Runtime 进程回归覆盖材质新依赖、损坏纹理失败及重试。取消按钮与服务取消分别有路由及
  服务测试，未把人工点击按钮或真实跨屏 DPI 记为已经验收。

## 真实模型与窗口测量

Windows，Intel Core i5-8600K / Intel UHD 630；仓库 Lantern GLB 经 `gneiss_assetc import` 重新生成，
三个 Mesh 和材质及其纹理闭包合计 CPU 候选 16,974,653 字节。导入工具分别约 128/118 ms，
此耗时独立于 Runtime 准备阶段；基准重载导入产物，不在主线程执行 glTF 导入。

命令：

```powershell
python tools/performance/measure_model_loading.py build/windows-clang-debug/bin/gneiss_texture_load_window_benchmark.exe build/windows-clang-debug/bin/gneiss_assetc.exe examples/lantern_gallery/assets/source/Lantern.glb --output build/0.41-model-debug --samples 3
```

Release 换用 `windows-clang-release` 与独立输出目录。每模式三次，加载过程中移动相机、九次 resize，
最小化后恢复。结果范围（毫秒）：

| 配置/模式 | CPU 准备 | 主线程最大更新间隔 | GPU 命令 | 最大呈现间隔 |
| --- | --- | --- | --- | --- |
| Debug 线程池 | 325.95–431.91 | 3.64–29.60 | 12.31–14.69 | 229.72–303.82 |
| Debug 协作 | 316.77–356.05 | 317.03–356.44 | 12.85–23.56 | 262.73–314.61 |
| Release 线程池 | 79.70–80.83 | 3.88–5.90 | 9.85–10.37 | 232.18–300.95 |
| Release 协作 | 79.51–81.28 | 79.58–81.35 | 9.21–11.00 | 239.26–509.17 |

12 次均完成发布和窗口恢复。另两次在约 1 秒开始加载后请求退出，Debug 总运行/销毁 1.344 秒，
Release 1.153 秒，分别呈现 59/61 帧；未发布未完成候选。保留实际析构等待，不宣称即时取消解码。
汇总见 [Debug](artifacts/0.41-model-debug.json) / [Release](artifacts/0.41-model-release.json)，
原始 CSV 与日志在对应本地输出目录。

线程池减少 CPU 解析期间的主线程阻塞；协作模式不能抢占单个任务。呈现间隔包含窗口最小化及
GPU 阶段等待，不能据此宣称稳定帧率或单纯归因于上传。独立网格缓冲避免整体重建，更多缓冲/绑定
也有成本；本模型测量不是所有资产、硬件或规模的性能保证。

## 边界

初始 Scene、Scene/Prefab 结构修订仍同步，公共异步 SDK 与完整引擎 Web 未提供。
缓存身份使用全局修订保守失效；读取复查不提供跨进程原子快照。单资源超上传预算时单独执行，
驱动调用及单个协作任务不可抢占；候选限制不是进程内存上限。
