# 0.13.0 结构化日志与 Editor Console 验收记录

## 当前结论

0.13.0 候选已完成 Windows VS2022 Shared Debug 自动化与隔离安装树验收。Engine、Runtime、Game
Module、跨进程协议、Editor 有界 Console 和 Lantern Gallery 日志链路均通过。浮动面板布局将在
后续 Editor Docking 工作区中重做，不作为本版本发布门槛；当前仅剩 Linux 等远端矩阵尚待验收，
因此本记录尚未确认版本完成。

## 人工验收处理

0.13.0 不再以当前浮动面板的视觉布局作为发布门槛。Console 数据模型、筛选、会话隔离、暂停显示、
清空、复制、自动滚动、Runtime 启停和 Lantern Gallery 结构化日志链路均已有自动化覆盖。当前布局
缺少 Docking 与持久化，运行后可能因 ImGui 浮动窗口状态产生不稳定观感；该问题不在临时布局上
继续修补，统一进入后续 Editor UI 工作区改造。
