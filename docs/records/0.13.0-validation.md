## 待完成人工验收

使用构建树 Editor 打开 Lantern Gallery：

```powershell
./build/windows-vs2022-debug/bin/Debug/gneiss_editor.exe `
  --project ./build/windows-vs2022-debug/examples/lantern_gallery
```

需要确认：

1. 运行工程后 Console 同时显示 Runtime、Application 与 Lantern Gallery 模块事件。
2. 级别、Raw、当前会话、来源、分类和搜索组合筛选符合预期。
3. Pause 冻结可见结果但 Resume 后能看到期间日志，Clear、Copy visible 和 Auto-scroll 可用。
4. 重启 Runtime 后，Current session 不显示旧会话记录。
5. 窗口在 1280×720 下无明显遮挡、截断或无法操作的控件。
6. 缩放 Editor 主窗口后 UI 覆盖完整客户区，各主要面板可以移动和拖动边界，Console 放大后文字
   清晰可见；当前不验收尚未实现的 Docking 与布局持久化。
7. 顶部运行、暂停和停止图标清晰可辨；运行与停止可驱动现有 Runtime 工作流，尚无控制协议的暂停
   按钮保持禁用，窗口创建和缩放期间不会因零尺寸过渡帧退出。
