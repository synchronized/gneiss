## 已确认边界

- Game Module 使用单一 C 查询入口和版本化 Experimental ABI。
- Runtime 按初始化、固定更新、逐帧更新、关闭顺序独占模块生命周期。
- Game Context 只借出当前 World、启动根实体、输入动作和退出请求等最小能力。
- Editor 停止旧 Runtime 后通过受约束 CMake preset/target 构建模块，成功后才重新启动。
- 原生动态 Game Module 必须链接 Shared Engine；Static Engine 不提供该动态模块模型。
- 工程格式 v2 可声明输入映射和平台无关模块产物，v1 无模块工程保持兼容。
