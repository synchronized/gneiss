# Granit 0.71.0 升级与原生窗口联合体

## 范围

2026-11-17 查询上游标签与 HEAD，最新发布为 v0.71.0，均指向
`4eebbdd73bca010761b7528ec34bd76ae630d32f`。FETCH 锁定该提交，归档 SHA-256 为
`1b5ee78e20ea9da7543cd1a05d42a2c9ec3e9fe4d92f247c3ff45acc8c5119d4`。
继续使用 MIT 许可的 Granit 渲染/窗口/AssetTools 能力；未引入 Render Graph 或 CAORS，
未修改 Granit 仓库。依赖来源仍支持 PACKAGE 和父工程目标，具体版本要求见构建指南。

## 适配

- 同步 FETCH 默认缓存迁移、PACKAGE 查找与静态安装 find_dependency 的 0.71.0 版本要求。
- Window 使用 Granit 的 window_flag C++ 枚举，不再引用已移除的 C 标志宏。
- 自有 native_handle 改为 backend + union data，分别表示 Win32、XCB、Wayland、Emscripten、SDL3。
  Granit get_native 一次查询后显式转换；不泄漏第三方类型，也不复制其 ABI 内存布局。
- Canvas selector 是带长度的借用，Render 转为 Granit surface_desc::canvas；窗口必须晚于表面销毁。
- SDL3 来源可表达，但 Render 未链接 IntegrationSDL3，明确返回 unsupported；没有默认增加 SDL 依赖。
- native_handle_changed 使原有表面失效，当前返回 unsupported；不把它当作 resize 后继续使用旧表面。
  真正的表面重绑需后续实现。
- C++ 内部句柄布局发生变化，所有消费者应重新编译；持久化资产格式不变。

## 验证

- Windows Clang Debug 完整共享构建通过，16 项相关测试通过。
- 包含原生窗口资产集成、安装 Runtime smoke、版本缓存迁移、AssetTools inspect/cook、
  资源准备/纹理加载、渲染队列/场景和真实窗口 smoke。窗口用例包含连续 resize、最小化捕获和恢复。
- Windows Clang Debug 静态 Engine 与相关测试目标构建通过，5 项相关测试通过。
- 补齐 AssetTools、Scene Viewer 和示例资产后，Granit 与 Gneiss 静态安装成功；独立 CMake
  消费程序通过 find_package(gneiss) 链接 gneiss::engine 并运行成功。消费程序借用同源码的
  内部头文件，仅验证安装目标的依赖传播与静态链接，不代表提供安装版 C++ SDK。
- 静态配置显式切换为 FETCH，避免既有 PACKAGE 缓存继续指向旧版 Granit。未运行完整静态测试集。

本地日志位于 build/granit-upgrade-*.log，不作为发布产物。

## 限制

当前环境没有可用的 emcc，未进行 Emscripten 编译或浏览器验收；SDL3、Linux、Release 和远端
Actions 未验证。具备原生句柄分支和 Canvas 转换不等于 Gneiss Web/SDL 全链路已完成。
