# 同步渲染重载收敛记录

日期：2026-10-23。对应[四步删除清单](../plans/PLAN-051-progressive-render-assets.md) 第 2/4 步的同步路径部分。

## 变更

`render_asset_loader::reload_assets` 删除临时缓存、临时加载器、独立排序与逐类型获取回调，
复用 `prepare_render_assets → stage_asset → publish_assets`。
同步入口继续阻塞所属线程，不创建线程或额外管理器。

旧 URI 缓存资源重载成功后保留 Mesh、Material、Texture RID，并替换不可变 CPU 内容。
原有租约因此看到新内容；旧帧仍持有旧数据。失败保留原内容；发布修订号阻止此前已上传但尚未
采用的异步候选覆盖新的同步结果。材质纹理依赖统一由通用准备流程展开，沿用该流程的数量、
容量和来源复验约束，而不再使用无独立批次预算的旧加载回调。

## 验证

- 全量 Windows Clang Debug 构建通过。
- 加载器、纹理服务、真实 GPU 像素定向测试 3/3 通过。
- 加载器测试覆盖三类 RID 稳定、内容替换、旧数据保活、失败保旧和最后引用释放。
- 可控上传回执测试验证：异步候选等待期间同步写入新颜色，迟到候选失败且不覆盖新颜色。
- GPU 测试只修改并重载纹理文件，不重建场景或材质，画面从红色变蓝；无效文件重载失败后
  画面保持蓝色。
- Windows Clang Debug 完整回归 201/201 通过，耗时 179.29 秒。
- clang-tidy 修正本次容量表达式的整数扩宽告警；文件原有候选/发布复杂度、隐式布尔转换及
  初始化列表告警仍在，未关闭检查。格式和差异空白检查通过。
- 随后补强失败时三类数据对象均不变的断言，并对容量表达式作等值类型修正；重新构建后
  加载器、纹理服务和像素定向回归 3/3 再次通过。

## 边界

此入口只处理旧 URI 缓存，不会替固定版本场景执行采用。仍沿用整批 CPU 发布，不代表已经
删除普通路径的全部事务；首次请求预留租约、场景提前激活及编辑器历史收缩仍待实施。
同步入口不等待 GPU 上传，后续帧重建镜像；GPU 上传失败保旧的完整语义仍由异步迁移继续处理。
未验证其他平台和后端，不将测试耗时作为性能改进结论。
