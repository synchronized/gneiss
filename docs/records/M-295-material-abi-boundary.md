# M-295：材质创建的 ABI 边界

日期：2026-10-06。

## 变更

Render 资源服务接收内部 `material_resource`，资产加载器直接提交该值，取消内部值到 C 描述再解析的往返。
唯一资源表、RID 校验、采样及数值校验、内存预算和帧快照持有语义不变。

`src/engine/api/material_description.hpp` 负责 C 描述的版本、保留字段和默认值转换；仅读取声明版本内的字段，
转换失败保留内部输出。公开创建入口仍先清空输出句柄，保留 Application 校验与异常隔离。
公共头、布局和导出符号没有变化。边界检查禁止内部反向包含 API 适配，以及 Render 消费或生成材质 C 描述。

## 验证

- 共享完整构建及渲染、场景、资产准备和边界相关回归 31/31 通过，101.43 秒。
- 新增转换失败不修改输出的断言后重新构建材质测试，1/1 通过。
- 静态构建 C 渲染、材质及帧包目标；C 渲染、材质、边界及负例 4/4 通过，2.51 秒。
- 真实 C 入口新增 V1/V2 尾部忽略、非法尺寸、保留字段和失败清空句柄验证；原有纹理归属与材质生命周期用例保留。

Mesh、Texture 和其他 Render/Scene 描述仍有待转换，本记录不代表整版验收或发布完成。
