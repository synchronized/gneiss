# M-295：网格与原始纹理输入边界

日期：2026-10-06。

## 变更

资源服务的同步创建接口改为 `asset_internal::mesh_view` 与 `render_internal::texture_view`。
视图使用 span 表达同步借用，成功创建后复制为唯一资源数据；已有 CPU 准备结果的移动发布、多 Mip、
Manifest/Payload 和上传租约路径不变。资产加载器不再为内部网格发布拼装 C 描述。

C 描述的版本、保留字段、指针/数量关系集中到 API 适配器；网格拓扑、法线/切线、颜色、纹理尺寸与
行距、跨服务 RID 和内存预算仍由所属资源服务校验。原始纹理字节数先验证可表示为本机范围，避免在
32 位平台转换为 span 长度时截断。公共头与 ABI 没有变化。

## 验证

- 共享完整构建通过；渲染、场景、Lantern、Cook、GPU 像素、资源所有权与边界相关测试 32/32 通过，102.46 秒。
- 静态专项构建通过；C 渲染、资源服务、PBR、UI、帧包及边界正反例 7/7 通过，2.65 秒。
- 新增借用源修改后资源副本不变、RID 销毁后帧持有仍有效、转换失败保留输出的测试。
- 真实 C 入口覆盖 Mesh V1/V2 忽略尾部、非法尺寸、空指针/非零数量、Texture 保留字段与失败清空句柄。
  32 位字节数溢出断言已加入，当前 Windows x64 不执行该条件分支，留给最终 Emscripten 矩阵。
- clang-tidy 未报告本次新增逻辑问题；资源服务原有尾逗号及指针隐式 bool 风格提示保留，未降低检查等级。

UI/Debug 提交、Scene 描述以及编辑器剩余面板职责仍待收口；未运行最终远端矩阵或发布。
