# M-166：渲染命令进度与失败隔离

## 结果

渲染 Command 获得线程安全进度 Reporter，可发布准备、上传和工作量信息。调用方可在 Command
执行期间查询当前序列、阶段、完成量、总量及活动状态；Command 结束后，最终快照与结果码进入
完成回执。

初始化与关闭命令已接入 Reporter。失败命令只产生对应失败回执，不会终止渲染执行器；资源镜像
仍采用候选对象创建成功后再替换的方式，纹理与几何上传失败不会提交半成品句柄。

## 验证

- 单元测试在 Command 执行期间查询上传阶段及工作量，并验证完成后的最终状态。
- 失败命令保留已报告工作量、返回原始错误且执行器继续运行。
- Windows Clang Shared 构建、渲染执行器测试和 Granit 平台 Smoke 通过。

## 已知边界

- 首版阶段进度表示 Gneiss 已确认的命令工作量，不代表驱动内部的逐字节百分比。
- 当前资源 API 只支持创建和销毁，没有原地修订；修订号和热替换协议应在资源更新 API 落地时扩展。
