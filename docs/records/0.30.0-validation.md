# 0.30.0 版本验收记录

## 候选范围

- 公共 C 声明、ABI 符号基线与 Stable/Experimental 分类一致性门禁。
- 安装 SDK 中可复制的游戏工程模板及 `GNEISS_GAME_TEMPLATE_DIR`。
- 源码树外的 Game Module 配置、构建、动态加载、日志和 Runtime smoke 闭环。
- 兼容、Game Module、工程格式和构建文档收敛。

## 本地验证

- Windows Clang Debug Shared：配置、完整构建及 132 项 CTest 通过。
- Windows Clang Debug Static：配置、完整构建及 130 项 CTest 通过。
- Windows Clang Release Shared/Static：全新配置、完整构建，各 65 项 CTest 通过。
- `gneiss.api_stability_manifest`：102 个导出分类检查通过。
- `gneiss.runtime.installed-smoke`：安装后模板与既有 Runtime 工程验收通过。

Release 首次配置发现旧构建目录保留了用户显式 Granit 提交覆盖，指向不含 RenderPipeline 资产的
早期提交。使用 preset `--fresh` 清除该本地缓存后，当前锁定的 Granit 0.14 配置与两组 Release
矩阵通过；该旧缓存不属于源码或发布产物。
