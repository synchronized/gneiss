# M-154：0.23.0 发布验收记录

## 结果

0.23.0 已完成 Granit v0.5.0 依赖基线、C++ Result 值类型和 Granit Provider 可重复性收口。
`gneiss_result` C ABI 与既有结果码数值保持不变；Granit Fetch 使用完整提交哈希，PACKAGE 最低要求
0.5，沿用旧默认提交的构建缓存可升级且不会覆盖其他显式提交。

## 验证

- Windows Clang Shared Debug：全量构建及 125/125 测试通过，包含 C11/C++20 API、ABI Consumer、
  Granit 平台、Runtime、Editor、示例和安装消费。
- Windows Clang Static Debug：全量构建及 123/123 测试通过，包含静态安装消费与 Granit 平台路径。
- CMake 配置测试覆盖全新默认值、引入追踪前的旧默认缓存、显式自定义提交和关闭默认升级。
- [Linux Actions 33941416872](https://github.com/synchronized/gneiss/actions/runs/33941416872)
  的 Clang/GCC Shared/Static、Granit Runtime Shared/Static 无头测试和 Sanitizer 共 7 个任务通过。

## 已知边界

- 引入默认值追踪前，CMake 无法区分用户刻意指定的旧默认提交与项目旧默认值；需要固定该提交时
  设置 `GNEISS_GRANIT_UPDATE_DEFAULTS=OFF`。
- 本版本不增加用户功能，也不包含 Scene、Prefab 或 Game Module 结构热重载。
