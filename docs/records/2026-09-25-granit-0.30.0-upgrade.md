# Granit 0.30.0 接入验收

## 范围

2026-09-25，默认依赖由 Granit 0.29.1 升级到正式发布 0.30.0，固定提交
`0471650803b9ff725c9ae287d0cafc8e8cb63f71`。同步更新 FETCH 默认缓存迁移、PACKAGE 最低版本、
安装包依赖和父工程目标的编译期版本检查；未修改 Granit 仓库。

继续使用 Granit 原生 Window/Input，两套验证构建的 `GRANIT_ENABLE_WINDOW_SDL3` 均为 OFF。
0.30 新增的 SDL3 后端必须显式选择；Gneiss 当前仍查询原生窗口句柄并传给渲染服务创建 Surface，
因此本次不宣称支持切换 SDL3，也不迁移平台与渲染服务的交接方式。

## 验证

| 配置 | 构建 | CTest |
| --- | --- | --- |
| Windows Clang Debug Shared | 通过 | 142/142，243.19 秒 |
| Windows Clang Debug Static | 通过 | 139/139，50.84 秒 |

使用仓库 configure/build/test preset，未降低警告或跳过用例。验证包含默认版本缓存迁移、
公共 C/C++ 测试、安装后的稳定 Runtime Consumer、窗口和 Editor smoke、Runtime 资产修订、
源监听与重导入、灯廊和纹理工作流。Shared 还覆盖安装后的 Runtime 与打包启动检查。
两套构建均确认实际使用 0.30.0 固定提交，原有调用代码无需额外适配。
Static 的既有 `FETCHCONTENT_SOURCE_DIR_GNEISS_GRANIT` 覆盖复用 Shared 下载的源码，
独立生成静态库；其目录中遗留的旧下载副本不参与构建，已通过 cache 和编译命令核对。

本地日志位于 `build/036-granit030-*.log`，未纳入版本控制。源码编译期版本断言已按
clang-format 格式化；本轮未重复完整 clang-tidy 扫描。

## 未覆盖与后续

本次未运行 Linux、MSVC 或远端矩阵，未做真实鼠标滚轮、手工 resize、跨 DPI 或 SDL3 验收。
原生窗口的程序化 smoke 通过不替代全部交互验收。0.36 仍在开发，升级不表示本版本已发布。
后续若引入 SDL3，应先设计 Granit Window 统一创建 Surface 的内部交接，再验证输入、resize、
DPI 及安装依赖；无需在 Gneiss 公共 API 中暴露 SDL 类型。
