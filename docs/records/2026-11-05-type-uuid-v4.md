# 内建类型 UUID v4 迁移验收

日期：2026-11-05。环境：Windows、windows-clang-debug。

## 变更

将 17 个内建类型的手工短编号替换为一次生成并固定的 UUID v4，保留 guid::literal 声明方式。
原 matrix3 与 prefab_property_override_key 共享 97410000 短编号，本次按类型分别生成身份，消除重号。
已有正常 UUID 不变。源码、测试、样例及当前参考文档均已核查，无旧类型编号残留引用；
仓内资产没有写死这些旧编号，无需改写资产文件。字节补零测试使用独立测试值。
新增静态断言覆盖这 17 个类型的 UUID 版本位、variant 位及互不重复。

下表仅记录本次迁移，不是运行期兼容映射；旧身份不再受支持。
新增类型的固定身份规则见 [Core 参考](../reference/core.md)。

## 验证

- windows-clang-debug 构建通过。
- 57 项身份、反射、序列化、资源加载、Scene/Prefab、IPC、编辑器及边界回归全部通过。
- 全源码 GUID 常量检查确认每个新 UUID 仅声明一次，未与既有常量冲突；正常 UUID 均保持原值。
- 独立 C++20 编译探针及测试静态断言确认 UUID v4 格式与唯一性。
- clang-format 检查与 git diff --check 通过。

未运行大型场景或远端 CI，未执行远端操作。仓外若持有旧类型编号的数据，需要按类型更新或重新生成，
不提供旧编号兼容。
