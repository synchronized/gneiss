# M-158：Prefab 批量结构刷新

## 结果

Prefab Runtime 投影新增身份协调重载路径。Scene 实例按来源 URI 收集全部同源实例，加载一次候选
Prefab，并在修改 World 前逐实例验证来源身份、结构差异、渲染资源和局部覆盖。全部准备成功后才
提交整批实例。

- 实例根保持不变；匹配来源节点按“实例 UUID + 来源节点 UUID”保留节点 ID 与实体 ID。
- 新增节点按父到子创建，重挂接先于删除，删除节点按子到父处理。
- 名称、Transform、Camera 与 Mesh Renderer 按作者差异更新。
- 每个实例的局部覆盖在新来源作者值之上重新应用。
- 覆盖指向已删除来源节点，或 Camera 覆盖指向不再包含 Camera 的节点时，整批在准备阶段失败。
- 成功提交后清除受影响实例的旧手动刷新撤销令牌，避免跨来源修订切换。

现有面向编辑器命令历史的单实例“刷新/切换/释放令牌”接口保持原行为；自动结构热重载使用新的
批量路径。应用层仅提供仓库内部宿主入口，IPC 接线由 M-159 完成。

## 验证

新增 `gneiss.prefab_structural_reload`，覆盖两个同源实例同步更新、匹配身份保持、来源新增节点、局部
Transform 覆盖重新应用，以及失效覆盖导致整批保留旧投影。
