## 正确性覆盖

- 真正解析和暂存后拒绝提交，旧派生目录中的标记文件和旧索引保持不变。
- 在导入阶段修改源文件，哈希复核拒绝过期产物；新通知使受阻任务失效并重排，最终索引匹配新源哈希。
- 阻止索引暂存文件写入，验证已经替换的派生目录能回滚到旧目录。
- 用屏障阻塞导入回调，主线程仍能轮询、请求刷新、取消和暂停；取消后可以再次导入成功。
- 暂停时最多接受 256 个待接收命令，超出明确拒绝；停止后拒绝新导入。
- 停止时析构等待屏障内的调用返回，取消任务不更新索引，不留下后台线程。
- 原生 Win32 回归在导入回调被阻塞期间完成 90 帧、18 次 resize、3 轮最小化恢复、
  5 组合成 DPI 消息，逐帧更新 Editor Camera 并提交 UI。
- 原资产导入、重导入队列、监听、浏览器及导入到 Runtime/打包工作流回归继续通过。

## 响应性测量

输入仍为静态三角形 glTF，以 JSON 空白扩展至指定大小；64 文件组每份 1 MiB。
这不代表复杂几何或大纹理处理成本。基准保留同步路径作对照，再修改一个源文件并后台补扫导入。
主线程每轮读取状态、消费通知与浏览器快照，记录整轮最大耗时；总耗时包含去抖、后台计算和等待。

```powershell
./build/windows-clang-debug/bin/gneiss_editor_asset_response_benchmark.exe ./build/0.38-asset-response-new
./build/windows-clang-release/bin/gneiss_editor_asset_response_benchmark.exe ./build/0.38-asset-response-release-new
```

Windows Clang Debug 首轮结果（原始日志 `build/0.38-asset-response.log`）：

| 输入 | 同步修改补扫最大 tick ms | 后台总耗时 ms | 主线程整轮最大 ms |
| --- | ---: | ---: | ---: |
| 1 MiB × 1 | 62.823 | 532.163 | 0.103 |
| 16 MiB × 1 | 690.576 | 1185.581 | 35.323 |
| 64 MiB × 1 | 3085.017 | 4324.201 | 229.322 |
| 1 MiB × 64 | 104.957 | 2577.051 | 1.340 |

Debug 仍有短暂停顿，不能宣称完全消失。分段探针将其定位在状态对象的默认构造：64 MiB 复测中，
状态读取最大 0.157 ms、事件交换 0.045 ms、浏览器读取 0.069 ms，但对象构造最大 242.810 ms。
本机 MSVC STL 的容器代理在构造时分配内存；UCRT `heap/debug_heap.cpp` 在全局堆锁内填充大块
分配及释放内存。独立于 Gneiss 的 O0 双线程探针（一线程反复分配/释放 256 MiB，另一线程构造
空路径和字符串）也测得 Debug CRT 577.086 ms；同一探针使用普通 CRT 时低于三位小数计时精度。
这支持调试堆争用的解释；没有关闭 Debug 检查或把其数据混作 Release 性能。

Windows Clang Release 结果（原始日志 `build/0.38-asset-response-release.log`）：

| 输入 | 同步修改补扫最大 tick ms | 后台总耗时 ms | 主线程整轮最大 ms |
| --- | ---: | ---: | ---: |
| 1 MiB × 1 | 29.039 | 485.292 | 0.136 |
| 16 MiB × 1 | 208.524 | 699.587 | 0.168 |
| 64 MiB × 1 | 585.660 | 1225.092 | 0.137 |
| 1 MiB × 64 | 52.000 | 1349.656 | 11.354 |

后台化移除了这些操作在主线程上的直接执行，不意味着导入吞吐同比提高。快照交接和释放仍有成本，
也不承诺任意机器的硬实时帧时限。上述为单轮观测最大值，不是统计分位数或最坏情况保证。

## 保留边界

作者 Scene/Prefab 监视、冲突判断和加载应用仍在主线程。解析器不能抢占，关闭可能等待当前阶段。
取消可能保留已复制的源文件；开始提交后的任务完成或回滚。外部 glTF 依赖未纳入源哈希。
不提供跨进程读隔离或断电事务恢复；文件系统同时阻止写入与回滚时需要保留备份人工恢复。
无实际物理跨屏 DPI、完整几何拾取或 SDL3 切换。以源码标签和 GitHub Release 发布，不附预构建 SDK。
