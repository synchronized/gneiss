# M-294：相机设置与子树映射边界

日期：2026-10-06。

## 变更

Scene 相机设置直接接收已有 `camera_description`，ABI 尺寸及保留字段检查归 C 入口。
保留字段非法时先验证作者节点归属，维持原先无效 Scene/节点优先返回 invalid_handle 的行为；
正常调用不额外查询节点。相机数值、主相机选择和作者数据更新仍由 Scene/World 完成。

子树 UUID 映射改为 `span<const uuid_mapping>`；C 边界用临时数组将指针/长度转换成借用视图，
不复制 UUID 字符串。临时数组分配失败返回 out_of_memory，不修改场景。重写完整性、目标 UUID 唯一性、
资产准备、失败回滚和作者数据所有权继续由 Scene 负责。

Scene 内部不再处理版本化 C 描述或字符串指针/长度；变换、实体 ID 等纯值类型继续复用。
边界检查加入相机描述与 C UUID 映射负例。

- 共享场景及候选构建专项重新构建后 4/4 通过，0.30 秒。
- 新增相机保留字段非法、Scene 失效、作者节点失效的错误顺序测试；原有子树 UUID 重写与撤销/恢复用例继续通过。
- clang-tidy 检查 C 入口；修正新增初始化列表提示，保留既有同类型相邻句柄提示。

本记录关闭 Scene 描述迁移子项；剩余模块审计、编辑器面板与最终发布验收继续进行。
