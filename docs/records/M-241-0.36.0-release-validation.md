## 发布限制

- 补扫按候选数量分帧；索引解析、单文件哈希与导入仍同步，不保证严格帧耗时上限。
- 脏场景冲突需要用户处理；补扫完成不代表所有导入或 Runtime 修订均成功。
- 真实鼠标 Gizmo、完整拾取、跨显示器 DPI 和 GPU 像素读回未全面人工验证。
- 既有 clang-tidy 异常逃逸、复杂度等告警未全部清理；本版本没有全仓静态分析零告警承诺。
- SDL3 Window 后端未接入；升级 Granit 不自动切换窗口后端。
