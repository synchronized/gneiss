- 本地验收日期：2026-08-27

## 实施结果

- 建立 Texture C11/C++20 契约、RGBA8 像素复制、颜色空间和 RID 生命周期。
- 使用 libspng 0.7.4 与 miniz 3.1.2 从 VFS 解码 PNG，第三方类型不进入公共接口。
- Mesh/Material v2 支持 UV、base-color Texture URI 与依赖租约，并保持 v1 资产兼容。
- Granit 后端实现 Texture/View 镜像、Sampler、Bind Group、材质批次和默认白纹理。
- 原创纹理神殿示例覆盖三张纹理、材质颜色乘法、无纹理材质和 2.5D 显式层级。
