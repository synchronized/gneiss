# M-295：Gizmo 绘制与编辑器宿主入口

日期：2026-10-06。

## 变更

ImGuizmo 帧初始化、重置、绘制与拖拽结束适配归 Editor UI；上下文仅在当前主线程调用借用
会话、命令历史、世界与拖拽状态。Apps 不再直接包含 ImGuizmo，库不持有整个应用状态。

main 只转交私有 C++ 入口，程序窗口、项目菜单、文件对话框、服务轮询及进程协议装配由
editor_application.cpp 所在的 Apps 宿主拥有。可复用模型、会话、资产服务、面板和创作事务已
归 src/editor；此次入口拆分不新增状态副本。退出先清理命令历史，再关闭被命令借用的会话。

## 验证

- 共享完整构建与静态 Editor/Gizmo/窗口交互目标构建通过。
- 共享专项 8/8，8.14 秒；静态专项 8/8，8.79 秒。
- 新增无原生窗口 ImGui 测试，覆盖普通绘制、选择变化时提交原对象拖拽、撤销恢复、零尺寸
  视口终止拖拽；既有输入回放、原生窗口交互及边界正反例保持通过。
- clang-tidy 检查新增实现与测试；仅保留既有公共描述初始化宏的 signed-bitwise 提示，未抑制检查。
