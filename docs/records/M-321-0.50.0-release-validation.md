0.688 秒（基线 216.66 秒）；该比值不代表 GPU 帧率或整机 CPU 使用率。

输入 P95 17.82 ms、最大 35.59 ms，任务接收 P95 16.83 ms、最大 21.52 ms，
窗口关闭接收 11.30 ms；553 节点、505 资源。图像与取消/清理另行验收。

实际 Runtime 二进制源码为 `aeaeab0`；响应夹具扩展在 `c121b1d` 归档。
