# Granit 0.74.1 拾取释放修复接入验收

## 基线与范围

- 新锁定提交：`c0bf848bdd8c19f98e85556c41047252b8e906ea`，远端标签 `v0.74.1`。
- 原版本：0.74.0，提交 `ae4d499c68d75d25fc49840c4b797d2a42a783a7`。
- codeload 归档 SHA-256：`c3864309ecb90f6eeed1a304ad76c6295c9b92506455381052b3c8631aa4086b`。
- 同步更新默认依赖、旧默认缓存迁移、PACKAGE 最低版本和源码版本断言。
- 本轮没有修改 Granit 仓库，也未执行远端发布操作。

## 修复核对

Granit 的 RenderPipeline 销毁路径新增 object_id_pipelines 遍历销毁与清空，
并显式释放 object-ID fragment shader 与 MASK fragment shader。
此前 Gneiss 的首次关闭检查残留 1 个 graphics pipeline，详见
[UPSTREAM-052](../plans/UPSTREAM-052-granit-object-picking.md)。

## 本地验证

Windows Clang Debug 共享与静态构建均通过，两种配置各 9 项定向测试全部通过：
granit_version_cache、world_render_binding、render_executor、render_scene、
asset-pixel、render-pressure、render-texture-uploads、render-capture-failure 和 render-picking。

原拾取测试未修改；首次关闭输出 status=0、live=0、graphics_pipeline=0。
同时通过命中、背景、完整高位身份、旧请求映射、尺寸变化和删除场景后领取检查。
共享拾取测试耗时 1.96 秒，其余 8 项测试耗时 30.42 秒；静态 9 项合计 35.32 秒。
后端源码格式检查、文档相对链接检查及 git diff --check 通过。
