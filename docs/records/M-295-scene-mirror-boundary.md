# M-295：场景镜像脱离 IPC

日期：2026-10-06。

## 实施范围

将 Runtime 场景镜像迁至 `src/editor/` 的独立编辑模型目标。使用自有节点、变更、批次与
顺序标记；与属性模型共用 `runtime_object_id.hpp`，保留 generation 语义。
顺序跟踪器及原测试从协议模块迁入 Editor，不复制运行状态或保留旧实现。

Apps 的 `runtime_scene_adapter.hpp` 移动已解码节点文本并映射身份、相机、变换、资源和批次信息。
成功后镜像继续组装分片、检查顺序和图结构；转换失败保持转换输出不变，宿主使镜像失效并请求
重同步，可见快照保留。主程序与灯廊工作流读取模型节点，线协议和 Runtime 发送逻辑不变。

## 验证结果

- Windows Clang Debug 共享配置全量增量构建通过。
- Editor、工程/IPC 与边界 CTest 49/49 通过，48.07 秒。
- 原分块、缺口重同步、重复批次、非法图与 Prefab 复合身份测试保留；顺序测试迁移并新增零值及序号溢出验证。
- 宿主适配测试覆盖批次/节点字段、删除项、协议对象销毁后的字符串所有权及非法变更类型下输出不变。
- 镜像实际编译命令不含仓库 Apps 路径，独立测试链接不含宿主、工程或 IPC 协议库。
- 新模型/适配与修改测试的 clang-format、文档相对链接及 git diff --check 通过。
- 本轮未重跑静态、完整 Engine 单测、跨平台 Actions，也未注入分配失败。
