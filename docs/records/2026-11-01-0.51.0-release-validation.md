# 0.51.0 发布验收

2026-11-01，发布候选验证中，尚未发布。

## 范围

本版交付原生 C++ 架构与所有权整理，删除公共 SDK/C ABI 和 Game Module。
这是早期开发阶段的不兼容调整，旧消费者和旧资产格式不能假定兼容。
不把完整浏览器运行、流送系统或历史性能问题标记为已经完成。

## 已有证据

- Windows Clang Debug 最近的编译与 34 项 Editor/Runtime/CPU/IPC 回归通过，见
  [集中验收](2026-11-01-editor-resource-consolidated-validation.md)。
- 发布工作流移除已删除的 C Application、跨帧构建和来源复验目标，改用原生 Application、
  同步实例化与现有 Prefab 绑定测试；保留 Sanitizer 校验要求。
- `36a5a031` 首轮本地全量 203/205；两项旧夹具失败已保留原日志。修正工程 schema 和
  像素夹具后，全量 205/205 通过；Web 最小调度宿主在本地真实 Chrome 中通过。
- [首轮 Windows](https://github.com/synchronized/gneiss/actions/runs/41284523799) 与
  [首轮 Linux](https://github.com/synchronized/gneiss/actions/runs/41284526689) 暴露跨平台编译和
  验证环境遗留，不作为通过证据。修复后须验证新的候选。
- 合并与标签尚待完成。

## 首轮问题与修复

- 异步输入夹具不再强行写入旧工程版本，使用有效源工程版本。
- 像素夹具不再寻找已删除的 `prefab_instances`；按逐项采用约定验证失败网格保留旧几何、
  成功材质更新，并以同几何/同材质的成功重载作完整图像对照，不再要求跨资源事务回滚。
- 公共头辅助函数不再无条件链接数学依赖；依赖归入真正包含数学类型的值接口。
- 文件后端的同名类型使用限定名，基准程序使用 `nullptr` 判断 World 指针。
- Linux 核心矩阵包含图形示例，因此同样启动 Weston/Xvfb，而不是跳过图形测试。
- MSVC 共享库改为成员函数导出，不把 STL 私有存储整类导出；修正遮蔽和条件未使用参数，
  不关闭警告或降低 Werror。

## 第二轮候选

`bd573b89` 的 Windows Clang Debug 全量编译及 205/205 测试通过，包含 GPU 小夹具与 IPC。
[Windows 第二轮](https://github.com/synchronized/gneiss/actions/runs/41285544830) 和
[Linux 第二轮](https://github.com/synchronized/gneiss/actions/runs/41285570127)继续检查编译器差异。

GCC Release 对可选组件临时赋值报告未初始化，改为成功解码后直接构造新增覆盖，
移除覆盖明确使用 nullopt。GCC Sanitizer 不接受函数地址的 constexpr 空值比较，
改为按 nullptr 类型选择模板分支，再判断实际函数指针；补充有类型空回调测试。
修复后本地序列化、反射、场景相关 11/11 回归通过，GCC 结果仍须由后续矩阵确认。

MSVC 另修复测试局部变量遮蔽、65 层聚合初始化限制和编译期分支不可达代码。
深度限制验收仍是 64 层成功、65 层拒绝；资源退休队列在构造对象之前初始化销毁回调，
始终抛出异常的工厂仍按原规则回收分配。Linux 内存后端使用库内构造/析构，避免客户端引用隐藏虚表。

Windows 托管 Runner 无 Vulkan ICD，异步输入启动使用真实窗口，归入已有 GPU 测试分工：
本地 Windows 与 Linux 图形矩阵运行；Windows 托管矩阵仍全量编译，但不运行此 GPU 用例。

修复后的本地 Windows Clang Debug 全量编译与相关 18/18 测试通过；
MSVC Release 全量编译通过，保持警告视为错误。新候选远端矩阵仍待执行。
