## 已确认发布内容

- `gneiss_engine` 是完整运行库，CMake target 为 `gneiss::engine`。
- `gneiss_runtime` 是按工程根和 `startup_scene` 启动的实验性游戏运行宿主。
- `gneiss_editor` 通过独立 Runtime 进程提供保存并运行、停止、状态和输出反馈。
- 安装树包含 Runtime、Engine、所需 Granit 动态库及完整 Editor Demo 工程。
- Runtime 宿主协议、命令行和 Editor 运行协议在 0.11.0 仍为 Experimental。
- C/C++ 公共接口和持久格式不因 Engine/Runtime 命名调整而改变。
