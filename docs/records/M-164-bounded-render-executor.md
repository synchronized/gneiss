# M-164：有界渲染任务队列

## 结果

新增内部同步与线程渲染执行器。线程执行器由单个常驻工作线程串行消费两类任务：Frame 携带自有
帧包并允许在执行前被更新帧替换，Command 携带自有回调且不可丢弃。两类任务共享单调序列号，
完成结果进入各自有锁回执队列。

Frame 数量达到配置上限时，最旧的未执行 Frame 以 `not_ready` 和 `dropped` 回执结束；Command
不会替换任何任务，总队列达到固定余量后返回 `not_ready`。执行器提供队列高水位、累计替换帧数、
排空、停止、Join、运行状态及重复关闭语义。

## 验证

- 同步执行器覆盖帧包传递和执行结果。
- 线程测试确定性阻塞首帧，验证中间帧被替换、最新帧执行、序列唯一及三个回执完整。
- Command 测试覆盖执行、进度、完成回执和排空。
- 关闭测试覆盖正常停止及重复停止。

## 已知边界

- 当前执行器尚未接管 Granit Render Service；M-165 完成真实 GPU 所有权迁移。
- 进度仅保存在最终回执；M-166 增加运行中进度快照和 Engine 查询入口。
