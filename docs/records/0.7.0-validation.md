# 0.7.0 编辑器基础验收记录

## 结论

2026-08-28 已在 Windows 完成 Editor Foundation 的功能、交互与构建矩阵验收。Project Manager、
工程加载、场景层级、独立编辑器相机、反射属性编辑、原子保存、最近工程、新建工程以及 Lantern
Gallery 工程均形成闭环。Linux 图形闭环尚未执行，因此本记录对应发布候选，不代表 0.7.0 已满足
全部跨平台发布条件。

## 交互验收

- 无参数启动 Project Manager，窗口、主题、Inter 字体和目录选择入口正常显示。
- 可通过工程根打开 `editor_demo` 与构建后的 `lantern_gallery`，选择窗口销毁后再创建正式 Editor。
- 场景树按父子层级展示节点，选择行高度、文字对比度和折叠箭头抗锯齿正常。
- Scene View 可显示现有 World 渲染结果，并支持移动、环视、滚轮推进和选择聚焦。
- Inspector 可通过反射元数据编辑 Transform 与 Camera，修改后显示脏状态并可显式保存。
- ImGui Demo 窗口用于核对常用控件、半透明混合、字体和主题状态。
- Lantern Gallery 可作为独立工程进入 Editor，加载构建期导入的 Mesh、Material 与 Texture。

属性失败原子性、未知字段保留、保存失败不覆盖、最近工程去重/失效过滤、新建工程重复目标拒绝及
临时目录组装由自动化测试覆盖。

## Windows 构建矩阵

| 配置 | 结果 | 测试 |
| --- | --- | ---: |
| Clang Shared Debug + Granit + Editor | 通过 | 55/55 |
| Clang Static Debug | 通过 | 43/43 |

Clang Static 的 `gneiss.installed_consumer` 同时验证安装后的 C11、C++20 和属性检查 Consumer。
Visual Studio 首轮发现 UI Draw List 测试存在 `size_t` 到 `uint32_t` 隐式转换警告；改为显式转换后
重新构建及 55 项测试全部通过。所有配置保持警告视为错误。
