# M-295：作者层级树与延后执行的拖拽请求

日期：2026-10-06。

## 变更

作者与 Prefab 层级树绘制归 `gneiss_editor_ui`，只读取节点快照。选择、上下文菜单及拖拽返回拥有
身份的请求，Apps 在完整树绘制结束后处理。

原改父节点操作在递归绘制中刷新 Session 节点数组，可能使仍在遍历的父级迭代器和引用失效。
现在改父节点和撤销记录均在绘制结束后执行；请求复制源/目标 UUID，根级移动使用空父身份。
菜单对话框与宿主进程忙碌条件仍在 Apps 适配，Prefab 只读显示语义不变。

## 验证

- 共享完整构建、静态 Editor/层级树/Session 目标构建通过。
- 共享专项 6/6 通过，7.12 秒；静态专项 4/4 通过，2.96 秒。
- 无原生窗口的真实 ImGui 拖拽测试覆盖节点选择、拖到另一节点、绘制期间父关系不变，以及
  源记录字符串清空后请求仍拥有正确 UUID。
- clang-tidy 检查新增面板及测试，修正函数复杂度和初始化格式；保留原 ImGui 有符号 flags 提示，
  未改变第三方 flags 语义或降低检查等级。

Gizmo 与宿主编排收口、最终平台矩阵和发布仍待完成。
