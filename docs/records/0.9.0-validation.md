# 0.9.0 场景创作工作流验收记录

## 结论

2026-08-28 已在 `feat/ver009-scene-authoring` 完成本地 Windows 验收。Editor 已形成“创建或打开场景、
编辑层级与首批组件、操作 Transform、撤销重做、保存并重新打开”的场景创作闭环。用户完成的人工
检查覆盖 Project Manager、场景显示、世界网格、Transform Gizmo 和 Inspector 交互；其余确定性行为
由自动测试和构建矩阵覆盖。远端 Linux/Windows 手动矩阵尚未触发，因此当前结论为本地可评审。

## 自动化闭环

- Scene Instance 测试覆盖节点创建、重命名、重挂接、子树复制、删除、恢复及失败原子性。
- Editor 测试覆盖工程、保存、属性、命令历史、Gizmo 数学、XYZ 欧拉角转换和资产工作流。
- Editor、Project Manager、Temple、Lantern Gallery、Granit 平台及启动诊断 smoke 均通过。
- Lantern Gallery 工作流覆盖导入、场景节点创建、Undo/Redo、保存和重新加载。
- 静态安装测试覆盖 C11、C++20 和属性检查 Consumer。
