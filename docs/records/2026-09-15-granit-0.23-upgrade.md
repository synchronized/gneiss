# Granit 0.23.0 接入验收

## 变更

Gneiss 在 0.35.0 特性分支将 Granit 默认提交锁定到 v0.23.0 的
`496a298ce9e94cb616790df1ddd95e051cea7cb8`，PACKAGE 与安装 Consumer 同步要求 0.23。
旧默认缓存自动迁移，显式版本覆盖继续保留。

- Surface 改用统一描述构造器。
- PBR 改为校验和嵌入标准 `.grshlib`，Material 借用同一 Renderer 的 Shader Library；释放顺序为
  Pipeline/Material、Library、归档字节。公共 Gneiss ABI 不变。
- Texture Manifest、合并负载、摘要和内容 ID 改由 AssetTools Texture Builder 生成；BC7 编码、
  变体优先级和 `.gneiss-texture` 外层封装仍归 Gneiss。纹理处理器版本从 3 提升到 4，使旧缓存失效。
- 工具和相关测试依赖 AssetTools，Runtime 不链接它。PACKAGE 下复制离线工具所需 DLL；FETCH
  完整 SDK 安装测试补齐上游组件要求的 CLI 构建。
- 安装资产检查切换到 Shader Library。安装测试捕获工具中文输出时显式指定 UTF-8，避免 Windows
  本机代码页使已有成功断言误判。

## 已执行验证

环境：Windows，Clang 23.1.1，Debug，严格编译警告，Vulkan。

- Shared 完整构建通过。140 项测试首轮 136 项通过；补齐 CLI、修正输出解码后，安装 Runtime 与
  Stable Runtime Consumer 通过。Runtime Process 和 Lantern Runtime 工作流单独复测通过。
- Static 完整构建通过，138 项测试全部通过，包含安装 Runtime、Stable Runtime Consumer、公共头
  编译与核心 API 测试。
- Shared/Static 安装前缀分别构建独立 C11、C++20 和属性检查 Consumer，各 3 项全部通过。
- PACKAGE 模式通过已安装 Granit 0.23 AssetTools 构建 `gneiss_assetc`，运行 glTF inspect 通过。
- PBR 归档测试覆盖内嵌/文件内容一致、重置、文件缺失、截断、损坏和失败后状态清空；保留原顶点
  布局契约验证。Runtime Texture Builder 的确定性与非法 Mip 测试通过。
- 修改源码按 clang-format 排版；对 PBR 归档与纹理构建运行 clang-tidy，修复诊断字符串在 noexcept
  边界外分配的问题。剩余 3 条 signed-bitwise 提示来自标准文件打开模式与上游 Texture Usage 宏，
  没有关闭检查或修改第三方代码。
