# M-295：Reflection 内部注册契约与 C 适配

日期：2026-10-05。0.45 阶段结果，不代表完整版本验收完成。

## 改动

Reflection 的 12 个 C 入口移至 `src/api/c/reflection_api.cpp`，负责空指针、结构大小、数组范围表达、
旧布局检查与异常隔离。内部 `type_registry.hpp` 使用 `type_definition`、`field_definition` 的
`string_view` / `span` 输入，按语义检查名称、重复字段与属性能力；注册时继续复制名称和字段。
World 内建反射直接使用此契约，不再调用 Reflection 的公共 C 入口。

注册表仍只有一个。解析得到的私有 `registry_ref` 仅保护当前操作对象；C 句柄销毁后立刻失效，
不因内部短期引用仍存活而重新有效。私有 C++ 头不安装，导出只供同版本宿主与实现测试使用。
冻结后的 C 元数据视图缓存和 C 属性回调协议保留，用于稳定借用指针及互操作，不另建属性运行时。

内部名称长度与字段数量限制在公开查询结构可表达的范围；C ABI 原有输入宽度、错误优先级及
输出初始化规则保持不变。回调意外异常继续转为 INTERNAL；新适配入口也统一捕获分配及其他异常。

边界检查新增 Reflection 源码范围及反例，拒绝内部重新定义 C 导出、依赖外部 RAII 或绕回公共
Registry C 入口。

## 验证

共享库构建及 17/17 专项通过（8.02 秒），覆盖反射/属性访问、内建组件、Editor/Runtime 属性链路、
旧 ABI、安装消费者和边界反例。新增混合入口测试覆盖单一注册表、名称复制、异常回调、跨线程只读
查询、旧 generation 和销毁后的句柄失效。静态库全量构建及相同 17/17 专项通过（10.30 秒）；最终边界正反例与清单一致性 3/3 通过。

新适配与新测试的静态检查无告警；内部实现仅余原有初始化列表尾逗号风格建议。
本轮未运行 Vulkan validation、真实大场景或远端平台矩阵，未改变渲染行为。
