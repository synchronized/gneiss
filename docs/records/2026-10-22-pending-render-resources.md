# 首次渲染资源未就绪接入记录

日期：2026-10-22。对应 [实施计划](../plans/PLAN-051-progressive-render-assets.md) S1。

## 已实施

- 复用资源服务 RID 表：空内容槽位表示合法预留，填充后保持 RID；未新增状态容器。
- 内部 Mesh/纹理查询区分 CPU 内容已就绪、合法未就绪、无效句柄。CPU 就绪不代表 GPU 上传完成。
- 帧快照保留捕获时的空内容状态；后续填充不改变旧帧。销毁、跨服务和类型错误仍报错。
- Granit 后端跳过未就绪 Mesh；材质可引用预留纹理，采用对应槽位的默认纹理。
- 材质镜像记录实际纹理绑定，依赖就绪后重建绑定；预备材质也仅在绑定匹配时复用。
- UI 未加入纹理占位策略，材质本身也尚无预留入口。公共 C ABI 未改变。

## 验证

帧快照测试覆盖预留、空输出参数、取消、类型/跨服务错误、稳定 RID 填充、旧快照隔离、
销毁后失效、重复销毁、迟到替换拒绝及最终回收。

- Windows Clang Debug 全量构建通过，保留警告视为错误配置。
- 格式检查及 `git diff --check` 通过。
- 对帧快照实现执行 clang-tidy，仍有原有单行分支及统计表达式括号可读性告警；
  未禁用检查，也不将其描述为零告警。
- 完整 CTest 201/201 通过，耗时 183.44 秒，包括资产像素与安装消费者回归。

未验证其他平台或后端，未执行新的性能对比；测试总耗时不是加载性能基线。

## 限制与后续

本批是底层接入，场景加载器尚未分配预留 RID，不能据此宣称已实现端到端场景渐进显示。
新增默认纹理到真实纹理的切换尚需专门的 GPU 像素断言；已有像素测试用于回归既有加载流程。
下一步接入实际加载方的预留、成功填充和失败取消，再验证首次延迟的画面变化。
Mesh 异步上传、普通路径版本采用协议收缩、历史语义拆分和性能基线仍按计划继续。
