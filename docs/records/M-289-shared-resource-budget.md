# M-289：Application 共享资源预算验证

日期：2026-09-30。范围：0.44 开发分支的共享资源准入，不代表版本发布验收完成。

## 实现

在渲染资源服务中按共享对象身份统计逻辑容量与 CPU 数据；已销毁 RID 或被替换对象仍被帧、缓存
持有时继续计费，最后一个强引用消失后退还。同一候选对象发布不增加占用。
场景下一批准备取候选额度与 Application 剩余额度的较小值，注册新资源再次检查。
超预算注册返回内存不足，替换失败保持原资源。

默认上限、线程约束和统计边界以 [ADR-052](../decisions/ADR-052-texture-residency-and-budgets.md)
为准；之前的候选分项和上传预留验证见 [预算分项记录](M-289-budget-accounting.md)。

## 验证

新增低预算测试覆盖两对象占满额度、共享发布去重、旧帧延迟释放、超限创建与替换保留旧对象、
释放后重试，以及替换后旧快照继续计费。

Windows Clang Debug 共享库相关 10 项测试通过，包含资源服务、资产加载、场景加载、纹理服务、
文件读取与版本检查、Prefab 和真实 GPU 像素测试。新增测试首次因遗漏测试纹理行跨度失败，
修正测试输入后通过。

Windows Clang Debug 静态库资源服务、场景加载、纹理服务与真实 GPU 像素测试 4/4 通过
（13.77 秒），Vulkan 校验日志未出现 Validation Error 或 VUID。测试窗口保持隐藏。
最终参数命名调整后，共享库资源服务测试亦再次通过。

静态检查执行于修改的两个实现文件；修复新增参数命名告警，原有复杂度、初始化列表与条件表达式
等告警仍存在，未将其描述为全量静态检查通过。差异格式与空白检查通过。

## 未验证与剩余范围

- 全部临时分配之前的统一预留、后台恢复暂存预算和 Editor 分项反馈尚未完成。
- 未实测完整 4K Sponza 的 CPU 峰值、驱动显存与连续场景切换；当前数字不能用于声称这些指标达标。
- 未验证跨平台矩阵；本轮不涉及公共 ABI 或 Granit 改动。
