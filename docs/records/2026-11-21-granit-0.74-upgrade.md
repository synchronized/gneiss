# Granit 0.74.0 升级验收

## 基线与范围

2026-11-21，Gneiss 从 Granit 0.73.2 升级到远端标签 v0.74.0。
本轮只修改 Gneiss；没有修改 Granit 仓库或执行其发布操作。

- 新锁定：`ae4d499c68d75d25fc49840c4b797d2a42a783a7`。
- 原锁定：`8eb744482de1dbd380393e0d8a28ae5339e51fb2`。
- codeload 归档 SHA-256：`3633605cb1292be329a1fb5f05ae35170738d0351e4d40c01d1545a5fd7be93f`。
- FETCH 默认值、旧默认缓存迁移、PACKAGE 最低版本、源码版本断言与构建指南同步更新。

## 上游能力核对

0.74.0 已有逐 View 的 object_id_view、R32_UINT，以及 read_texture_view 异步区域回读。
标准 Opaque/MASK 路径写入 ID；BLEND、UI、Debug 不写入；ID 为 0 的物体仍参与深度遮挡。
单视图启用 ID 附件也应使用 render_desc.outputs，不能向旧单视图简写传入不存在的字段。
限制包括 MSAA ID resolve、自定义 record 自动注入与透明拾取策略。
完整需求对照见 [UPSTREAM-052](../plans/UPSTREAM-052-granit-object-picking.md)。

## 本地验证

Windows Clang Debug 共享与静态构建均通过；两种配置下以下 8 项定向测试全部通过，
分别耗时 39.25 秒和 32.70 秒。

- granit_version_cache：新默认值、旧默认缓存迁移与自定义覆盖。
- render_executor、render_scene：队列及持久场景回归。
- asset-pixel：材质、纹理、阴影与资产就绪后的像素回归。
- scene-viewer-dual：双视图独立相机/尺寸与合成回读。
- render-texture-uploads、render-pressure：异步上传、背压重试与资源关闭。
- render-capture-failure：真实后端错误到 Application 的关闭收尾及截图终态。

共享配置已确认自动从旧默认提交迁移至新锁定提交。
共享 DLL 已确认导出 granit_readback_batch_read_texture_view。
后端源码格式检查、文档相对链接检查和 git diff --check 通过。
