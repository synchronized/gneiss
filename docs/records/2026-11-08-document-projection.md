# 2026-11-08：文档历史与投影迁移首批

实施范围见 [PLAN-106](../plans/PLAN-106-document-history-projection.md)，决策见 ADR-111。

- 新增独立 project_scene_document 入口，接管恢复版本的运行更新。
- 已同步且只有有效 Transform 差异时原地更新；先检查全部目标和变换基线，再应用差异。
  组件、资源、名称或结构变化暂时完整重建。失败通过既有 projection_status 报告。
- 新增连续合并编辑及撤销重做后目标、无关对象 node/entity 身份不变的回归断言。
- 默认 Windows Clang Debug 构建通过，39 项相关 CPU 回归全部通过，git diff --check 通过。
- 验证期间误启动重叠构建导致静态库文件锁失败；等待原构建退出后串行重跑默认构建通过。
  未修改检查等级。未运行 GPU 大场景、远端 CI 或跨平台矩阵，未推送。
- 局部历史、独立编辑会话、完整结构投影尚未落地；版本历史仍是当前实现，不宣称计划完成。

## 局部对象历史接入

- document_patch 只记录变化对象、来源和资源项；应用先校验旧值及顺序，再验证独立候选。
- 外部编辑命令改为 document_patch_command，保存轻量 revision 和局部差异；执行准备期间
  暂借旧版本，完成后释放。保存点仍按版本身份比较，跨文档和旧基线拒绝。
- 连续拖动合并为每个变化项最初旧值/最终新值，不累积中间版本。
- 当前仍以变化对象为粒度，属性细分、结构投影和编辑会话拆分待继续；未声明计划完成。
- 默认 Windows Clang Debug 构建通过；合并实现后 40 项定向回归全部通过，包含保存、
  历史、组件、Prefab 和变换操作。纯文档测试覆盖正反应用、旧值冲突、顺序和合并。
- git diff --check 通过，未运行远端 CI、GPU 大场景或跨平台矩阵。

## 增量编辑与运行状态

- 存活对象历史细分为领域字段；普通对象增删、名称、父关系、组件及变换按对象投影。
- 删除恢复分配新实体，无关实体保持；Prefab 成员集合变化和资源身份变化仍可回退重建。
- 组件适配器新增 update，验证正常编辑及撤销重做保留运行状态，删除才释放生命周期。
- 修复项目模板遗留组件包装格式，并将覆盖记录测试改为读取文档；面板恢复测试不再依赖末尾控件。
- 默认 Windows Clang Debug 编译通过，扩大后的 77 项相关回归全部通过；未运行远端 CI。

## 文档与会话拆分

- 原协调对象迁移为 scene_edit_session，所有编辑器调用方同步迁移。
- scene_document 只持有不可变内容、版本身份和保存点，删除旧完整版本撤销栈。
- scene_projection 独立维护同步回执，不保活旧文档；过期回执拒绝。
- 纯文档测试覆盖非法结构、旧版本/跨文档拒绝、异步保存点、资源释放；历史合并等由真实局部历史回归覆盖。
- 默认构建通过，含 Core 边界的 79 项相关回归全部通过。

## 普通编辑统一投影

- 普通编辑与撤销共用投影入口，删除各操作直接写 World 的重复路径。
- 新增、删除完整 Prefab 实例只更新对应子树；资源绑定按文档身份恢复。
- 同步失败后，下一次合法编辑尝试恢复投影；同步成功才清除失败状态。
- 默认编译及 79 项相关回归通过；已有 Prefab 内部结构变化仍有整场景回退，计划继续实施。

## 历史准备前移

- 接受每个文档候选前生成局部差异并准备历史存储，准备失败不接受该候选。
- 多步命令按正向/反向顺序恢复；多段差异不尝试仅合并第一段。
- Gizmo 预览结束先恢复基线，再使用统一编辑入口提交最终值，删除事后补历史接口。
- 默认编译通过；准备入口调整后 79 项回归通过，Gizmo 收尾调整后 6 项定向回归通过。
- 多步命令仍逐候选提交，整体单次提交及精细属性差异继续实施。
