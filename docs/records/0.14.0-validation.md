# 0.14.0 Editor UI 工作区验收记录

## 当前结论

0.14.0 候选已完成 Windows VS2022 的 Debug/Release、Shared/Static 四象限本地自动化验收，以及
Linux GCC/Clang、Shared/Static、Sanitizer 和 Granit 运行时矩阵。Docking、确定性默认工作区、按
工程布局持久化、面板可见性、v1 布局迁移和失败回退均已形成自动化闭环。最终人工视觉检查及依赖
Granit 内容缩放接口的动态 DPI 仍未完成，因此本记录当前不构成版本发布结论。

## 已知边界

- 当前 ImGui `DisplayFramebufferScale` 固定为 1；Gneiss 不直接调用 Win32/X11/Wayland API 猜测
  DPI，避免在 Editor 层建立第二套平台状态。
- Static Release 代表性验证显式启用了 `GNEISS_ENABLE_GRANIT_PLATFORM`、`GNEISS_BUILD_EDITOR`
  和 `GNEISS_BUILD_RUNTIME`；这些能力按项目设计默认不参与普通库构建。
- 构建期间 fastgltf 第三方目标报告 MSVC 优化选项覆盖提示，不属于 Gneiss 自有目标，也未降低
  Gneiss 的警告即错误策略。
