## 人工验收

- 已检查 1280×720 默认工作区、场景显示、Console、面板布局和主题可读性。
- 已验证 Runtime 启停和返回 Editor；失焦后键盘与鼠标状态会按权威快照复位。
- 已修复 DockSpace 背景遮挡 3D 场景、中文缺字和 Clang 测试夹具严格警告。

## 已知边界

- 当前 ImGui `DisplayFramebufferScale` 固定为 1；Gneiss 不直接调用 Win32/X11/Wayland API 猜测
  DPI，避免在 Editor 层建立第二套平台状态。动态 DPI 等待 Granit 内容缩放接口后另行接入。
- 当前 Inter 与 Noto Sans SC 组合只解决现有 Editor 中英文可读性；字体切换、多语言、复杂字形回退
  和未来自研 GUI 的字体体系不属于 0.14.0。
- Static Release 代表性验证显式启用了 `GNEISS_ENABLE_GRANIT_PLATFORM`、`GNEISS_BUILD_EDITOR`
  和 `GNEISS_BUILD_RUNTIME`；这些能力按项目设计默认不参与普通库构建。
- 构建期间 fastgltf 第三方目标报告 MSVC 优化选项覆盖提示，不属于 Gneiss 自有目标，也未降低
  Gneiss 的警告即错误策略。
