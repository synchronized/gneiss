# M-280～282：PBR 资源、切线与纹理构建阶段验收

2026-09-29，0.43 开发阶段记录，未发布。基线为 Granit v0.39.0；
设计见 [ADR-051](../decisions/ADR-051-pbr-material-dependencies.md)，
当前格式见 [Render 资产格式](../reference/render-asset-formats.md)。

## 已实现

- Material v4、C 描述扩展及内部五槽依赖；旧布局保持兼容，资源与帧租约保留全部依赖。
- CPU 准备、上传候选、同步获取和异步重载贯通五槽，任一依赖失败保留旧材质与旧帧。
- Mesh Binary v2 和公共可选切线；作者切线正交化并保留 W，缺失时通过固定版本 MikkTSpace
  生成，镜像 UV 接缝拆点。MikkTSpace 仅由工具私有依赖，不进入普通公共 API。
- glTF 五槽和因子导入、独立颜色/数据/法线派生路径；实际无 sRGB 用途的数据图不重复生成颜色副本。
- 线性光域颜色 Mip、向量法线 Mip、奇数尺寸面积过滤；Cook 处理器版本升为 5，用途影响缓存身份。
- 修复场景采样器 `max_lod=0` 及 Texture View 默认仅一层的组合缺陷；原先上传完整 Mip 不等于采样到它。
- 未支持的 MASK/BLEND、双面、顶点色、UV1、非默认采样器及非 PNG 输入明确诊断，不静默降级。
- 导入器身份升级为 2，旧记录显示 stale，源哈希相同也不能跳过版本迁移；失败保留旧产物。

## 阶段验证与发现

- 升级基线的 158 项 Debug 测试通过；五槽资源阶段 159 项通过，详见
  [M-279](M-279-granit-0.39-upgrade.md)。
- 切线/Mip 初次针对性测试 20/20 通过，覆盖 Lantern 导入、Cook、Editor 与 Runtime。
- Mip GPU 夹具使用基础级蓝色、其余级红色及高密度 UV；先复现 View 层数限制，修复后通过。
- 新增导入同图五用途、二进制新旧版、无效切线、镜像手性、缓存全命中和用途变更失效测试。
  用途变为已有相同线性数据时允许重用图像缓存，仍使描述与材质依赖键失效。
- 全量复测初次为 159/161：一项新增断言错误（复用缓存与禁止覆盖输出目录的规则未计入），
  一项 Lantern Cook 在并行静态编译时超过原 90 秒门槛。修正夹具并消除多余图像变体；未放宽超时。
- 已运行新增源文件 clang-tidy，修复复杂度、括号与大括号提示。仍有第三方 C 回调签名及相邻坐标参数
  等提示，不声称全仓库静态检查零告警；未降低检查等级。

Windows Clang Debug 全量复测 **161/161 通过，157.41 秒**；随后增加导入器版本迁移检查，
对应 SDK、索引、Asset Browser、重导入队列 **4/4 通过**。格式检查和 `git diff --check` 通过。
日志为本地 `build/0.43-pbr-debug-verified.log` 与 `build/0.43-import-version-tests.log`。
静态库验证仍在进行；远端发布矩阵尚未运行，不能用阶段通过代替版本发布验收。

修复后针对性 3/3 通过：Cook 用途/缓存、实际 Lantern Cook 与 Runtime、GPU 材质像素。
Lantern Cook 为 59.05 秒，低于原 90 秒门槛；新像素检查确认 MR 的 G/B、AO 的 R 及法线方向
分别影响预期结果，MR 的 R 与 AO 的 G/B 不参与计算，同时使用 Mesh Binary v2 的实际切线。

## 真实资产与发布阻塞

固定 Sponza 输入身份与 0.42 相同，旧基线未覆盖。源资产含 25 张基础色、24 张 MR、23 张法线图，
合计 72 张被材质引用的不同图片；不再把 0.42 的 25 张基础色驻留量当作本版完整负载。
当前新导入实际返回双面材质不支持诊断；另有 1 个 BLEND 材质与 59 个带 COLOR_0 的图元。
没有通过删除这些对象/属性来制造新的“保真”基线。

完整 Sponza 重导入、三次日常/完整性能采样、新增贴图驻留预算、负缩放 GPU 图像及完整材质状态
尚未验收。上游负缩放 TBN 是 P0 缺口，其他契约与建议最小 PR 见
[U43-01～05](../plans/UPSTREAM-043-granit-pbr.md)。按仓库分工，由用户向 Granit 提交；
Gneiss 分支保持开发状态，不合并或创建 0.43 发布标签。
