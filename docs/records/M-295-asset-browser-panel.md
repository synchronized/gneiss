# M-295：资产面板与宿主操作分离

日期：2026-10-06。

## 变更

资产面板绘制归 `gneiss_editor_ui`，只借用资产模型和单帧显示值；进程状态、协议枚举、文件对话框、
监听器与导入服务操作留在 Apps 适配。类型判断及默认材质配对归资产模型。
监听、导入、场景加载和 Runtime 更新分别使用独立绘制函数，避免一个函数承担全部分支。

面板返回拥有资产身份的操作请求，宿主在绘制结束后执行。此时才允许改变服务状态和文本，
防止按钮操作使当前绘制借用的字符串或条目失效；显示值不构成第二套异步运行时状态。
UI 仅在资产功能启用时链接私有资产目标，不改变 Engine 安装接口。

## 验证

- 共享完整构建和静态 Editor/资产工作流/面板目标构建通过。
- 共享编辑器及边界测试 45/45 通过，46.76 秒；静态专项 5/5 通过，6.78 秒。
- 新增无原生窗口的真实 ImGui 鼠标输入测试，验证补扫请求、点击时资产身份的复制、无操作帧、
  材质配对及失败/预算/冲突状态绘制。
- clang-tidy 检查新面板与测试，无新增告警；边界检查确认 UI 不反向包含 Apps 协议。

作者层级树、Gizmo 与宿主编排仍待收口，最终平台矩阵和发布尚未完成。
