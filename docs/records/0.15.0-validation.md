# 0.15.0 Editor–Runtime 双向控制通道验收记录

## 结论

0.15.0 已完成版本化本机 IPC、Runtime 控制状态机、Editor Play 工作流、结构化日志通道、Lantern
Gallery 可观察运行逻辑、重复会话与跨平台验证。Play、Pause、Resume 和 Stop 均作用于独立 Runtime
的真实游戏逻辑，不以 Editor 按钮状态代替运行结果。

## 已知边界

- IPC 当前仅使用回环 TCP 和私有 JSON 协议，不承诺 Stable ABI、远程调试或公网安全边界。
- Static 配置不构建动态游戏模块；它验证静态 Engine 下的宿主、IPC 与进程边界。
- Runtime 渲染表面仍独立于 Editor；场景同步、属性同步和游戏模块热重载不属于 0.15.0。
- 当前 ImGui 体验不作为本版本阻塞项，后续 GUI 方向单独规划。
