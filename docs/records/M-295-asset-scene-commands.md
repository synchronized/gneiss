# M-295：资产面板的作者编辑命令

日期：2026-10-06。

## 变更

添加 Mesh、放置 Prefab、替换 Mesh Renderer 资源的事务归入 `gneiss_editor_session`。
Apps 只传入名称、身份及 URI；Mesh/Material 使用带字段名的借用配对，命令复制所需字符串。
命令与撤销输入在首次写入前构造，统一使用已有命令历史执行和回滚，不增加另一套状态管理器。

历史记录失败时撤回创建或替换并恢复原脏状态，修正原 Prefab 添加路径记录失败后仍标脏的问题。
Undo/Redo 继续使用 UUID，Prefab 的撤销快照仍捕获撤销时的实例状态。

  的回滚与脏状态，包含已有资产工作流及边界正反例。
