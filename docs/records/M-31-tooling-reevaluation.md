# M-31 工具能力重新评估记录

- 日期：2026-08-27
- 结论：0.4.0 暂不增加诊断 Overlay、字体或编辑器宿主

## 判断依据

- Texture、Material 和 GPU 镜像已经具有可测试的错误返回与同步诊断路径，版本验收不依赖 UI。
- 只读 Overlay 仍需要字体、布局、输入焦点、绘制顺序和跨平台窗口生命周期，范围明显超过纹理闭环。
- 把临时 UI 塞入 Render Service 会破坏工具层与运行时服务边界，也无法自然演进为正式编辑器。

## 后续方向

保留现有诊断回调和测试作为 0.4.0 验收手段。正式工具能力应在后续版本先定义 Tool Host、字体与
UI 后端边界，再选择即时模式 UI 或自有方案；编辑器、反射和序列化继续由独立路线图规划。
