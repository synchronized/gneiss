# Granit 0.67.0 升级验收

## 范围

2026-10-19，按用户要求更新 Granit。远端 `main` 查询结果为
`c9803195cc81d2d1cef55e47f5bcff1c42884ccd`，上游工程版本为 0.67.0。
默认依赖从 `369adc7ebc9e202056c5d583bfd8d65243de6a4d` 更新至该完整提交。
不修改 Granit 源码，不接入 CAORS，不启用此次上游新增的渲染功能。

## 修改

- 更新 FETCH 默认提交及默认缓存迁移测试；继续保留用户显式锁定版本和关闭自动升级的行为。
- PACKAGE 查找与安装后的 `find_dependency` 同步请求 0.67.0。
  新版 Granit 的包兼容规则拒绝原先的 0.44.0 请求，仅改 FETCH 提交会导致安装消费者配置失败。
- 更新[构建指南](../guides/building.md)中的依赖要求。
- PBR 资源内容哈希发生变化，构建已重新生成内嵌资源；Gneiss 源码接口无需额外适配。

## 验证环境与结果

Windows、Clang Debug，使用现有共享和静态 preset，警告检查保持启用。
静态构建缓存通过 `FETCHCONTENT_SOURCE_DIR_GNEISS_GRANIT` 复用共享构建的 Granit 源码目录；
已核对实际 `granit_SOURCE_DIR` 对应提交为本次锁定提交，不能以静态目录下遗留的 `_deps` 副本判断版本。

- `cmake --preset windows-clang-debug` 及完整构建通过。
- `gneiss.granit_version_cache` 通过，包含默认升级与自定义锁定保留。
- 共享构建完整 CTest 首轮 202/205 通过；两项安装测试因包版本请求失败，修复后分别复测通过。
- `gneiss.editor.lantern-runtime-workflow` 首轮在后台静态编译并行运行时触发场景加载的 5 秒等待超时；
  编译结束后单独复测通过（整个用例 6.40 秒）。未修改超时或跳过断言；不能据此宣称已消除负载相关抖动。
- `cmake --preset windows-clang-static-debug` 及完整构建通过。
- 静态版相关测试 45/45 通过，覆盖渲染、PBR、纹理、资产加载、Editor 冒烟、ABI consumer 和安装消费者。
