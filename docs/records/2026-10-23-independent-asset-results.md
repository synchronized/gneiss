# 资源逐项失败处理与 IPC 回执

日期：2026-10-23。

## 已实施

普通加载请求独立准备各请求项，某项读取、解析或上传失败后继续处理其余项。
上传按单资源回执应用；成功项在后续失败和取消时保留。完成值携带成功资源引用及逐项结果。
请求总资产数与 CPU 字节预算仍受约束；失败的解析临时数据不再阻止其他 CPU 文档共享。
材质及其依赖的 CPU 准备仍作为一组，依赖独立就绪还未实现。

Asset IPC 域更新为 4，增加逐项 URI、类型、结果码和生效标记；旧域版本通过协商拒绝。
Runtime 汇总失败时保留成功项计数，Editor 可展开资源结果；取消提示明确已生效内容保留。
修订号仍用于请求去重，不是资源内容版本。

## 验证及限制

Windows Clang Debug 构建及完整回归 201/201 通过（201.93 秒）。最后上传循环简化后，
资源服务、IPC 编解码及 Runtime 回执定向测试通过。GPU 像素与两种执行模式在完整回归内。
静态检查无错误，报告复杂度及初始化风格告警；后续上传结构收缩继续处理相关复杂度。
未验证其他平台及静态库矩阵。每次上传一个资源降低失败耦合，但增加小资源命令开销，
最终性能验收仍须按[计划](../plans/PLAN-051-progressive-render-assets.md)执行。
