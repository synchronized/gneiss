# M-296：公共类型、常量与回调映射

日期：2026-10-06。

## 审查结果

在 102 个函数映射之外，补充[类型清单](artifacts/0.45-type-inventory.json)：13 个有类型/宏的公共头
（含版本头模板）、96 个类型（其中 15 个回调签名）、281 个宏。头保护宏不计入，条件编译导出宏去重。

所有权分类区分资源拥有者、借用身份、值结构/联合、标量及回调。纯值直接使用 C 类型或既有 C++ 别名，
常量、位标志、初始化器、结构版本与导出规则继续使用 C 宏；不为计数增加状态或无意义的 RAII 类。
用法与寿命的权威入口为 [C++ SDK 参考](../reference/cpp-sdk.md)，逐模块约束链接原有 Reference。

回调审查覆盖 Application 生命周期/时钟/关闭/诊断/日志、反射 getter/setter、Game Module 查询和生命周期。
确认没有公共异步请求或注销接口，不能承诺自动等待任务、捕获闭包寿命或 DLL 卸载安全。
日志与反射具有异常隔离，其他生命周期回调仍必须自行处理异常，不能统一宣传为任意回调可抛异常。

新增属性测试验证回调异常转为 internal、getter 错误输出清空、Registry 移动后继续使用同一借用上下文，
以及字符串复制、关闭后失效。清单检查同时比对当前头中的类型/宏，拒绝漏项、额外项和空映射。
