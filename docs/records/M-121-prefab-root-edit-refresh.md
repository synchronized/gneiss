# M-121 Prefab 根级编辑与刷新事务实施记录

## 结论

M-121 已完成 Prefab 实例根的编辑与命令历史闭环。实例支持重命名、Transform、复制、删除和显式
刷新；来源节点继续只读。放置及根级修改进入现有 Undo/Redo、脏状态和场景序列化流程。

## 刷新事务

- 资源缓存提供成功后替换的强制重载；加载失败保留原缓存项。
- 刷新先读取新来源并创建完整替代投影，成功后才销毁旧投影。
- 每次成功刷新返回事务令牌，令牌只持有另一个版本的解析资产租约，不保留隐藏 Runtime 节点。
- Undo/Redo 通过令牌交替重建新旧来源版本，并在每次切换后返回新的实例根 ID。
- Editor 命令离开历史时释放令牌；场景卸载负责兜底释放。
