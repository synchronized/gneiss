# M-236：0.35.0 发布验收

## 范围

0.35.0 发布候选为 `db88c3deeae6792c13e850032f9901c0265e5dfb`，Granit 固定为 0.29.1
（`462d19b88678ea4048bfdeddbee1ea37955527b6`）。PNG Cook、BC7/RGBA8 运行变体、设备选择、
批次上传、诊断及编辑器修复汇总于 [CHANGELOG](../../CHANGELOG.md)。

发布沿用源码标签和 GitHub Release，不附带预编译 SDK。相关变更集中于
[PR #50](https://github.com/synchronized/gneiss/pull/50)。

## 验证证据

- Windows 本地 MSVC Shared/Static 完整测试分别 142/142、139/139 通过，Clang 矩阵及受影响
  专项通过；首轮失败、复测及无后端构建修复见[完整记录](2026-09-23-version-035-local-matrix.md)。
- 最终候选本地版本程序输出 `gneiss 0.35.0`，版本与两项 Editor smoke 共 3 项通过。
- [Linux 发布矩阵](https://github.com/synchronized/gneiss/actions/runs/35855733759)：7 个任务成功，
  覆盖 Clang/GCC Core Shared/Static、Granit Shared/Static 无头图形及 GCC Sanitizer。
- [Windows 发布矩阵](https://github.com/synchronized/gneiss/actions/runs/35855738394)：4 个任务成功，
  覆盖 MSVC Runtime Shared/Static 与安装 C/C++ Consumer。托管 Runner 无 Vulkan ICD，
  图形 smoke 由 Linux 矩阵及 Windows 本地验证覆盖。

两套工作流均锁定上述候选；最后的验收记录与状态更新仅修改文档，不重复执行矩阵。
合并后须核对内容与 PR head 一致，再创建 `v0.35.0` 标签和正式 Release。

## 验收范围限制

- 首次上传仍同步提交完整 Mip 链；不宣称实现异步跨帧 Streaming。
- 用户确认拉远后不再卡住或跳动；2400 主循环帧、870 次成功渲染及呈现和两次原生 resize 的
  程序化验证见 [Granit 接入记录](2026-09-23-granit-0.29.1-upgrade.md)。全部 Gizmo 拖动、拾取、
  DPI 和实际鼠标 resize 组合未完整人工验收，不将这些通用编辑器交互描述为本版本已全面验证。
- 本地真实设备选择 BC7；没有真实不支持 BC7 的设备进行回退画面复验。
- Sanitizer 检查 Application/Scene、设备创建失败及图形 smoke；图形 smoke 按既定配置关闭
  驱动泄漏检测，不等同于全部代码与所有驱动均经过泄漏检查。
- 既有静态检查告警未全部清理；Linux、Windows 编译和测试均保留原有严格检查及超时标准。

这些限制随 Release 说明公开，后续通用桌面交互及设备兼容性复验不扩充为 0.35 的新功能范围。
