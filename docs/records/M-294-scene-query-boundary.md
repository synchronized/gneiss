# M-294：Scene 查询结果边界

日期：2026-10-06。

## 变更

Scene 内部查询返回 `scene_node_view` / `prefab_node_view`，用 string_view 表达借用字符串，用 optional
表达相机详情。内部不再消费公共查询结构的尺寸、保留字段或指针/长度输出。

C 适配层按调用方声明的版本写回：V1 只写身份字段，V2 增加资产 URI，V3 增加变换和组件详情。
内部查询按 identity、assets、components 选择详细程度，保持旧版不额外读取组件的行为。
失败时仍写回已确定字段及默认值，不写入调用方版本以外的尾部；应用句柄校验顺序不变。

没有增加缓存或延长对象寿命；查询字符串仍只借用到场景下次修改或销毁。
边界检查增加两类 C 查询结构的负例。CPU 场景候选测试直接消费内部视图。

## 验证

- 共享完整构建通过；Editor、Scene、Prefab、C++ SDK 与边界相关回归 58/58 通过，46.59 秒。
- 条件表达式调整后，静态专项构建与场景、Prefab、候选构建、边界测试 10/10 通过，4.05 秒；共享查询专项 3/3 通过，0.28 秒。
- 新增 V2 尾部变换/相机/组件字段哨兵验证，以及失效句柄清理当前版本字段但保留尾部的测试；原有 V1 用例保留。
- clang-tidy 检查 C 入口，修正本次新增的嵌套条件表达式；既有同类型相邻句柄参数提示保留。

相机设置和子树 UUID 映射输入仍待分离；最终平台矩阵与版本发布未完成。
