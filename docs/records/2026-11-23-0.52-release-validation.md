## 首轮兼容修复

GCC Release 要求消费 write 返回值；致命输出失败直接退出，不递归调用日志。
GCC 对同名类型/成员解析更严格，限定 render::frame_policy 和 render::memory_usage，不修改 API 语义。
Windows 托管 Runner 原先按旧测试名排除图形用例，改按现有 gpu 标签选择无图形设备可执行范围；
图形测试仍在本地与 Linux 完整矩阵执行，不删除测试或降低断言。

Linux Clang/libstdc++ 对拾取嵌套状态的 optional 默认 emplace 判定失败，改为显式构造状态后移入，不改变取消与选择语义。
