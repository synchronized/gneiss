# 0.5.0 版本验收记录

- 本地验收日期：2026-08-27
- 验收分支：`feat/ver005-basic-3d-plan`

## 实施结果

- 建立版本化 Camera、活动 Camera 生命周期、右手视图与 Vulkan 透视投影约定。
- Granit 路径增加 D32 深度附件、深度清除和与绘制顺序无关的 3D 遮挡。
- Mesh v3 增加逐顶点法线，并使用逆转置规则支持非均匀缩放下的基础光照。
- 原创片麻岩神殿升级为真实 3D 场景，支持 `A`/`D` Camera 轨道观察和确定帧 smoke。
- 示例资产与测试 fixture 分别归属各自目录，正式安装包不再携带引擎级通用资产目录。
- 完成 glTF 离线导入边界评估，后续由 TOOL-001 实现独立 `gneiss_assetc`。
