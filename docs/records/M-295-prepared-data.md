# M-295：网格与纹理准备数据归属

日期：2026-10-05。依照 ADR-054 继续分离 CPU 准备数据与渲染发布生命周期。

## 实施结果

- 网格数组及字节计数迁入 `src/engine/asset/mesh_data.hpp`，Render 使用类型别名复用，
  没有第二套网格数组或资源存储。
- `texture_preparation_data.hpp` 保存纹理 CPU 数据及调用方提供的不可变能力快照。
  设备 generation 只是不透明身份值，不包含后端对象、纹理 RID 或上传引用。
- Render 的已发布纹理仍保存上传负载弱引用；同步获取、批次暂存和单纹理暂存统一在发布边界
  移动数组所有权，保持原有资源布局、所选变体、设备身份和可重建来源。
- 准备接口头不再包含 Render 资源类型；增加禁止重新包含的边界反例，以及准备类型不得具有
  上传弱引用的编译期检查。
- 批次纹理测试核对准备与发布后的 manifest、payload 地址相同，继续验证上传引用释放与
  源数据重建。单纹理暂存也检查移动后 payload 地址、设备身份与变体索引。

## 剩余边界

准备实现仍显式包含 Render 资源值头，仅用于材质发布资源预算。下一步应由调用方传入预算契约，
再评估将准备实现归入 Asset；不能为了消除 include 而改成较小的准备结构大小，放宽现有上限。
本轮未改变公共 C/C++ SDK，未修改 Granit。

## 验证结果

- Windows Clang Debug 共享全量构建成功，相关 CTest 11/11 通过（17.89 秒）。
- 静态相关目标构建成功，相同范围 CTest 11/11 通过（19.66 秒），覆盖加载服务、场景加载、
  真实 GPU 像素测试与边界正反例。
- 准备测试 `clang-tidy` 无自有代码告警；修改文档的 346 个相对链接和 `git diff --check` 通过。

未运行远端 Actions、跨平台完整矩阵或外部大型场景；本次不构成 0.45 发布验收。
