# M-139：IPC 协议注册表与统一分发实施记录

## 结果

已建立内部协议域注册表与统一 Dispatcher。注册表拥有域能力名和操作规则副本，处理器上下文仍由
Editor 或 Runtime 组合层拥有；组合层必须保证 Dispatcher 使用期间上下文有效。

每个域声明版本、能力名、负载上限以及各操作允许的消息语义和发送方向。Session 域可在握手前处理；
其他域必须完成握手，并出现在“域 + 版本”的协商结果中。

## 拒绝语义

Dispatcher 在调用业务处理器前依次校验：

- 信封结构、已注册域和域负载预算；
- 握手状态、域协商结果和域版本；
- 域内操作、发送方向和消息语义。

拒绝原因使用强类型结果区分，不改变会话状态。业务处理器失败也保留原始结果码，由后续双端组合层
决定发送协议错误、关闭连接或仅记录诊断。

## 验证

- 覆盖成功注册、重复域、非法描述和重复操作。
- 覆盖握手前业务消息、未协商域和域版本不足。
- 覆盖未知域、未知操作、错误方向、错误消息语义及超限负载。
- 覆盖 Session 握手前分发、处理器成功与处理器失败传播。
