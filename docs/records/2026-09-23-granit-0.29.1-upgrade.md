# Granit 0.29.1 接入验收

## 范围

Gneiss 默认依赖由 Granit 0.28.1 更新至 0.29.1 发布提交
`462d19b88678ea4048bfdeddbee1ea37955527b6`。FETCH 默认值、旧默认缓存迁移测试、PACKAGE
最低版本、安装 Consumer 依赖和父工程编译期版本检查同步更新。

上游包含 `7e20ba2d` 的无阴影投射物修复：仍保留阴影 Pass，空投射物列表时清空持久阴影图，
继续后续场景与 UI 渲染，避免空阴影视图导致持续 `NOT_READY`。
此前故障证据见[远距离缩放冻结排查](2026-09-23-granit-no-shadow-casters.md)。

0.29 同时迁移到包含逻辑名称的 Shader Library schema 2。Gneiss 没有使用已移除的独立
Shader Index 接口；重新配置并构建后，从新依赖资产重新生成内嵌 PBR Shader Library。
旧版动态库和 Shader Library 不能与新版混用；已有构建目录需要重新配置、编译和安装。

## 验证

Windows Clang Debug Shared 与 Static 完整构建通过：

- Shared 完整 CTest 首轮 140/142 通过；安装打包超过 120 秒、Runtime 停止协议启动等待失败。
  编译结束后在原有超时限制下单独复测，两项均通过，分别用时 28.38 秒和 1.45 秒。
- Static 完整 CTest 139/139 通过，用时 60.85 秒。
- 测试包含版本缓存迁移、内嵌 PBR 归档、Runtime/Editor、公共 C/C++ 头文件及安装 Consumer。

日志位于本地 `build/granit-0291-tests.log`、`build/granit-0291-retest.log` 和
`build/granit-0291-static-tests.log`，不纳入版本控制。

## 远距离缩放与 resize 回归

保留 Lantern Gallery 方向光，临时将 Editor smoke 延长为 2400 帧：前 900 帧每帧注入
`dolly=-1`，随后 600 帧停留，最后 900 帧注入 `dolly=1` 拉回。
在第 1100、1300 帧调用 Win32 `SetWindowPos`，两次均返回成功。

渲染线程实际执行 870 帧，管线渲染与交换链呈现全部成功，没有持续 `NOT_READY`。
渲染尺寸依次覆盖 1280×720（401 帧）、1008×729（79 帧）、1264×681（390 帧）；后两者为
调整窗口外框后的客户区尺寸，确认 resize 后仍持续呈现。
日志位于本地 `build/granit-0291-probe-run.log`。

临时自动输入、Win32 resize 和逐帧日志均已撤销，正常 Editor 重新构建通过；Camera、Grid、
Editor smoke 与 Lantern Editor 4 项测试再次通过。这验证了实际原生窗口、渲染与呈现链路，
未做像素读回、真实鼠标滚轮或全部桌面交互的视觉验收。

未修改 Granit 源码，未执行远端写入操作。本轮不重复 MSVC、Linux 或 WebGPU 完整矩阵。
