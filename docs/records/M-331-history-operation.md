# M-331：分帧历史操作基础

用户确认大型结构撤销重做可以显示模态进度，历史保留快照与实际版本租约，不保留完整隐藏实例。
本轮为内部命令增加可选分帧历史事务，普通命令继续使用同步回调。

事务成功完成后才移动游标和当前状态；失败与取消保持原位置。推进期间拒绝新的历史执行、
记录、撤销重做、清空和保存点修改。取消只请求清理，仍须推进至终态；历史销毁前也必须完成
清理。事务负责保证失败时文档回滚，历史容器不替代 World 事务。

Windows Clang Debug 构建通过，editor.command-history 和 editor.asset-edit 测试 2/2 通过。
新增测试覆盖等待期间互斥、成功提交、取消后历史不变、重试重做及保存点恢复。
目前没有生产命令启用该接口；Prefab 事务、进度 UI 与关闭流程接入尚未完成，未作窗口/GPU验收。
