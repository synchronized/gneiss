# 0.8.0 编辑器资产工作流验收记录

## 结论

2026-08-28 已在 `feat/ver008-editor-assets` 完成 0.8.0 本地与远端验收。Editor 已形成“导入资产、
识别过期、重新导入、放入场景、撤销/重做、保存并重载”的首个资产创作闭环。Runtime、公共安装
package 与 fastgltf、资产索引和 ImGui 保持解耦。

## 端到端验收

`gneiss.editor.lantern-workflow` 使用 CC0 Lantern GLB 和临时工程完成以下确定性路径：

1. 通过 Editor 导入控制器复制并导入 GLB，资产索引与 Asset Browser 状态为 `Ready`。
2. 修改工程内源文件后识别为 `Stale`，恢复源文件并重新导入成功。
3. 从派生 Mesh 与 Material 创建场景节点，以稳定 UUID 完成 Undo 和 Redo。
4. 原子保存场景，重新加载后仍能通过 UUID 找到节点及资产引用。

现有 `gneiss.editor.lantern-gallery-project` 与 `gneiss.lantern_gallery_example` 继续负责真实窗口、场景
加载和渲染 smoke test；业务正确性不依赖 UI 自动化。
