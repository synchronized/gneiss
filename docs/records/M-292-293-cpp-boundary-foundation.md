# M-292～M-293：接口审计与 Core 边界首轮实施

日期：2026-10-05。0.45 开发中，本记录不代表版本重构或发布验收完成。

## 审计基线

基于 v0.44.0 枚举公共头中导出函数，并与 `abi/api-stability.txt` 完整交叉核对，共 102 个。
[接口清单](artifacts/0.45-api-inventory.json) 中的候选包装引用不代表语义覆盖。
本轮审查 4 个 Core 函数并补齐 8 个没有直接包装入口的查询函数；余下 90 个函数的所有权与测试映射
仍标记 pending。类型、描述结构、常量和回调的全面审查尚未完成。

迁移前 Windows Clang Debug CTest 为 164/164（219.99 秒）。不以此替代迁移后的验收。

## 发现与改动

- Core 的版本/结果 C 入口原本与实现混放；现移入 `src/api/c/core_api.cpp`，委托内部 `.hpp` 契约。
  内部复用固定宽度结果值，未复制枚举或建立第二套状态；版本与结果公开布局、符号保持不变。
- `world` 补实体计数、节点局部变换、父节点及关联实体查询，并提供两个内建类型 ID 函数。
- `type_registry` 补冻结状态与按序号枚举，明确 Registry 元数据的借用寿命。
- 增加 Core 边界检查、违规反例测试及 API 清单一致性检查。规则当前仅约束 Core，不能声称已约束全仓。
- 部分 IO/IPC/Process 模块引用公共 `result.hpp` 的轻量值类型；需与拥有型 RAII 依赖区分审查。
- Application 中 Mesh/Material/Texture 目前是显式 create/destroy 加 ID，仍需拥有型包装；
  `get_world` 返回借用裸句柄，借用视图方案待完成。这些不因查询包装补齐而被标成完整。

## 模块所有权初审

| 模块 | 现有职责与待处理边界 |
| --- | --- |
| Core | 无业务状态；RID 与任务基础设施，优先约束不依赖宿主 SDK |
| Application | 状态装配与主循环；API 文件持注册表且混有内部加载入口，后续拆分需保持唯一注册表 |
| World / Scene | ECS 与 Scene Tree；World API 同时含节点入口，内部调用与句柄解析需收口 |
| Render / Asset | Render 管理 RID/GPU 生命周期；解码、格式及加载跨目录混放，迁移前需细化依赖图 |
| Log / Game | 日志 ABI 校验被其他 C 入口复用；回调、分发与上下文寿命需分开处理 |
| Reflection | Registry 内部类与 C 入口同文件；借用元数据与冻结语义必须保持 |
| Platform / Tooling | 后端与离线工具边界继续保留，不因重构下沉到公共 ABI |

## Log 校验分层补充

日志 UTF-8 规则保留在 `src/log/log.cpp`，内部 `.hpp` 接收借用 `string_view`。
`src/api/c/log_validation.hpp` 负责结构大小、保留字段、严重级别、指针长度及 size_t 可表达性校验；
C 导出、Application 与 Game Context 的 ABI 入口共用该适配，不再调用导出函数复用规则。
现有异步分发线程、回调与上下文所有权保持不变，仍待后续契约审查。

新增 C 测试覆盖空消息、空指针非零长度、非法 UTF-8、合法中文、保留字段与短结构布局。
共享库相关 7/7（0.65 秒）及 Game Module 联测 4/4（1.62 秒）通过。
新增头使用 include guard，并修复范围算法建议；原有 UTF-8 复杂度、嵌套条件和公共宏展开告警仍存在。
清单另完成日志校验 1 项审查，当前累计 13 项，余下 89 项 pending；不代表完整 SDK 审查完成。

最终日志专项在静态库 5/5（1.01 秒）和共享库 5/5（0.29 秒）通过。
