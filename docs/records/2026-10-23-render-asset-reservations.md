# 普通渲染资产预留租约与缓存事务删除

日期：2026-10-23。

## 已实施

- 普通异步请求提交时，在现有 URI 缓存预留 Mesh、Texture、Material RID；调用者可复制
  `requested_assets()` 返回的租约。缓存条目存在只表示有资源身份，不表示内容可用。
- 同 URI 复用同一 RID。首次失败且使用者继续持有租约时，显式重试填充同一槽位；没有使用者
  的失败或取消目标随 `release_unused()` 回收。同步读取遇到预留槽位返回未就绪。
- 普通候选成功后替换目标内容，删除发布时的缓存条目事务及材质依赖二次映射。
  `resource_cache::reload_transaction` 已无生产调用者，连同 `reload_request` 删除。
- 预留材质在帧快照中使用默认参数；填充后新帧取得真实内容，旧帧保持原快照。
  材质缓存条目持有准备阶段的描述租约，避免候选释放后过早回收。

## 验收范围

覆盖首次失败后保持 RID 重试、上传预算等待、更新失败保旧、取消等待在途回执、显式销毁后
拒绝迟到完成，以及未就绪材质的跨服务/类型校验、重复销毁和帧快照隔离。

- Windows Clang Debug 完整构建通过。
- 完整回归 201 项中 200 项通过；资源缓存测试因删除事务用例后累计计数未调整而失败。
  修正该测试断言后，定向重建与重跑 1/1 通过；没有改动产品代码或跳过测试。
- `clang-format --dry-run --Werror`、`git diff --check` 通过。
- 五个受影响实现执行 clang-tidy；本次新增的嵌套条件告警已修正并复查。
  既有大函数复杂度、初始化格式等告警仍存在，不将此次检查描述为零告警。
- 未单独运行静态库/跨平台矩阵；公共 C ABI 未修改。首次材质缺省已验证帧快照语义，
  尚无专门的材质迟到 GPU 像素测试。

## 尚未迁移

校验；场景、普通场景重载及编辑历史仍有固定版本消费者。它们的迁移顺序和验收要求以
