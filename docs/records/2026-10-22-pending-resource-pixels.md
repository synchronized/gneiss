# 缺省渲染资源的 GPU 像素验证

日期：2026-10-22。对应 [渐进资源计划](../plans/PLAN-051-progressive-render-assets.md) S1。

## 验证内容

在真实 Granit Application 中加载带摄像机的场景，将一个节点绑定到预留 Mesh/纹理 RID。
通过内部资源服务控制内容出现时机，读取 128×128 帧中心像素：

1. Mesh 尚未填充时不绘制该物体。
2. Mesh 填充后，未就绪自发光纹理使用默认白贴图。
3. 纹理填充为红色后，同一材质和同一纹理 RID 显示红色。
4. 同一纹理 RID 更新为蓝色后显示蓝色。
5. 空数据替换被拒绝，画面保持蓝色。
6. 纹理销毁后，即使后端已有镜像，捕获仍返回无效句柄；迟到填充被拒绝。
7. 移除绘制组件恢复原背景，并显式释放手动创建的资源。

测试不依赖随机延时，也没有重新创建材质来绕过依赖绑定刷新。
为共享库测试导出四个已有内部资源方法；头文件仍位于 `src`，未新增公共 C/C++ SDK 接口。

## 范围与限制

这是受控资源填充的真实 GPU 验证，不是磁盘到场景的异步加载测试。
空数据失败不代表已模拟 GPU 上传失败；后者由已有可控上传回执测试覆盖。
场景加载器仍等待整批资产；其接入顺序和生命周期调整已写入实施计划。
其他平台、后端和加载性能未在本批验证。
