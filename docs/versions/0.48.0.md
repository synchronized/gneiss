# 0.48.0：C++ SDK 可读性与调用一致性

2026-10-07 发布，[源码 Release：v0.48.0](https://github.com/synchronized/gneiss/releases/tag/v0.48.0)。
本版不附预编译程序或第三方场景资产。

## 目标与交付

- Application、World、Input、Scene、Render、Reflection 与 Game Context/Module 的复杂适配集中到 8 份自动包含的实现片段，模块头展示类型、操作与所有权。
- 统一 World/Scene 借用包装的 const 操作约定，保持失败输出、资源关闭和回调存储寿命；短小的 Core、Asset URI 与日志操作保留原处。
- 新增无窗口 Application/World 示例及双编译单元安装消费者；稳定运行时示例改用原生 C++ 描述、Scene RAII 和输入查询。
- 保持 C ABI、result/输出参数及现有模块边界；同步 API 映射、ADR、参考与迁移文档。

## 验收摘要

本地 Windows Clang 完整共享 190/190、静态 187/187，干净安装消费者各 4/4。
SDK 含 28 个入口头与 8 个实现片段，独立 C11/C++20 头编译、旧路径负向检查、格式和相关静态检查通过。
C ABI 声明、102 个公共 C 导出及 61 个同版本私有 C++ 导出与 0.47 一致。

最终候选 Windows 4/4、Linux 8/8 手动矩阵通过。MSVC 运行时两组各 169/169，
Linux 图形共享 188/188、静态 185/185，另覆盖 GCC/Clang 核心、Sanitizer 与 Web。
首轮隔离安装夹具漏复制新增示例已修复并复验；详细证据见 [M-311](../records/M-311-0.48.0-sdk-validation.md)。

## 迁移与已知限制

C++ 消费者需重新编译，并完整安装 detail/*.inl。显式成员函数指针可能需要补充 const 限定；
普通调用保持。详见[从 0.47 迁移到 0.48](../guides/migrating-0.47-to-0.48.md)。
const 不代表后端只读或新增线程安全保证，数组转换仍可能临时分配，借用文本及 user_data 遵守原寿命约束。

本版未重测大型第三方场景，不承诺降低内存或改善性能；历史 IPC SIGPIPE 与灯廊启动时序风险
仍保留，当前门禁通过不表示根因修复。不升级 Granit、不开发插件或开放 Editor API。
