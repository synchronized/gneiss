# 0.42.0：真实大场景异步加载与安全切换

2026-09-28 发布，[标签与源码 Release：v0.42.0](https://github.com/synchronized/gneiss/releases/tag/v0.42.0)。
本版为源码发布，不附二进制包或第三方大场景资产。本文概括发布时的状态，详细结果以所链接记录为准。

## 目标与交付

让 Runtime 在真实大场景加载与同工程场景切换期间继续处理窗口和控制事件，支持取消与失败恢复，
且不向活动场景暴露构造到一半的候选。

- 启动与完整场景切换采用后台描述准备、有界资产子批及主线程分阶段实例化；候选使用独立 World
  和缓存，安全点激活前的失败或取消保留旧场景。
- Editor 显示加载阶段，提供取消与重试；切换后重建检查镜像和游戏模块上下文。
- 以固定 Intel Sponza 建立同步基线与异步验收，兼容有限平铺 UV 和未声明 MIME 的外部 PNG。
- 修复日志洪泛挤占 IPC 控制消息、退出终态处理及测试中的资源销毁与异步时序问题。

公共 ABI 保持不变；公共同步场景接口和原有 Scene/Prefab 结构热重载保留。
完整替换与结构热重载的对象身份语义不同，详见[场景隔离决策](../decisions/ADR-050-staged-scene-activation.md)。

## 验收摘要

- 本地共享 Debug/Release 各 158 项、静态 Debug 155 项回归通过，受影响工作流完成重复验证。
- Linux 8/8、Windows 4/4 发布检查通过，覆盖相应平台矩阵、安装消费者、Sanitizer 和最小 Web 任务宿主。
- Sponza 完成 24 组首载测试，以及完整场景连续三次切换、窗口操作、取消和关闭补测；验证图像、
  资源回收、响应时间及内存预算。

测量条件、提交对应关系、失败修复和完整数值见[验收记录](../records/M-273-278-0.42.0-validation.md)；
第三方资产来源、许可、转换损失及同步成本见[Sponza 基线](../records/M-272-sponza-baseline.md)。

## 已知限制

- 协作模式不能抢占单次解析、哈希或解码，大场景会明显停顿；异步总加载时间未优于同步，
  本版改善目标是线程池模式下加载期间的交互响应。
- 内部异步入口不是公共 SDK；源文件复核不提供跨进程原子快照，游戏模块回调副作用不承诺自动回滚。
- 使用基础 PBR 管线，但材质贴图链路不完整；法线、金属度/粗糙度、AO、自发光贴图及透明材质
  尚未完整接入，不能将 Sponza 测试理解为原始材质效果的完整还原。
- 完整引擎 Web、跨屏 DPI 人工验收和独立 GPU 显存测量未包含在本版已验证能力中。
