# 0.52.0：原生接口与模块职责整理

2026-11-23 发布，[源码 Release：v0.52.0](https://github.com/synchronized/gneiss/releases/tag/v0.52.0)。
沿用源码发布方式，不附预编译程序或第三方场景资产；[交付 PR #67](https://github.com/synchronized/gneiss/pull/67)。

## 目标与交付

- 统一 Meta 类型、能力、属性访问和 JSON/二进制序列化接口，收敛错误与断言契约。
- 整理基础模块、平台服务、日志事件、CMake 目标与测试归属，升级 Granit 至 0.74.1。
- Render 使用持久场景与增量同步，接入双视图、PBR 阴影、独立截图及 Editor 点击拾取。
- Application 阶段调度与 World 系统分离，提取 Editor 视口/会话及 Runtime 会话所有权。
- 修复 Runtime 暂停门控、跨库 RTTI、跨编译器兼容，以及测试夹具中的资源析构顺序。

具体链接、历史失败与修复证据见[发布验收记录](../records/2026-11-23-0.52-release-validation.md)。

## 已知限制

本版属于早期开发的不兼容源码整理，不承诺稳定 SDK/ABI。PLAN-128 的 Runtime 协议与业务调度
尚未完全分离，工作区与宿主职责仍有后续迁移；完整高 DPI、保存确认/取消和连续关闭项目重开
尚未手工验收，自动化通过不替代这些项目。

PLAN-115 的真实设备丢失、高并发 GPU 上传饱和、代表性跨硬件预算定标、完整拾取遮挡/MASK
矩阵及浏览器非阻塞消费尚未完成。不根据小场景结果宣称通用预算已定标。

以上事项按用户确认退出本版范围，由 [PLAN-129](../plans/PLAN-129-next-architecture-baseline.md)
承接，不标记为实现完成。下一轮具体对象模型和 API 需另行设计确认。
