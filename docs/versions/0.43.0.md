# 0.43.0：Granit 升级与 PBR 材质管线

2026-09-30 发布，[标签与源码 Release：v0.43.0](https://github.com/synchronized/gneiss/releases/tag/v0.43.0)。
本版为源码发布，不附二进制或第三方大场景资产。

## 目标与交付

补齐从 glTF 导入、作者格式、Cook、异步依赖加载到 GPU 呈现的主要 metallic-roughness 材质链路。

- Granit 固定升级至 0.43.0，接入 MASK 阴影常量可见性及 Vulkan demote 设备特性修复。
- 五类贴图及因子、用途对应的颜色空间/Mip、MikkTSpace 切线、负缩放和多贴图事务贯通。
- Material v5 支持逐槽 UV0/UV1 与采样器、OPAQUE/MASK/BLEND 和双面可见性；
  Mesh Binary v3 保存 UV1 与顶点色。旧格式与 C 描述布局兼容，导入缓存版本更新。
- 修复候选驻留漏计扩展顶点属性、PNG 预算错误诊断、编译器兼容与安装 SDK 依赖版本。

当前接口和格式见[Render 资产参考](../reference/render-asset-formats.md)，不将本版称为完整 glTF/PBR 支持。

## 验收摘要

- 最终代码候选 `1d683e0` 的 Linux 8/8、Windows 4/4 通过，覆盖对应共享/静态、安装消费者、
  Sanitizer 和最小 Web 调度。后续合并前收尾仅文档与验收记录。
- Linux 共享/静态及 Windows 实机完整像素回归开启 Vulkan validation，无 VUID 错误；
  Windows 托管 Runner 无 Vulkan ICD，GPU 路径由 Linux 与本地 Intel UHD 630 验证。
- 本地升级后完整回归 160/162，安装配置修正后受影响三项复验通过；前序共享/静态及 Release
  全量通过。日常 Sponza 三次采样、连续切换、窗口交互、取消和回收通过。
- 升级后补测日常 Sponza 的资源量保持一致，回读图像与前序同机结果逐字节相同。
  完整 4K 配置验证明确预算拒绝与回收，没有把加载失败算作场景成功。

详细数值、前后候选关系、失败修复与日志见[M-284～M-285 验收记录](../records/M-284-285-0.43.0-validation.md)。

## 已知限制

- 完整 4K Sponza 超出 2 GiB CPU 候选预算，不能激活；该预算不是整个进程工作集或显存上限。
- 对象级透明排序不能保证相交三角形正确；不包含 OIT、折射、完整双面阴影语义、JPEG/KHR 灯光。
- 协作模式的解析、哈希与解码长任务不可抢占；完整引擎 Web、独立显存和物理跨屏 DPI 未验收。
- Vulkan 设备需支持 shaderDemoteToHelperInvocation，不支持时设备选择失败。
