# 0.51.0：原生架构与资源、场景所有权收敛

2026-11-04 发布，[源码 Release：v0.51.0](https://github.com/synchronized/gneiss/releases/tag/v0.51.0)。
沿用源码发布方式，不附预编译程序或第三方场景资产。

## 目标与交付

- 移除公共 C ABI、对象 SDK 和动态 Game Module；同源码宿主直接使用内部原生 C++ 接口。
- Asset Manager 负责 CPU 资产加载，Resource Service 负责资源引用与创建，Render Service 通过 RID 管理后端。
- 统一异步文件入口、资源强引用和弱缓存，明确最后一次引用释放与后端销毁的边界。
- World 管理运行对象及 ECS，Scene 管理场景成员与 Prefab 来源/覆盖，Editor Document 保存编辑状态。
- Meta 提供类型视图、嵌套属性、容器、枚举与通用序列化，统一 GUID、数学值类型和 result 返回值。
- Editor 资源准备及 Runtime 重载按请求编号接收、取消与清理；文档恢复提交前检查冲突。
- 补齐 MSVC、GCC、Clang、Sanitizer 及共享库边界的发布兼容修复。

## 验收摘要

引擎候选 `9083f370` 的 Linux 完整矩阵 8/8、Windows 共享/静态核心构建通过；
本地 MSVC Release 205/205 通过。随后仅拆分资产测试的 CPU 与原生窗口入口，
`3a1e972d` 的 Windows 共享/静态宿主补验通过，本地拆分后两项测试均通过。
托管 Windows 无 Vulkan ICD，图形用例由有 GPU 的本地环境验证；Linux 两个 Runtime
各 202/202 并通过额外 Vulkan 像素验证。最终文档提交未重复触发矩阵。

详细候选、远端链接和历史失败记录见[发布验收](../records/2026-11-01-0.51.0-release-validation.md)。

## 已知限制

这是早期开发阶段的不兼容版本，旧 SDK 和旧资产格式不能假定兼容，迁移方式见
[迁移指南](../guides/migrating-0.50-to-0.51.md)。目前不提供新的客户逻辑 SDK 或动态插件替代协议。

普通资源按项采用，不保证跨资源批次回滚。完整浏览器 Editor/Runtime、流送系统及 CPU 数据
释放策略的后续扩展不在本次完成范围；Web 验收仅覆盖独立任务调度宿主。

本次未重新下载或采样大型场景，不声明修复 0.50 的帧响应、视口性能和相关验收缺口；
原失败证据和门槛继续保留于[0.50 归档](0.50.0.md)。
