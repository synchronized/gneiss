# 0.45.0：内部 C++ 分层与完整 SDK

2026-10-06 发布，[标签与源码 Release：v0.45.0](https://github.com/synchronized/gneiss/releases/tag/v0.45.0)。
本版为源码发布，不附二进制或第三方大场景资产。

## 目标与交付

内部 C++ 实现、薄 C11 ABI 与轻量 C++20 SDK 分层，运行时状态保持唯一所有者。

- Engine 按 Core、Platform、Asset、Function 组织，C 适配集中到 src/engine/api。
- Editor 模型、会话、面板和资产服务归 src/editor；离线实现归 src/tooling；根目录 apps 保留入口和宿主装配。
- 公共 102 个 C 函数及类型、常量、回调完成 C++ 映射与生命周期审计，增加 Prefab 刷新令牌 RAII。
- 修复 Prefab 子树捕获范围、作者树拖拽期间的遍历失效及创作命令回滚边界。
- 正反例检查约束依赖方向与 API 覆盖；面板交互测试不创建原生窗口。

## 验收与限制

本地共享 CTest 187/187、静态 184/184，独立安装 C/C++ 消费者两组各 3/3。
远端 Windows 4 项、Linux 8 项发布检查全部取得通过证据，包含 Web、Sanitizer 与 Vulkan validation。
导出为 102 个公共 C 符号和 61 个同版本私有 C++ 符号；安装仅包含预期公共头。
平台任务、修复复验和大场景证据见 [M-297 验收记录](../records/M-297-0.45.0-validation.md)。

完整 Cook Sponza 的 Debug 首载未在工具 15 分钟期限内完成，不计为通过；Release 使用同一资产和预算验证。
本版不升级 Granit，不实现插件框架；cooperative 长帧、取消终态预算独立观测、驱动实际显存测量及
既有渲染语义限制继续保留。公共 C++ 包装不使借用对象越过父对象寿命；私有 C++ 导出不承诺 ABI 稳定。
