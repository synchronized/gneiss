# 0.46.0：公共头目录整理

2026-10-06 发布，[源码 Release：v0.46.0](https://github.com/synchronized/gneiss/releases/tag/v0.46.0)。
本版为源码发布，不附预编译程序或第三方大场景资产。

## 目标与交付

- Engine 功能头归入 `include/gneiss/engine/`，基础类型和版本头归其 `core/`。
- 根总入口保留，旧功能头及 `gneiss/core/` 通过转发头兼容；不增加弃用警告。
- 同步生成版本头、安装文件集、示例、当前 API 清单与新旧路径检查。
- 修复清单夹具残留旧头、MSVC 编译仅宏头时空单元警告的问题，保留原警告等级。

## 验收摘要

本地 Windows Clang 共享完整 CTest 187/187、静态 184/184，安装消费者各 3/3。
新旧路径及独立 C11/C++20 头编译通过，安装集合为 54 个自有公共头。
102 个公共 C 符号与 61 个同版本私有 C++ 导出与 0.45 基线一致。
最终候选远端 Windows 4/4、Linux 8/8 通过，包含 Vulkan validation 图形验收。
远端结果与修复过程见[验收记录](../records/engine-public-header-layout.md)。

## 已知限制

本版不开发插件、不开放 Editor API、不升级 Granit，也不改变运行时行为。
既有 Debug 完整大场景加载时限、cooperative 长帧及资源观测限制继续保留，本版没有新性能结论。
旧路径移除不在本版范围；同版本私有 C++ 导出不承诺跨版本 ABI 稳定。

首轮 Linux 静态矩阵观察到一次 `runtime.ipc-session` SIGPIPE 异常，根因尚未定位；相关实现未在本版修改，该风险未宣称修复，详见验收记录。
