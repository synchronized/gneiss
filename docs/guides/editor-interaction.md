# Editor 选择、变换与窗口交互

## 启动与打开场景

启动工程和 File → Open Scene 使用同一个异步加载界面。窗口与 UI 初始化后先进入主循环，
加载期间显示 Opening Scene；线程池模式在后台读取和解析资产，场景实例在所属线程同步创建，并在安全点激活。
`--cooperative-tasks` 保留协作执行，不承诺与线程池相同的响应时间。

进度条表示**当前阶段**的已完成数量，不是整个加载过程的时间百分比；总量未知时显示等待动画。
Cancel 取消候选，存在在途上传时先等待安全回收再允许重试。失败显示错误，可 Retry 或 Back to Editor。
首次启动取消后返回未命名空场景；已有场景加载失败或取消时保留原场景、选择及撤销历史。
成功切换才清空历史、重绑场景树和编辑器相机。

加载界面暂时替代编辑面板，避免修改正在切换的文档；操作系统窗口消息继续处理。
工程配置、窗口/渲染器/UI 初始化仍在进度界面之前完成；这不是整个进程启动的后台化。
文件监视触发的结构重载、Prefab 来源读取与保存、普通场景保存均使用异步文件服务。
文件操作期间显示等待界面并暂停编辑；保存成功后才执行后续文档动作，失败保留未保存状态。
`--smoke` 等待场景成功激活并运行三帧再退出，加载失败或超过五分钟返回失败。
需要观测加载后的持续渲染时可使用 `--smoke-frames 3000`（有效范围 1～100000），
它自动启用冒烟模式并指定加载后的主循环帧数；整个运行仍受五分钟超时约束。
该模式每 120 轮及首尾输出渲染采样：从激活开始的已显示帧数、显示间隔、构帧、排队和 GPU 阶段耗时。
主循环帧数不是显示帧数；GPU 数据是最近一次可用的异步回执，不是当前主循环帧的 GPU 耗时。

## 工作区布局与退出

编辑器通过 `user://<工程路径哈希>.layout` 读取布局；原生挂载对应用户配置目录下的 `layouts`，
因此已有布局文件仍可使用。工程路径由启动引导规范化，布局层不再访问原生路径。
启动先显示默认工作区；有效配置读完后采用面板显隐与停靠数据，缺失或损坏时保留默认。
Reset Layout 优先于尚未完成的读取，避免迟到结果覆盖重置。

退出时显示 Closing Editor，先收尾编辑与后台任务并保存布局；写入完成后才退出。
布局保存失败时可选择重试或不保存布局退出，旧配置不会被截断。
`--smoke` 不读取或保存用户布局。Project Manager 正常退出也显式推进服务关闭。
工程启动目录准备、日志和 Render 最终 GPU 等待仍有同步路径，详见
[剩余文件访问审计](../plans/PLAN-051-async-file-service.md#剩余文件访问审计与最终验收清单)。

## 选择与变换

在 Scene Hierarchy 选择节点后，在 Scene View 使用 Move、Rotate 或 Scale。Move/Rotate 使用世界轴，
Scale 由 ImGuizmo 按节点局部轴处理。拖动预览实时写回作者场景，释放后产生一条撤销记录；
切换或清空选择、折叠视图时会收尾原节点的拖动，不把操作转移到新选择。
命令记录失败时恢复原节点拖动前的值。
Delete 或 Ctrl 快捷操作执行前会先收尾拖动；删除后的第一次撤销恢复节点，第二次撤销恢复拖动前变换。

支持普通场景节点和 Prefab 来源子节点；Prefab 实例根当前使用 Inspector 编辑。
父级正非均匀缩放遵循 Scene Tree 的显式 TRS 组合，不能表达任意剪切矩阵。
负缩放、零缩放或无效 Gizmo 矩阵不能用于此拖动路径；失败不覆盖作者变换。

当前选择入口是层级树。Scene View 的命中检测针对 Gizmo 控件，**尚无点击模型表面选择对象的完整
几何拾取**，也不提供遮挡选择或 ID Buffer 拾取。不要把 Gizmo 轴命中视为已经实现场景拾取。

## 窗口与坐标

当前场景渲染覆盖整个窗口，Scene View 负责裁剪显示和输入区域。Gizmo 使用全窗口纵横比，
移动或调整面板不会创建独立的场景渲染目标。

原生 Win32 路径的窗口渲染尺寸和鼠标坐标使用客户区物理像素，ImGui framebuffer scale 为 1。
不能再按显示器缩放比例单独乘鼠标坐标，否则会产生重复缩放。零尺寸期间 UI 使用最小 1×1 尺寸，
恢复窗口后重新采用有效客户区尺寸。该约定不意味着字体已实现随 DPI 自动重建或物理大小恒定。

## 回归验证

配置并构建 Editor 后运行：

```powershell
ctest --preset windows-clang-debug -R 'gneiss.editor.(transform-gizmo|gizmo-input-replay|native-window-interaction)' --output-on-failure
```

跨平台输入回放驱动真实 ImGuizmo 控件；事务测试验证 Scene Tree 写回及 Undo/Redo。
Windows 原生窗口测试覆盖连续 resize、最小化恢复及合成 DPI 消息，验证窗口尺寸、指针状态和 UI 提交。
离屏窗口收到真实鼠标离开消息时，测试要求 ImGui 同样报告指针不在窗口内。

这些测试不验证 GPU 截图、主观拖拽手感或物理多显示器跨屏行为；完整覆盖范围与限制见
[0.37 验收记录](../records/M-242-245-0.37.0-validation.md)。
