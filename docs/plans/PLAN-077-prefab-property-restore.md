# PLAN-077：Prefab 属性覆盖提示与恢复

状态：已完成。

## 目标与边界

- Transform、Camera、MeshRenderer 的可写字段统一显示来源差异，并提供恢复源值按钮。
- 来源使用当前实例持有的 Prefab 修订，不额外读文件；来源视图只在绘制期间借用。
- 面板只产生独立属性编辑请求，复用描述命令及资源异步替换，不增加加载器或历史系统。
- 实例根 Transform 是实例位置，不提供来源覆盖提示；主相机状态只读。
- 删除重复 Transform 单字段提示/恢复实现，保留整组恢复及独立组件增删操作。

## 验收

完整 Debug 编译；无窗口点击恢复控件验证路径、值和不直接修改对象；组件命令、资源编辑、
Prefab 覆盖及保存重载回归。暂不运行大场景、真实 GPU 窗口或远端 CI。

## 实施与验收记录

- 共用反射面板接受同类型来源视图，递归至可写标量字段生成差异提示及恢复请求。
- 来源引用由宿主在绘制期间持有；恢复请求拥有独立 value，不保存成员指针。
- 三类组件继续使用既有命令/异步资源入口；删除宿主中重复的 Transform 单字段提示和恢复按钮。
- 2026-10-30：完整 Windows Clang Debug 编译及 8 项相关回归通过。

  既有命令测试验证撤销重做、资源失败保留、实例隔离和保存重载。
- 未运行真实 GPU 窗口、大场景、浏览器或远端 CI。
