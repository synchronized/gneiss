# PLAN-063：Scene / Prefab 对象树校验与编解码收敛

## 状态

已完成。

## 目标与边界

继承 [PLAN-062](PLAN-062-prefab-explicit-root.md) 的显式根语义，收敛重复实现。
保留扁平 objects、parent_uuid 和 Prefab root_uuid，不增加持久化树或新服务。
Scene v5、Prefab v1 格式不变；不扩展嵌套 Prefab、结构事务和流送能力。

## 实施与验收

- [x] 共用对象树检查，返回临时 GUID 索引、父先子后顺序和深度；检查身份、父引用、环、指定根及深度上限。
- [x] 编解码、加载准备、结构差异和 Prefab 创建/重载调用共用检查；运行时组件支持检查仍在 function 层。
- [x] 创建 Prefab 根不再生成空对象表到新对象表的结构差异。
- [x] Scene / Prefab 共用对象编解码，分别识别格式、版本、资产身份和根身份；不再转换 JSON 格式后二次解析。
- [x] 保存直接验证内存结构、变换、覆盖值和内置组件；反射编码不再调用整份资源解码或组件解码。
- [x] 保留原始作者 JSON 的扩展字段；组件内容由组件编码器负责，仍需解析其 JSON 输出以拼装文档。
- [x] 完整 Debug 编译、场景/Prefab/编辑器相关短测试及差异检查通过。

## 验收重点

非法父引用、环、多根 Prefab、无效根、重复身份在保存时拒绝；Scene 继续允许森林。
拒绝非有限变换、未归一化旋转、零缩放、非法相机/网格引用和重复或无效覆盖。
自定义组件保存只调用编码器，解码调用计数不增长；扩展字段、重排和根身份往返保持。
自定义组件的业务合法性由其编码器负责，保存不再通过解码器附带执行检查。
本阶段不运行大场景、GPU、浏览器矩阵和远端 CI。
