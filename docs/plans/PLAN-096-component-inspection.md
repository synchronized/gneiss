# PLAN-096：通用组件检查迁移

状态：已完成。

## 已确认边界

以 World 实际组件为唯一存在性来源，复用 component_adapter.capture 和 component_descriptions。
场景查询、编辑器快照与 IPC 使用组件描述集合；Transform 保持节点公共字段，不重复加入集合。
不增加 has_*、逐类型 optional 或第二套组件注册表。反射视图借用快照，修改通过组件命令提交。
IPC 更新检查域协议，不双写旧字段。资源选择保留既有异步命令，不通过反射直接改 ECS。

## 实施顺序

1. 支持未绑定资源的 MeshRenderer 捕获、安装及依赖查询，渲染跳过未就绪项。
2. 场景查询和本地编辑器使用组件集合，删除固定标记与专用快照字段。
3. IPC、运行时检查和面板使用通用组件集合，普通组件属性访问复用适配器。
4. 验证自定义组件、空组件、添加删除、属性编辑、序列化与 IPC 往返，更新记录。

## 验收

新增测试组件仅注册反射和适配器即可捕获、传输、读取与编辑属性。
无 scene_node_components/component_flags 残留；Debug 构建和相关 CPU 测试通过。
不运行 GPU、大场景或远端 CI，不扩展脚本系统和任意 ECS 内部组件的可编辑性。

## 实施结果

场景、本地编辑器与运行时检查使用组件集合，检查域协议升级到 2。
属性读写迁至组件适配层；World 仅提供实体到节点查询。空资源组件支持安装、捕获、
保存加载、撤销和恢复；未就绪项不进入渲染快照。
Debug 全量构建及 25 项相关 CPU 测试通过。新增自定义组件 IPC、反射访问、属性写入、
非法值拒绝、未知类型拒绝，以及空材质撤销重做与空组件子树恢复验收。
远程写入仍限现有协议支持的顶层标量；嵌套和容器属性只读展示，本地编辑不受此限制。

架构决策见 [ADR-101](../decisions/ADR-101-component-inspection.md)。
