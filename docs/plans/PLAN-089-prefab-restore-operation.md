# PLAN-089：异步恢复操作与入口收敛

状态：已完成，2026-10-30。

范围：将 PLAN-088 宿主内的异步恢复迁入文档操作模块，覆盖加载成功/失败、文档修改/关闭/切换、取消及历史重放；统一实例、组件、属性恢复的记录移除规则。
不做 GUI 手工验收，不新增通用事务系统，不修改来源文件。

操作在所属线程推进，等待期间不修改文档；提交前核对文档身份和内容。历史持有资源，撤销重做不读文件。
快捷入口保留：属性恢复仅清除对应属性，组件恢复清除该组件全部结构及属性覆盖，实例恢复清除所有覆盖。

## 验收

- 文档操作接管异步加载、身份/内容校验、取消和一次性历史提交；宿主回调不再包含加载装配逻辑。
- 组件/Transform 快捷按钮使用统一覆盖规划入口；旧网格恢复入口转发文档操作，删除 `restoring_` 专用分支。
- 新增 `gneiss.editor.scene-document-edit`：真实文件、资源服务和 World 下验证成功、失败、等待期间修改、关闭、同 URI 重新打开、取消、终态重复推进，以及破坏源文件后的撤销/重做。
- 扩展作者操作测试验证组件范围恢复不影响其他组件；旧资源恢复测试改用稳定作者身份重新获取快照重建后的句柄。
- Debug 编译、37 项相关 CPU 回归及 `git diff --check` 通过。
- 按用户范围未执行 GUI 手工验收；未运行 GPU、大场景、浏览器或远端 CI。
