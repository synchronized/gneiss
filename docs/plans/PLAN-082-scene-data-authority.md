# PLAN-082：场景数据权威来源收敛

状态：实施中。决策见 [ADR-095](../decisions/ADR-095-scene-data-authority.md)。

## 目标与非目标

普通对象以编辑 World 为准；Scene 保存成员归属，Prefab 保留来源和覆盖。
不改文件格式，不增加 Manager，不实现完整嵌套 Prefab 结构覆盖、三方合并或流送。

## 实施顺序

1. 当前状态读取：重载差异从 World 捕获；名称、层级、相机停止描述双写。
   Prefab 根捕获及替换时附属对象识别读取 World。已完成，Debug 编译及 9 项相关 CPU 测试通过。
2. 明确资源 URI 与已解析引用的关系，保证失败引用不丢失；组件安装与捕获形成对称入口。
3. Prefab 引用/覆盖移出完整描述；成员显式标记保存归属，去除数组前缀和下标耦合。
4. 普通资源组件停止双写，删除常驻完整描述；加载输入仅在创建期间持有。
5. 清理编辑器缓存与快照接口，验证运行状态隔离与临时对象不保存。

## 验收

- 改名、换父节点、增删相机、变换编辑后保存再读一致。
- 编辑后重载相同源文件仍按当前 World 正确恢复源值。
- Prefab 根改名/换父节点可捕获；替换保留自有子节点。
- 后续阶段覆盖失败 URI 保存、Prefab 覆盖/Revert、撤销恢复、成员不重复保存。
- 编译及相关 CPU 测试，不运行大场景、GPU、远端 CI。
