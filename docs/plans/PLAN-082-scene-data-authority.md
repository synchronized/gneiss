# PLAN-082：场景数据权威来源收敛

状态：已完成。决策见 [ADR-095](../decisions/ADR-095-scene-data-authority.md)，
当前接口契约见[场景实例参考](../reference/scene-instance.md)。

## 目标与非目标

普通对象以编辑 World 为准；Scene 保存成员归属，Prefab 保留来源和覆盖。
不改文件格式，不增加 Manager，不实现完整嵌套 Prefab 结构覆盖、三方合并或流送。
保持现有资源准备成功后才提交的行为，不新增未解析 URI 占位组件。

## 完成情况

1. 当前状态读取：重载差异从 World 捕获；名称、层级、相机停止描述双写。
   Prefab 根捕获及替换时附属对象识别读取 World。
2. 资源契约：准备失败不提交新选择，保留旧引用及 URI；无来源身份的组件拒绝保存。
   提取 capture_scene_object，与现有安装操作覆盖相同的相机/网格组件。
3. Prefab 引用/覆盖移至 prefab_binding；成员使用 persistent 标记保存归属。
   查询、删除、快照、恢复和重载不再依赖描述数组下标或显式成员前缀。
4. 普通资源组件停止双写；删除 scene_instance 常驻 description_ 与 source()。
   输入描述由同步创建调用持有，实例仅保留场景 UUID、成员及 Prefab 绑定。
5. 编辑器删除从 UI 缓存生成的旧局部快照与恢复接口，完整撤销使用 World 捕获的子树快照。
   创建输入改名 mesh_node_creation，UI 查询记录不充当保存数据源。

## 验收结果

2026-10-30：Windows Clang Debug 构建通过，25 项相关 CPU 测试通过。

- 场景创建、改名、换父节点、相机与资源编辑、保存及结构重载。
- Prefab 实例成员交错、源更新、覆盖、撤销恢复与附属对象保留。
- 失败的资源替换不改变保存内容；临时对象不进入保存和子树快照。
- 跨持久化边界的父引用拒绝保存，输出保持不变。
- 两个 World 的实例修改隔离；UI 缓存未刷新时撤销快照仍捕获实际对象值。
- 修正 Prefab 测试的根节点前缀假设，以及保存测试中 PLAN-081 已取消的未知字段保留预期。

未运行大场景、GPU、浏览器、远端 CI；未推送。
新增组件仍须配对实现安装与捕获，本计划未增加任意组件自动安装框架。
将来支持未解析资源占位或三方合并时，须另行设计目标身份或只读基线，不恢复描述双写。
