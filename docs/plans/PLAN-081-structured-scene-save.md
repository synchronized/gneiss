# PLAN-081：Scene/Prefab 仅保存结构化描述

状态：已完成

## 已确认决策

删除 Scene/Prefab author_json，不保存完整源文本，不保留未知扩展字段。
程序需要的数据由内存描述承载，输出由描述生成。未知组件类型与格式错误继续拒绝。
保留现有文件布局、对象层级、组件及覆盖校验，不修改文件版本号。

## 实施

- 删除旧文档解析、UUID 对齐和扩展字段合并，清理子树快照重新编码底稿的步骤。
- 资产请求记录成功加载的文件字节数，缓存复用该统计；场景加载输入传递累计统计。
- 描述对象不携带加载元数据；单文件和累计字节、节点/依赖/深度上限继续有效。
- 更新往返、未知字段丢弃、失败不覆盖、缓存统计与场景加载边界测试及参考文档。
