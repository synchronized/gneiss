# PLAN-106：局部文档历史与增量场景投影

## 状态与范围

2026-11-08：已确认，实施中。归属 DEV-052，承接 PLAN-105 的对象与 Prefab 边界。
决策见 [ADR-111](../decisions/ADR-111-document-history-projection.md)。
本计划替代 PLAN-105 中“普通历史继续整文档版本切换、增量同步暂不实施”的选择。
普通历史已使用局部对象差异；结构变化仍回退整场景替换，完整目标尚未完成。

## 职责与对象布局

- scene_document：描述、组件、Prefab 引用及覆盖，保证编辑数据合法；最终不调用 Application/World。
- document_editor：把用户请求解释为准确的文档变更，捕获旧值，准备后统一提交。
- document_history：局部变更、游标、合并键与保存点；复用现有历史入口，不长期保留两套历史。
- scene_projection：文档身份到实体的关联、已应用基线、失败状态；同一路径消费编辑与撤销变化。
- scene_edit_session：装配文档、历史、投影及选择状态；加载保存属于外部协调。
- compose_scene_document：纯内存组合，继续共用于有效数据计算与查询。

目标文件集中于 src/editor/documents；局部历史与投影不下沉 World。
scene_projection.hpp/.cpp 先接管恢复时的运行更新；scene_document_edit 随后迁移局部记录，
旧 scene_document_versions 已删除，纯 scene_document 只保留当前内容和保存点。

## 已确认语义

- 运行身份继续使用带 generation 的 entity_id，不再增加同生命周期的 instance_id。
- 描述 UUID 与实例/来源地址用于编辑定位；多次实例化不共享运行实体。
- 历史条目为 property_change、prefab_override_change、subtree_change、parent_change、component_change 的组合。
  每项保存 before/after；正向顺序执行，反向逆序执行；UI 不编写撤销回调。
- value 快照必须冻结或复制可变对象；资产引用按身份保活，不复制 GPU 内容。
- Prefab 覆盖的“不存在”与“显式设为来源值”必须区分，撤销记录作者数据真实变化。
- 校验、反向记录及历史存储准备成功后才提交一次文档编辑，不纳入文件/GPU 事务。
- 投影失败不撤销文档；失败后不可推进已同步基线，重试必须基于实际已应用状态。
- 原地属性/组件/父关系更新保持实体；删除后恢复创建新实体，历史不保活已删除 ECS 实体。
- 完整快照用于保存、检查点及整文档替换，不作为普通编辑历史的最终形式。

## 实施顺序与验收

### A：投影入口与最小身份保持闭环

- [x] 独立投影入口接管版本恢复的运行同步，先实现结构不变时 Transform 原地更新。
- [x] 只有已同步基线才能走增量；结构变化与未知状态暂保留明确的完整重建路径。
- [x] 撤销/重做变换时目标及无关对象的 node/entity 身份不变；失败不误标同步。

### B：局部文档变更与历史

- [x] 外部编辑历史改用局部对象/来源/资源差异与轻量版本标识，释放整份前后快照。
- [x] 同一交互合并差异，保留最初旧值与最终新值；旧值和顺序冲突拒绝应用。
- [ ] 将变化对象进一步细分为属性、组件与结构记录，避免属性修改持有整个对象描述。

- [ ] 引入明确变更类型，复用已有 value、属性路径、覆盖键及子树快照。
- [ ] 准备/应用入口覆盖成功、非法值、旧值冲突、分配失败及历史容量准备。
- [ ] 接入属性及 Prefab 覆盖历史，验证无覆盖恢复、连续拖动合并和 redo 分支清除。
- [ ] 接入组件增删、父关系与子树插入删除，恢复稳定描述 UUID，删除旧版本命令路径。
- [ ] 保存点、异步保存回执和关闭清理使用同一历史权威状态。

### C：完整增量投影与模块拆分

- [x] 对象集合和资源不变时，组件增删、编辑属性、显式对象名称和父关系原地同步，撤销重做保持实体。

- [x] 普通对象添加、删除及恢复按对象增量更新，无关实体身份保持。
- [ ] 独立维护文档身份关联，删除对 runtime prefab_binding 的编辑查询依赖。
- [x] 组件 create/update/remove 分开；update 回调保留描述之外的运行状态，未声明时使用既有 install 策略。
- [ ] 层级增删、重挂接、Prefab 来源刷新按受影响对象更新，删除普通撤销的整场景替换。
- [x] scene_edit_session 接管协调与选择，纯文档移除 Application/World 依赖及重复历史。
- [ ] 资源未就绪、部分应用失败、过期完成与重试有明确状态和回归覆盖。

### D：收尾

- [ ] 更新 Reference、移除旧接口和重复历史；默认编译及相关 CPU 回归通过。
- [ ] 验证跨文档拒绝、关闭后操作、复制身份、连续撤销重做、资源保活及选择恢复。

## 非目标与风险

不做嵌套 Prefab、协同编辑、磁盘历史日志、跨文件原子事务或 Granit 修改。
不运行大场景和耗时远端 CI。局部更新带来的状态同步风险通过集中入口处理，不能让各面板自行写 World。
分阶段本地提交，不将第一阶段的完整重建回退描述为最终架构。
