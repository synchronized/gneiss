# VER-036：0.36.0 编辑器资产工作流稳定性

## 状态

- 状态：已完成
- 目标版本：0.36.0
- 分支：`feat/0.36-editor-asset-workflow`

## 目标与非目标

在 0.35 的纹理与发布能力上，验证导入、源文件修改、自动重导入、场景更新、打包运行的闭环，
改善资产失败反馈与恢复，并补充编辑器交互验收。本轮不增加渲染特性、不改变公共 ABI。用户于 2026-09-25 明确授权推进本版本直到发布，
覆盖实现、本地提交、分支推送、一个 PR、按需 Actions、合并、标签与正式 Release。

## 已确认现状

- Granit 基线升级到 0.30.0，保留原生 Window 后端；本轮不迁移 SDL3 Surface 接入。
  本地 Shared/Static 验证见[升级记录](../records/2026-09-25-granit-0.30.0-upgrade.md)。

- 已有文件监听、去抖队列、内容哈希检查、导入事务、Runtime 资产修订发布与工程打包。
- 重导入回调异常已按单任务报告失败并消耗预算，后续任务可继续；再次通知同一路径可重试。
  原缺陷与验证见 [M-237 记录](../records/M-237-reimport-failure-recovery.md)。
- Runtime 异步热更新失败后已有显式重同步入口；验证与剩余范围见
  [M-238 阶段记录](../records/M-238-runtime-reload-retry.md)。
- Runtime 同步发布错误与异步应用错误均提供反馈；作者文件补扫继续保护未保存修改。
- 文件监听错误已有可见反馈及重启入口，事件丢失显示累计告警；
  已导入源文件会自动按索引分帧补扫，作者文件补扫复用冲突检查。

## 测试与验收

- 导入失败必须包含受影响源路径和原因；失败任务不无限重试、不阻断后续任务。
- 再次通知同一源文件后可恢复，既有成功与失败事件、导入预算和队列容量契约保持一致。
- 验证源修改、无变化、删除、非法文件、Runtime 更新失败以及恢复后的打包结果。
- 区分单元测试、原生窗口自动化与真实人工交互，逐项记录通过和未覆盖范围。
- 复用既有 Windows/Linux 矩阵；完成后再统一整理版本 PR 与发布，不为每个小步骤分拆 PR。

## 验收结论

错误反馈与重试复用 Asset Browser；源文件补扫按索引处理，作者文件补扫复用冲突检查。
