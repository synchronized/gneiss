# VER-037：0.37.0 编辑器交互稳定性

## 状态

- 状态：实施中
- 目标版本：0.37.0
- 分支：`feat/0.37-editor-interaction-stability`
- 用户于 2026-09-25 授权本版本实现、提交、推送、一个 PR、Actions、合并、标签和发布。

## 背景与目标

补齐 0.36 的交互验收缺口，先建立可复现测试，再修复发现的问题。优先验证 Gizmo、选择、
父子变换、撤销重做，以及窗口尺寸变化、最小化恢复和 DPI 下的输入与画面一致性。
测量资产补扫、哈希和导入耗时，以结果决定后台化范围。

## 非目标

不切换 SDL3，不修改 Granit，不扩展公共 ABI，不承诺完整场景几何拾取。
不把数学或合成输入测试描述为真实跨显示器人工验收。

## 已确认决策

- 复用显式 TRS、Editor Session、命令历史和 ImGuizmo；保持 ADR-021 的全窗口投影约定。
- 交互测试覆盖多帧拖动、释放、选择变化和失败恢复，单次拖动应对应一条历史记录。
- 窗口测试区分原生事件、合成 DPI 坐标测试与物理显示器验证，分别记录证据和限制。
- 大资产测量保留可重复的输入规模和阶段耗时，不预先引入线程及第二套资产状态。

## 测试与验收

- 移动、旋转、缩放在根节点与正非均匀缩放父节点下符合 Scene Tree 世界变换。
- 拖动中的选择变化、隐藏面板和释放不遗失历史、不写入另一节点；失败不污染变换。
- 记录拾取入口与不支持范围；负缩放、剪切、非法矩阵保持明确失败语义。
- 原生窗口连续改变尺寸、最小化恢复后仍能完成帧并正常关闭。
- 覆盖尺寸和输入坐标的缩放约定；真实跨屏验证不足时发布记录明确限制。
- 测量大文件与多文件补扫的单次阻塞和总耗时，记录是否需要后台化及其后续范围。
- 完成相关本地检查及 Windows/Linux 手动矩阵，一个 PR 汇总并完成版本发布。

## 风险与未决问题

测试证据、耗时及未覆盖范围见[验收记录](../records/M-242-245-0.37.0-validation.md)。

真实多显示器 DPI 和主观拖拽手感取决于可用桌面环境；自动化不能替代全部人工观察。
若测量暴露后台化需求，先确认所有权、取消和关闭边界，再决定本版本修复或后续专门计划。
