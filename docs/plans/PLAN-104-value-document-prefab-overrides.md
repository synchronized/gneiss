# PLAN-104：结构化 value、文档版本与 Prefab 覆盖

## 状态与范围

2026-11-07：实施中，已确认设计，开始清理 value 的标量分类假设。结构化 value、统一文档版本与操作应用尚未实现。
归属 [DEV-052](DEV-052-architecture-cleanup.md)，决策见 [ADR-109](../decisions/ADR-109-value-document-model.md)。
本计划允许修改子树与文档撤销快照，不保留旧快照体系作为长期平行入口；不要求兼容未发布的旧文件格式。
[PLAN-102](PLAN-102-resource-object-loading.md) 仍负责资产加载；本计划复用其身份、异步加载和弱缓存规则。

## 现状与问题

- core/value.hpp 目前只有基础值、数学值和共享对象引用；Meta 以排除 object 的方式推断标量。
- scene_instance_edit.cpp 按反射递归计算覆盖；可变列表、键集合变化及其他非标量走 property_snapshot。
- property_snapshot 用 JSON 固定复杂属性，混合了数据复制与文件编码。
- 编辑器组件历史、scene_subtree_snapshot、scene_document_snapshot 各自保存描述与资源引用。
- 组件路径目前依赖类型身份；增加多实例组件前需要独立组件 UUID。

## 已确认目标

1. value 统一数据内容：基础值、record、sequence、map、optional、variant、资产身份和文档对象引用。
2. 结构化内容逻辑不可变，版本共享未修改节点；修改返回新根，不能暴露可写子节点。
3. 运行时对象强引用仍可传递；持久化捕获必须转换为内嵌内容或稳定身份，不自动保存对象图。
4. 对象 UUID、组件 UUID、属性 ID、可选的稳定序列元素 ID 组成路径；类型 GUID 不承担组件实例身份。
5. Prefab 保存源资产引用和操作覆盖；编辑操作直接生成修改，反射 diff 用于整块替换等补充场景。
6. 文档是编辑内容的权威来源；World 是运行时投影，运行时不强制持有编辑历史。
7. 历史保存 before/after 文档根和操作；子树复制复用同一数据表达并显式重映射身份。
8. JSON 使用 $kind/$content，二进制后端遵循相同语义；内存版本不经过 JSON 中转。

## 非目标

- 不深拷贝外部纹理、网格、材质内容；资源强引用不冻结热重载后的内容。
- 不实现自动共享对象图、循环对象捕获、协作编辑 CRDT、跨文件事务或 GPU 回滚。
- 不为普通无身份列表推测元素身份；没有稳定 ID 时整体替换。
- 不把每帧 ECS/World 数据动态化，不把 Service、RID 或后端对象写入文档树。

## 数据与 API 目标（未实现）

value 的 record 保存类型 GUID 和属性 ID 映射；sequence 保存顺序，map 保存受约束的稳定键；
optional 明确有无，variant 使用注册的稳定分支名。资产引用保存类型和来源身份；文档引用保存对象身份。
运行时对象分支不能直接进入不可变文档，否则仍会通过共享对象改变旧版本。

capture_value(context, instance) 负责反射捕获；apply_value(context, target, value) 负责类型检查和恢复。
普通 read_value 不隐式捕获整个对象。Core 不依赖 Asset/World，引用转换由上下文适配。
文档入口递归检查持久化能力、重复 ID、非法引用、层级及深度；捕获内嵌循环明确返回错误。

property_path 使用对象/组件身份及属性、元素、键段。操作包括 set、insert、erase、move、put_entry、erase_entry。
操作保留 C++ 强类型，内容统一使用 value。map 首版只接受有稳定相等语义的键，不允许对象/容器或 NaN 作键。
集合元素 ID 由领域数据提供，不能在序列化时临时生成。复制子树生成新对象/组件 ID，重写内部引用，外部资产保持共享。

## 实施顺序与删除条件

### A：value 基础能力

- [x] 显式定义标量集合，移除新增分支自动变为标量的假设。见[首批验收](../records/2026-11-07-value-scalar-boundary.md)。
- [ ] 增加不可变结构化存储和结构比较，允许共享未修改节点，不暴露可写别名。
- [ ] 增加资产身份、文档对象身份；明确空值、空 optional、空对象引用的区别。
- [ ] 接入 variant_ops 和格式注册，完成 $kind/$content 往返；IPC 不支持的分支显式报错。

验收：旧根不随新版本修改；移动/复制安全；结构相等不依赖节点地址；失败不修改旧值；深度限制有效。

### B：反射捕获与恢复

- [ ] 按 ops 支持 record、容器、optional、variant、内嵌多态和外部资产。
- [ ] 引用策略注册为内嵌/外部身份；使用上下文解析资产，不让 Core 依赖资产管理器。
- [ ] 候选组件上执行恢复与校验；资源加载失败保留来源，不等待视觉完成。

验收：容器、切换分支、空值、多态类型变化、循环拒绝、错误路径、资产共享/异步绑定。

### C：稳定路径与修改操作

- [ ] 组件描述和文件格式增加组件 UUID，迁移类型查找与实例查找边界。
- [ ] 统一路径解析和操作应用，提供 apply_patch(root, operations) 返回新根及变更信息。
- [ ] 同步实现差异生成；无身份列表整体替换，有身份集合按 ID 增删移动。

验收：删除元素不使其他覆盖错位；重复 ID 拒绝；固定数组越界、错误类型、锚点缺失有明确诊断。

### D：Prefab 覆盖

- [ ] 编辑指令直接写覆盖，整体替换场景使用反射 diff；相同路径连续 set 合并，恢复源值删除覆盖。
- [ ] 新源重放覆盖；目标消失、类型不兼容保留覆盖并报冲突，不错误绑定其他对象。
- [ ] 缺失移动锚点不猜测位置，保留冲突；删除覆盖在目标已不存在时视为效果已满足。
- [ ] 嵌套实例使用实例路径+源身份，本地新增身份独立；成功的独立覆盖不因其他冲突撤销。
- [ ] 替换 prefab_override_value 和 JSON 快照应用分支，删除 property_snapshot/capture_property/restore_property。

验收：资源引用替换不复制资源；源更新后覆盖保留；嵌套实例隔离；序列重排和覆盖冲突可重现。

### E：文档与历史统一

- [ ] 编辑文档持有不可变根，历史持有 before/after 和操作，支持合并、分支清除、条数/内存预算。
- [ ] 子树删除/恢复/复制粘贴复用结构化值和身份重映射，处理子树外引用的保留/失效诊断。
- [ ] 迁移 scene_document_snapshot、scene_subtree_snapshot 和组件历史的内容存储，删除重复捕获恢复实现。
- [ ] 资产保活由历史所属层显式持有；URI 不保证旧资源内容，独立资产编辑使用自己的文档历史。
- [ ] 撤销一次源更新恢复当时采用的不可变源内容及覆盖，不通过 URI 重新获取当前源来伪造旧版本。

验收：撤销重做不读取文件；旧版本不变化；清空历史释放引用；删除对象可恢复；复制子树内部引用正确。

### F：World 投影与收尾

- [ ] 只根据文档变更更新受影响对象；失败保留文档和诊断，允许重试投影，不从半更新 World 覆盖文档。
- [ ] 区分结构校验失败（拒绝编辑）与资源/后端暂不可用（保留编辑，延后投影）。
- [ ] 删除反向抓取 World 推测编辑内容的旧入口；运行时实例化不强制保留文档历史。
- [ ] 更新 Reference、文件格式、测试和调用方，扫描遗留入口并完成统一编译验收。

## 验证与推进约束

每阶段使用相关编译与定向测试，不运行 GPU 大场景和耗时远端 CI。完整迁移后统一评估扩大验证范围。
每批独立提交，计划只记录阶段状态；验收细节放 Record。不得在 A 完成后宣称 Prefab/历史已经迁移。
不自动发布或操作远端。新结构进入生产入口后，同批删除对应旧路径，不能长期双写两份权威数据。
