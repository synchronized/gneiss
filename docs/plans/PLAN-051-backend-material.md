# PLAN-051：后端材质状态收敛

## 状态

实现完成，Windows Clang Debug 全部启用目标编译通过，格式、Core 边界、公共接口及 diff 检查通过。
按用户要求未运行场景、测试或 CI；GPU 行为与首帧开销仍待运行验收。

## 目标与决策

删除仅提前创建材质的 prepared_material 和准备表，首次绘制时直接创建活动材质。
保留 material_mirror 对 Granit 材质、采样器、来源和纹理绑定的必要管理。
删除上传结构中仅供旧材质准备表读取的 dependency_textures；资产层依赖引用继续保留。
纹理变化使用 Granit 已有 update 接口；不为任一纹理失效清空全部材质。
材质自身 CPU 对象替换仍会重建材质，以更新参数和采样状态。
Mesh/Texture 的实际上传与准备表不属于此次删除范围，不修改 Granit。

## 行为与代价

材质创建移至首次绘制，创建失败在该次绘制报告，不再由提前准备报告。
纹理绑定更新成功才记录新句柄；失败退出该帧，后续重新解析和重试。
未被绘制的材质可以暂存失效纹理句柄，任何后续绘制必须先更新全部槽位；
不把这些缓存句柄当作纹理所有权。Granit update 内部可能重新分配 GPU 绑定，
仅保证 Gneiss 不再销毁材质句柄及重建采样器，不承诺零分配。

## 验收

编译全部启用目标，格式、Core 边界及 diff 检查。
运行验收延后：默认纹理转为就绪、纹理重载、未绘制材质恢复、更新失败重试、
材质参数替换及关闭回收；确认输出不退化，无失效句柄提交到绘制。
