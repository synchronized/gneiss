# PLAN-097：统一编辑资源准备

状态：已完成，包含文档恢复收尾。

## 范围

收敛网格资源选择与 Prefab 操作重复的就绪查询、缺失筛选和加载提交。
沿用现有资源服务与加载组，不新增缓存、任务队列或服务，不改变文件格式与资源所有权。
决策见 [ADR-095](../decisions/ADR-095-scene-data-authority.md#编辑资源准备的职责边界)，
契约见[场景实例参考](../reference/scene-instance.md#编辑资源准备)。

## 实施与验收

1. 加载组统一返回就绪资源或异步请求，混合请求保留缓存强引用，仅加载缺失项。
2. Scene 服务保护线程、关闭状态及加载互斥；Application 移除编辑专用查询、准备与清理方法。
3. 两类编辑命令消费相同准备结果，保留文档校验、取消、历史与 Prefab 显式重载。
4. 验证全部命中、混合命中、忙时查询、取消、错误线程、关闭及内部头文件隔离。

## 验收结果

2026-11-01：Windows Clang Debug 构建通过，13 项相关 CPU 测试全部通过。
覆盖资源准备、编辑与 Prefab 命令、场景加载、文档操作、线程及关闭边界、内部头文件隔离。
新增混合命中回归验证：忙时就绪查询不干扰原请求，完成值保留原缓存资源身份并包含缺失资源。

未运行大场景、GPU、浏览器、远端 CI；未推送。跨平台行为仍需后续统一验收。

## 文档恢复收尾

- 将 `scene_document_edit` 缺失依赖接入同一准备入口，删除私有资源请求数组。
- 按请求编号轮询及放弃；放弃同时释放回执槽位，过期编号不得影响新请求。
- 快照捕获返回 `result<scene_document_snapshot>`；准备返回快照及缺失依赖的组合结果。
  同步调用方明确拒绝未准备依赖，异步操作补齐后提交。
- 验证取消、析构、失败、文档关闭后的槽位回收，以及错误编号和过期编号隔离。

收尾验收：2026-11-01 Windows Clang Debug 构建通过，17 项相关 CPU 回归通过。
新增错误/过期编号隔离、文档恢复取消及析构后重试、失败及关闭后槽位回收覆盖。
未运行 GPU、大场景、浏览器或远端 CI；本批仅本地提交。

## 请求消费与取消收尾

网格与 Prefab 编辑统一按编号领取回执；资源阶段取消直接释放槽位，结束操作。
删除事后检查回执编号的旧路径、取消等待注释和 Prefab 常驻回执；其他准备/历史阶段保持原清理契约。
2026-11-01 Windows Clang Debug 构建及 14 项相关 CPU 测试通过。
新增覆盖取消立即重试、旧操作不消费/清理新请求，以及应用停止时资源编辑退出；未运行 GPU、大场景或 CI。
