# PLAN-098：Runtime 资产重载请求归属

状态：已完成；场景 IPC 基线超时已定位并修复。

## 目标与范围

Runtime 宿主保存资源服务接受的实际请求编号，按编号轮询、取消及退出清理。
轮询失败生成单次失败 IPC 回执并结束请求；失败不推进已应用修订，允许重试。
保留场景/Prefab 结构重载的独立路径，不新增服务或队列，不改变 IPC 格式。
契约见[场景实例参考](../reference/scene-instance.md#runtime-资产重载请求归属)。

## 实施

- 宿主保留 `asset_request`；取消同时检查 IPC 会话、修订与实际请求编号。
- 进度仅报告所属请求；过期编号不消费其他请求的结果。
- 终态、轮询失败及宿主退出清理自己的编号，底层任务继续由资源服务负责关闭。
- 协调器将轮询错误/异常转为失败终态；仅 `not_ready` 保持等待。
- 单元回归覆盖等待、I/O 错误、失效编号、关闭状态、回调异常以及失败后重试。
