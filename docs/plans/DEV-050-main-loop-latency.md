## M-318

先审计旧测量语义。保留 0.49 间隔字段，新增明确起止点的原始样本，不静默替换旧指标。
测试宿主主动 sleep、scheduler.run_ready、poll_scene_load 单独计时，回调外间隔暂列未分解。
随后根据样本细分引擎事件、渲染提交与回收；用采样调用栈区分执行和等待。
测试宿主存在独立主动睡眠，须补实际 Runtime 对照，不能把夹具延迟直接当作产品长帧。
详细诊断默认关闭，记录最后未闭合间隔，避免把未知值当作零。
保留完整输入身份、二进制摘要、命令和日志；性能采样不与构建或其他 GPU 测试并行。

## M-319 与 M-320

先解释可重复热点并冻结量化目标，再决定后台转移、缩小工作块、分帧接收或消除同步等待。
若改变长期分层或执行契约，先建立 ADR；纯观测不增加架构抽象。
修复不得让迟到结果激活取消场景，也不得提前释放在途 GPU 上传资源。

## M-321

按构建指南完成必要本地检查及发布平台矩阵；纯文档归档不重跑完整矩阵。
实际完成后更新 CHANGELOG、版本页与路线图，不提前描述为已发布。
