# PLAN-086：Prefab 组件结构覆盖

状态：已完成。决策见 [ADR-097](../decisions/ADR-097-prefab-component-overrides.md)。

## 目标与边界

在已有属性覆盖上增加组件新增、移除、恢复来源，接入文件格式、实例化、来源重载和编辑器历史。
按来源 UUID 和组件 GUID 定位，禁止名字猜测、静默丢弃和自动三方合并。
新增组件保存完整描述；移除记录在来源组件消失后仍保留。目标对象消失、来源新增同类型组件、
属性目标消失或类型改变均冲突。全部描述预检查通过后才修改 World，不引入 GPU 发布事务。

## 实施

1. 定义结构覆盖及格式校验，统一有效描述准备和冲突诊断。
2. 接入创建、依赖准备、来源更新；保持覆盖记录和旧实例在预检查失败时不变。
3. 接入面板、稳定身份历史和恢复来源，新增组件的属性编辑更新完整描述。
4. 编译及 CPU 回归覆盖正常、冲突、保存恢复、撤销重做；不运行大场景/GPU/浏览器/远端 CI。

旧文件级 Apply/Unpack 仍限定原有能力；遇到结构覆盖显式拒绝，不静默忽略。

## 验收

最终增量构建及 6 项受影响回归复测通过。
