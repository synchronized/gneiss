# PLAN-112：文件、任务及资产就绪队列

## 状态与范围

2026-11-11：已完成。延续 PLAN-111，对外请求接口保持不变。
验证结果见[验收记录](../records/2026-11-11-plan112-loading-ready-queues.md)。
本次只覆盖文件服务、任务调度器完成领取及资产管理器；场景、编辑批次和输入配置后续再接入。

## 已确认设计

- 文件后端完成只写结果并投递请求 ID；所属线程消费就绪队列，处理回退并交付回调。
- 任务进入终态时加入所属 scope 的完成队列；poll 不再扫描全部任务。任务选择、定时与串行调度不在本次重写范围。
- 资产首次提交、读取完成、解码完成和依赖完成触发操作入队；同一操作重复通知合并。
- 工作线程不修改 World 或采用资产内容，采用和后续调度仍在所属线程。
- 取消、关闭、迟到结果不得重新激活旧操作；队列生命周期不能保活服务或形成循环。
- 每次消费开始时固定本轮工作量，回调产生的新工作留到后续轮次。
- 容量不足的提交保留独立重试集合，不扫描正常等待 I/O、解码和依赖的操作。
- 弱缓存及最后一个资源引用的回收属于维护工作，不与异步完成队列混同。
