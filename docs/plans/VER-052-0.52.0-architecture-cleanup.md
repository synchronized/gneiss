# VER-052：0.52.0 原生接口与模块职责整理

## 状态与基线

2026-11-09：Meta、序列化、Game Object、文档历史和 PLAN-107 资产依赖协议已完成；
Application 值返回与 Runtime/Editor 边界本批收尾完成。原生接口剩余审计及完整平台验收仍待完成，
具体清单以 [DEV-052](DEV-052-architecture-cleanup.md#收尾审计后的明确待办) 为准。
基线为 [0.51.0](../versions/0.51.0.md)，分支为 `feature/0.52-architecture-cleanup`。
本页维护版本范围和完成条件，具体步骤见 [DEV-052](DEV-052-architecture-cleanup.md)。
0.51 的发布授权不自动延续到本版；本次不推送、创建 PR 或发布。

## 目标

让同源码调用方从接口看懂职责、返回值和所有权，减少跨模块转发与重复状态。
整理应落到真实调用链；不以搬文件数量、类数量或命名统一程度作为完成标准。

0.51 已交付 CPU 加载、资源强引用、渲染 RID、Scene/World 和编辑状态分工，本版沿用这些边界。
历史计划中的未勾选项须先对照源码核实，不直接视为本版待实现能力。

## 初步核查

以下是 2026-11-04 的规划基线，不代表当前代码；最新证据见[收尾审计](../records/2026-11-08-asset-boundary-audit.md)。

| 现状证据 | 本版处理方向 |
| --- | --- |
| `src/runtime/application.hpp` 仍有 `create(..., output)`、场景/资源请求输出参数及加载转发接口 | 按调用方迁移自然的值返回；审查哪些转发确有装配或生命周期职责 |

## 范围与优先级

1. **P0：现状及规则一致性。** 建立当前对象拥有关系、依赖与调用入口清单，纠正文档冲突。
2. **P0：原生接口一致性。** 按真实用例统一值返回、错误和异步终态；删除已迁移旧入口。
3. **P0：生命周期和宿主职责。** 核对资源、场景、编辑操作的取消、清理与关闭顺序，消除重复状态及无职责转发。
4. **P1：文件、命名和编译边界。** 在职责确定后移动或合并文件，减少实现头泄漏，补充必要的边界反例。
5. **P0：集中验收和文档。** 验证真实工作流及跨平台构建，记录交付与尚未处理事项。

## 延续的边界

- Asset Manager 统一拥有资产加载、创建和弱索引，类型 Loader 负责解码与依赖；Render Service 管理后端 RID。
- 加载完成不等同于 GPU 上传完成；普通资源逐项采用，不恢复候选发布或跨资源事务。
- World 拥有运行实体、层级和场景成员；Scene 组合解析 Prefab，Document 管理编辑内容，投影关联文档与运行对象。
- 强引用保持对象寿命，弱缓存不额外保活；后端销毁仍须满足所属线程和已提交工作的寿命。
- 只读快照、编辑历史、IPC 镜像与运行时权威数据有不同用途，不因结构相似就机械合并。
- `result<T>` 用于自然的成功值返回；原地修改、借用视图和失败附带数据按语义设计，不机械替换所有引用参数。
- 不为未来扩展强行引入类型擦除、通用基类或新的 service。改变长期边界前另补 ADR。

## 非目标

- 不恢复公共 C ABI、对象 SDK、Game Module 或旧资产格式兼容。
- 不实现流送、LOD、CPU 载荷驱逐、完整浏览器 Editor/Runtime 或新的脚本/插件系统。
- 不改 Granit 仓库，不借架构整理扩展网络、物理和音频能力。
- 不把大场景性能遗留记为已解决，也不默认下载或重测大场景；见[性能待办](editor-render-performance-backlog.md)。
- 不提前承诺逐文件重写、全仓重命名或整套对象系统替换。

## 完成条件

- 每批有可核对的旧入口/重复状态删除清单；保留项说明职责，不能只新增包装。
- 迁移后的正式调用方、示例、工具和相关测试使用同一入口，无长期并行兼容层。
- 成功、失败、取消、重复清理、资源最后一次释放和跨线程误用的相关契约有验证证据。
- 打开/关闭场景、资源加载与重载、Prefab 编辑、撤销重做及保存完成必要的小型回归。
- Windows MSVC、Linux GCC/Clang 的受影响共享/静态边界通过；保持 Werror。
- CPU 与 GPU 用例分工明确；无图形设备环境不因测试混合而跳过整个 CPU 工作流。
- 当前说明与代码一致；未来能力和历史计划不混写，未完成项独立记录。

在没有调用方和所有权证据前，不先创建替代类。新增长期语义取舍单独记录，不用临时实现默认决定。
