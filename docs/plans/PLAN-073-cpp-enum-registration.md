# PLAN-073：C++ 枚举类型注册

状态：已完成。

目标：使用 `enum_builder<E>` 注册 C++ 枚举名称和值，属性通过实际枚举 `type_id` 共享显示项；删除属性级 `choices` 注册入口。

边界：仍使用现有 Meta 注册表；不自动解析枚举名称、不增加枚举 GUID 要求、不改变 value 或文件的整数表示，不实现 flags/枚举子集覆盖。

实现：冻结注册表时按类型关联选项，允许属性先注册。未登记选项的枚举保留整数控件。枚举名称和值由注册表拥有，冻结后查询 span 借用该数据。重复类型、名称、值被拒绝；setter 保留底层整数范围检查，业务校验继续负责合法值域。

验收：完整 Debug 编译；相关短测试覆盖类型级共享、负数枚举、注册顺序、名称寿命、重复及冻结拒绝、越界写入保持原值、现有材质编解码与面板。

2026-10-30 验收：完整 Windows Clang Debug 构建通过，相关短测试 23/23 通过。未运行真实 GPU 窗口、大场景、浏览器或远端 CI。
