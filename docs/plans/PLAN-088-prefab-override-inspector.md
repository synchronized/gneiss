# PLAN-088：Prefab 覆盖查看与恢复

状态：已完成，2026-10-30。

1. 从现有属性和组件结构覆盖生成临时显示列表，显示来源对象、组件及嵌套属性路径。
2. 支持单项和整个实例恢复，复用场景文档快照与命令历史，不引入新的覆盖权威状态。
3. Apply 冲突显示可读名称和原始定位路径，提供跳转对应对象的入口；目标不存在时保留诊断。

恢复不修改来源文件；实例自身名称、放置变换和自有子对象不属于来源覆盖，不随恢复清除。
单项使用稳定键匹配，失效键报错；结构覆盖中的新增组件整体恢复，内部值随新增记录一起移除。
验证 Debug 编译、CPU 作者操作/快照/保存回归，不运行 GPU、大场景及远端 CI。

## 验收

- 列表使用临时显示项和稳定覆盖键，不增加权威状态；属性路径通过反射取名，未知身份回退 GUID/属性 ID。
- 单项与全部恢复复用文档变更和快照历史；缺失依赖由既有 resource_service 异步加载，场景变化时拒绝采用。
- 扩展作者操作测试覆盖列表、嵌套属性名、失效键、单项恢复、整体恢复的撤销/重做/保存重载及缺失依赖收集。
- 修复相关回归发现的重复设置相同 Prefab 网格资源多记撤销历史问题，显式恢复不受此短路影响。
- Debug 构建及 36 项相关 Scene/Prefab/Editor CPU 回归通过，`git diff --check` 通过。
- 未进行 GUI 点击、宿主异步恢复的手工端到端验证、GPU、大场景及远端 CI；UI 编译通过，恢复语义和依赖准备由 CPU 测试覆盖。
