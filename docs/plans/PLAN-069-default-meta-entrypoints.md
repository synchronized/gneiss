# PLAN-069：业务反射入口统一默认注册表

## 状态

已完成（2026-10-29）。

## 已确认方向与范围

业务层注册、编解码、资产加载、Scene/Prefab 覆盖与属性编辑统一使用默认注册表，
不再接收或持有 registry。项目注册回调不带参数，启动时注册完毕后统一冻结。
Meta 核心暂保留独立注册表和显式重载供隔离测试与内部遍历使用。
不改变资源文件格式，不新增对象模型；组件仍按 GUID 查类型并调用统一 codec，
反射 JSON 是内容序列化默认能力，自定义 codec 保持优先。

## 实施与验收

- [x] 补齐默认表编解码入口，资源及项目类型注册不再传表。
- [x] 清理资产管理器、Scene/Prefab、属性编辑器的注册表参数和成员。
- [x] 同步测试和接口文档，检查初始化、冻结、失败及动态组件往返。
- [x] 完整 Debug 编译及相关短测试；不运行大场景、GPU、浏览器或远端 CI。

## 验收结果

Windows Clang Debug 完整构建通过；相关短测试 52/52 通过，包括默认表初始化失败/异常、
独立表隔离、资源反射回退与显式解码优先、Scene/Prefab 自定义组件和纯反射组件往返、
运行时与编辑器属性读写。改动行格式化及 `git diff --check` 通过。
未运行大场景、GPU、浏览器、clang-tidy 或远端 CI。

## 当前边界

业务代码与示例不再取得、保存或传递 Meta 注册表。Meta 核心仍保留显式重载和
独立表能力，容器/实例视图内部继续持有注册表以保障元数据寿命；隔离测试保留使用。
AssetBuild 的处理器注册表与 Meta 无关，不在本次修改范围内。
