# VER-008：0.8.0 编辑器资产工作流

## 状态

- 状态：本地候选验收完成，待远端矩阵
- 目标版本：0.8.0
- 优先级：P0
- 路线图阶段：编辑器资产工作流

## 目标

在 0.7.0 Editor Foundation 上形成首个资产创作闭环：

```text
浏览工程资产 → 导入 glTF/GLB → 查看状态 → 放入场景 → 撤销/重做 → 保存工程
```

Editor 应复用现有离线导入核心和 Runtime Loader，不建立平行资产格式，也不让 Runtime 依赖
fastgltf、ImGui 或工程索引。

## 非目标

- FBX、USD、Blender、动画、骨骼、Morph Target 或完整 PBR 导入。
- 通用导入插件 ABI、跨进程资产服务或后台分布式构建。
- 完整 Docking、Prefab、脚本、Runtime UI、多语言与字体管理。
- 缩略图渲染农场、全局内容寻址仓库或跨工程共享缓存。

## 已确认决策

- 采用 [ADR-019](../decisions/ADR-019-editor-asset-workflow.md) 的 `sources/`、
  `assets/imported/` 与 `.gneiss/asset-index.json` 分层。
- 首版只支持现有 glTF/GLB 静态内容范围；不支持能力必须结构化失败，不静默降级。
- 导入 SDK 是内部工具接口；CLI 与 Editor 共用实现，Runtime 和普通 package 不传播工具依赖。
- Asset Browser 展示作者资产、派生产物和导入状态，但不把原生文件路径冒充 `asset://` URI。
- Undo/Redo 首版只覆盖属性修改、创建节点和删除节点；导入文件本身不进入场景命令历史。
- ImGui Demo 改为开发菜单按需打开，正式 Editor 默认关闭。

## 实施顺序

### M-51：导入 SDK 与产物所有权

将现有内部导入核心整理为 CLI 与 Editor 共用的工具 SDK，增加单源稳定键、独占输出目录、结构化
诊断和失败保留旧产物测试。不得把 fastgltf 传播到 Runtime 或公共接口。

状态：已完成。

### M-52：版本化资产索引

实现 `.gneiss/asset-index.json` 的读取、原子写入、重建和迁移边界，记录源内容哈希、导入器版本、
输出 URI 与状态。覆盖损坏索引、失效源、重复记录、输出逃逸和失败原子性。

状态：已完成。当前格式见 [Editor 资产索引格式 v1](../reference/asset-index-format.md)。

### M-53：Asset Browser 模型与面板

建立独立于 ImGui 的资产树模型，枚举作者资产、派生产物和源资产状态；Editor 增加 Asset Browser，
支持刷新、筛选和选择。ImGui Demo 移入开发菜单且默认关闭。

状态：已完成。工具构建关闭时 Editor 保持可构建，但不编译 Asset Browser 导入模型与面板。

### M-54：导入与重新导入闭环

Editor 可选择 glTF/GLB，复制到 `sources/`，调用 SDK 导入并更新索引。显式刷新比较元数据和内容
哈希，标记缺失、过期、失败或最新状态，并支持按需重新导入。

状态：已完成。操作步骤与当前平台限制见[在 Editor 中导入资产](../guides/editor-assets.md)。

### M-55：资产到场景的最小创作路径

从 Asset Browser 选择 Mesh/Material，创建 Mesh Renderer 节点或替换所选节点资源；所有写入继续
经过场景与属性边界，保存后重新加载保持引用。

状态：已完成。场景实例负责作者描述、运行时组件和资产租约的一致更新，Editor 不保存资源 RID。

### M-56：最小 Undo/Redo

增加 Editor 命令历史，覆盖属性修改、创建节点和删除节点。命令保存稳定 ID 与值快照，不保存组件
地址、ImGui 状态或后端资源句柄；新操作清空 redo，失败命令不进入历史。

状态：已完成。当前覆盖反射属性修改、Mesh Renderer 资源替换，以及无子 Mesh Renderer 节点的
创建与删除；命令通过节点 UUID 跨节点重建解析新的运行时 ID。

### M-57：示例工程与版本验收

使用 Lantern Gallery 验证导入、过期检测、重新导入、场景放置、撤销/重做、保存和重载。完成
Windows/Linux、共享/静态、工具关闭、安装 Consumer 与无头 Editor 图形矩阵。

状态：本地候选验收已完成。Lantern Gallery 自动化工作流与 Windows Clang/MSVC、共享/静态、
工具关闭及安装 Consumer 已通过；Linux 与 Windows 远端手动 Actions 尚待授权执行，结果见
[0.8.0 候选验收记录](../records/0.8.0-validation.md)。

## 测试与验收

- 相同源文件和导入器版本生成稳定源键与确定性产物。
- 导入失败不破坏上一次产物或索引；删除源文件和删除输出均能给出明确状态。
- Asset Browser 模型可在无图形环境测试，UI 冒烟不承担全部业务正确性验证。
- 多个源文件互不覆盖，任何索引或输出路径都不能逃出工程边界。
- Editor 可完成导入、创建节点、Undo、Redo、保存和重新加载端到端闭环。
- `GNEISS_BUILD_TOOLS=OFF` 时不下载 fastgltf，也不构建导入 SDK、Asset Browser 导入功能或相关测试。

## 完成条件

- M-51～M-57 全部完成并形成 0.8.0 验收记录。
- 用户无需命令行即可把受支持 glTF/GLB 导入工程并放入场景。
- Runtime、公共 ABI、普通安装 package 与资产索引/源格式保持解耦。
- 失败导入、失败命令和失败保存均保持上一次完整状态。
