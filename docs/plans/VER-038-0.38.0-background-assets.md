# VER-038：0.38.0 资产后台处理

## 状态与目标

已完成定义范围。用户授权本版实现、提交、推送、PR、验证、合并和发布。
分支：`feat/0.38-background-assets`。以 0.37 的资产耗时测量为依据，将源文件检查、
导入和 Asset Browser 刷新移出 UI 线程，提供可观察、可取消、可安全退出的串行任务。

## 边界与决策

遵循 [ADR-045](../decisions/ADR-045-editor-background-assets.md)。不修改 Granit 或公共 ABI，
不切换 SDL3。作者 Scene/Prefab 冲突判断、应用和 Runtime 通知仍由主线程执行；
作者文档加载与监视不在本次后台化承诺内。解析器不能中途抢占，取消在阶段边界生效。

| 里程碑 | 内容 | 状态 |

| M-246 | 暂存导入、源哈希复核、取消与提交边界 | 已完成 |
| M-247 | 单工作线程、浏览器快照、状态及重试、关闭协调 | 已完成 |

测试必须验证取消和过期任务不替换现有产物，索引保存失败恢复旧产物，工作线程阻塞时
主线程仍能提交命令及读取状态，关闭不遗留线程，以及手动/自动任务共用一个写入者。
打包与后台写入互斥。保留真实测量输入和输出，不将简单三角形大文件视为复杂模型性能。

验证结果、测量数据和保留边界见 [验收记录](../records/M-246-249-0.38.0-validation.md)。

## 风险

文件系统多路径替换并非跨进程原子事务；提交期间的外部读取及进程崩溃恢复能力须明确。
外部 glTF 依赖文件的追踪不自动扩展为全依赖图。实际物理跨屏 DPI 仍需相应硬件验收。
