# PLAN-090：组件身份与编辑策略收敛

状态：已完成，2026-10-30。

1. 使用组件适配器现有 property_type 映射，清理相机描述/运行属性身份的分散判断；保留既有身份与文件。
2. 注册编辑器只读属性元数据，替代面板中的相机属性编号；只影响编辑，不影响持久化。
3. 将编辑路由及相机历史重放时保留主相机状态的规则放入组件适配器。Transform 保留对象层级专用操作。

不实现新的资源插件协议，不泛化固定材质槽，不处理诊断结构化或 Create Prefab codec。
Debug 编译和相关 CPU 测试验收，不运行 GUI/GPU、大场景、远端 CI。

## 验收

- 相机双身份比较改用适配器映射查询；既有运行属性身份保留，不修改持久化 GUID。
- 新增 editor_read_only 标记及注册校验，面板读取标记；相机主状态继续序列化，自动属性覆盖收集跳过其运行状态差异。
- 编辑路由和编辑采用策略由适配器声明；通用命令删除相机/网格 GUID 特判，相机历史重放保留当前主状态，Transform 保留层级入口。
- 测试覆盖自定义别名映射、自定义组件编辑策略、只读标记与编解码、主相机切换后的属性编辑和撤销。
- Debug 全量相关重建及最终增量编译通过，26 项相关 Meta/Scene/Prefab/Editor CPU 回归通过。
- 未运行 GUI/GPU、大场景、浏览器或远端 CI。当前资源编辑路由仍只有网格资产入口，没有宣称通用资源插件支持。
