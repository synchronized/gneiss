# PLAN-071：材质反射编辑闭环

## 状态

已完成（2026-10-30）。

## 范围与边界

Asset Browser 打开可写作者材质，编辑独立 material_description 副本。
用已有 instance 遍历嵌套对象和固定数组；属性事件保存 property_id/数组下标路径，
提交时重新定位，不持久保存成员地址。校验完整副本后通过现有命令历史提交快照。
复用 author_file_save 的基线检查和异步单文件写入；回调不持有编辑器对象。
保存快照与当前内容分别记录，保存期间继续修改不能误清除 dirty；失败保留原文档。
关闭或切换文件前要求保存或显式丢弃。生成的导入输出不直接编辑。
不增加通用资源文档基类，不做动态容器增删、GPU 预览或自动资源热更新。
宿主内部头清单增加反射借用视图及模板依赖，不公开注册表存储或后端类型。
