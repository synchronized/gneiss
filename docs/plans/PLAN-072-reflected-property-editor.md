# PLAN-072：共用属性面板与对象替换

状态：已完成。枚举注册后续由 [PLAN-073](PLAN-073-cpp-enum-registration.md) 改为类型级注册。

目标：共用属性控件及对象/固定数组遍历；材质与对象 Inspector 复用控件；可选枚举名称；同类型对象复制赋值；材质嵌套对象复制、粘贴、恢复默认值。

边界：面板只输出操作，模型负责候选副本校验、历史和保存。Inspector 保持现有 World 属性写入入口。不增加动态容器增删、GPU 预览或通用文档框架。

验收：完整 Debug 编译，相关短测试覆盖同类型赋值、错误类型、替换失败保持原值、撤销重做、枚举元数据及无窗口面板绘制；不运行大场景和远端 CI。

## 实施结果

- `reflected_property_editor` 负责对象/固定数组遍历和共用值控件，输出拥有数据的操作。
- 材质面板使用递归入口；对象 Inspector 共用值控件，仍由 World 属性入口修改现有平面属性快照，不绕过既有历史。
- `type_builder::choices` 提供可选整数枚举显示项，注册表拥有名称和值，并拒绝重复名称、重复值及类型不匹配。
- `mutable_instance::assign(instance)` 使用原生复制赋值；类型不匹配和不支持复制返回错误，不使用内存字节复制。
- 材质对象标题右键支持带类型 GUID 的文本复制/粘贴及默认值恢复；整个材质校验后作为一次历史操作提交。

## 验收记录

2026-10-30：完整 Windows Clang Debug 构建通过，相关短测试 20/20 通过。
覆盖 Meta 实例/容器/JSON、枚举元数据、对象替换和默认值恢复、错误类型与非法值拒绝、只读访问、撤销重做、保存及模块边界。
面板沿用无窗口 ImGui 绘制验证；未运行真实 GPU 窗口点击、系统剪贴板交互、大场景、浏览器或远端 CI。

限制：对象替换仅接入材质的嵌套对象；Inspector 的组件修改接口保持原状。默认值恢复复用反射解码空对象，要求该类型支持默认构造和对应解码规则。动态容器增删与实时预览不在本轮范围。
