# PLAN-057：场景对象运行时状态收敛

## 状态

实现完成（2026-10-29）。Windows Clang Debug 完整编译及 31 项相关短测试通过。

## 已确认边界

- 场景树保存节点身份、名称、层级、变换与实体关联；ECS 保存功能组件和资源引用。
- 普通场景只保存所属节点；Prefab 只额外保存来源映射、根节点、来源描述与覆盖。
- Scene 与 Prefab 共用对象创建、销毁和组件查询入口。
- 描述数据用于文件与编辑；重载回滚只临时保存旧组件，不增加长期镜像。
- 不迁移场景树到 ECS，不增加通用 Object 继承体系，不改变文件格式。

## 实施与验收

- [x] 节点元数据、统一对象创建／销毁与组件读取入口。
- [x] 普通对象记录删除重复身份、实体和资源字段。
- [x] Prefab 记录删除重复名称、父节点、实体和资源字段。
- [x] 保存、编辑、重载和失败清理使用统一运行时状态。
- [x] Windows Clang Debug 编译及场景、Prefab、编辑相关短测试；不运行大场景或远端 CI。

## 风险

清理顺序必须先释放子树关联实体再回收节点；重载失败需要从临时快照恢复旧绑定。
节点身份允许不同 Prefab 实例复用来源 UUID，唯一性由实例归属和来源地址解释。
